# 專案設定

本頁呈現 <b>Substance 3D Designer[&#128279;](https://www.adobe.com/tw/products/substance3d-designer.html) 中的專案設定</b>，以及其中包含的設定。

Substance 3D Designer 允許你為每個專案&#x200B;*建立偏好設定*，並在工作站間分享。這些偏好設定可在偏好設定[&#128279;](../../../interface/preferences-window/preferences-window.md)視窗的專案</b>標籤中找到<b>。

如果你想為同一專案團隊建立共用的工作環境，並在所有&#x200B;*系統使用*&#x200B;相同的&#x200B;*專案檔案，*&#x200B;這非常有幫助。

>[!NOTE]
>
> 如需更多關於如何在生產流程&#x200B;**中建立及整合 Substance 3D Designer**&#x200B;的資訊，我們&#x200B;*強烈建議*&#x200B;參考[文件中的管線與專案設定](../../../pipeline-and-project-con/pipeline-and-project-configuration.md)章節。

## 配置

### 設定檔

這讓你能設定 Substance 3D Designer 的設定檔</b>路徑<b>。設定檔使用 <b>\*.sbscfg</b> 副檔名，包含專案檔案清單及一套相容性顯示設定。

*預設：default\_configuration.sbscfg*

>[!NOTE]
>
> 你可以使用 **--config-file** 命令列選項，啟動 Designer 並設定特定的設定檔。\
> 如需更多關於組態檔案的資訊，可參考 [文件中的組態清單 - SBSCFG](../../../pipeline-and-project-con/configuration-list-sbscfg/configuration-list-sbscfg.md) 頁面。

### 專案檔案

專案檔案包含多個設定，定義 Designer 工作環境的關鍵面向，並排列成分頁。 這些設定列於本頁的專案章節。 專案檔案使用 <b>\*.sbsprj</b> 副檔名。

你可以匯入多個專案檔案，讓 Designer 的工作環境使用。 當存在多個專案檔案時，設定為清單（例如函式庫監控路徑、別名等） 被&#x200B;*合併*，且由列表中&#x200B;*最後一個專案檔案定義*&#x200B;為唯一集合值的設定。

*預設：default\_project.sbsprj（唯讀），user\_project.sbsprj*

>[!NOTE]
>
> 欲了解更多關於在生產管線中使用專案檔案的資訊，可參考 [文件中的專案組態檔案 - SBSPRJ](../../../pipeline-and-project-con/project-configuration-fil/project-configuration-files-sbsprj.md) 頁面。

### 相容性顯示

使用最新版本 Designer 建立的一些節點與舊版 Substance Engine 不相容。

<b>相容模式</b>會以黃色邊框標示與所選物質引擎不&#x200B;*相容的節點*。

*預設值：Substance Engine v7*

### 別名

別名用於 *縮短* 系統路徑，並讓團隊更有效 *率地共享* 資產。 別名在軟體&#x200B;**&#x200B;中以及 SBS 檔案&#x200B;*中都會使用*。

這些設定允許你 *新增* 和 *編輯* 別名。 當套用別名時，*會用以下語法<b>替換*&#x200B;映射路徑：：//</b>。

舉例來說：如果 myFolder *資料夾中的*&#x200B;資源 *myResource* 被放在 C：/Users/user/Documents *位置*，那麼將該位置映射到 *myalias* 時，*應用程式會使用**該資源所屬的 SBS 套件中的 myalias://myFolder/myResource* 路徑。

*預設值：sbs;sd-3dview-shapes;sd-3dview-maps;sd-3dview-shaders（預設專案）*

>[!WARNING]
>
> 別名是 *全域於應用程式*&#x200B;的。 這表示它們會套用到&#x200B;*應用程式中使用的所有路徑*，以及載入的 SBSPRJ 專案設定檔&#x200B;*中*&#x200B;的所有路徑。在設置專案環境時，請記得這點！\
> 此外，我們建議 *不要巢* 狀別名——也就是說，不要對同時包含在另一個別名中的路徑做別名。

### 圖書館

此區塊讓您管理<b>圖書館[&#128279;](../../../interface/the-library/the-library.md)的自訂內容</b>。

新增路徑</b>清單中列出<b>的所有資料夾內容都會包含在資料庫中。內容的任何變更都會反映在資料庫中，並會經過一段可在偏好[&#128279;](../../../interface/preferences-window/preferences-window.md)設定視窗的資料庫[&#128279;](../../../interface/preferences-window/preferences-window.md)標籤[&#128279;](../../../interface/preferences-window/preferences-window.md)中設定的刷新期。

在清單的欄位中，你可以找到選項，讓你更細緻地控制這些資料夾內容如何加入圖書館：

* **啟用：** 資料夾內容會顯示在函式庫中（*預設：已*&#x200B;勾選）
* **遞迴：** 所有子資料夾的內容也會顯示在函式庫中（*預設：已*&#x200B;勾選）
* **排除模式：**&#x200B;名稱&#x200B;**&#x200B;與輸入正則表達式（正則表達式）相符的檔案不會&#x200B;**&#x200B;在函式庫中顯示（例如 `wip-*`）。在這裡了解更多關於正則表達式語法 [的資訊](https://doc.qt.io/qt-5/qregularexpression.html#wildcardToRegularExpression)
* **排除副檔名：**&#x200B;包含&#x200B;**&#x200B;輸入文字字串的檔案不會&#x200B;**&#x200B;在函式庫中顯示。多條字串應該用 `;` 分號分隔。 (E.g. `jpg;png;tif;fbx`)

若將 SBS 套件加入函式庫，**&#x200B;**&#x200B;**若其**「Visible In Library **」參數設為「是」，則可&#x200B;*將圖與資源**&#x200B;以獨立條目顯示於函式庫*&#x200B;中。\
在建立或新增套件中的圖形或資源時，有選項可定義此參數是否預設為「是」。 **

*預設：已勾選*

如果 [函式庫中包含的 Photoshop](https://www.adobe.com/tw/products/photoshop.html) 文件（\*.PSD 檔案）有多 <b>層圖層</b>，則有選項允許您在庫中將每個圖層的內容*&#x200B;作為獨立的影像條目* 顯示。

*預設：已勾選*

### 版本控制

>[!WARNING]
>
> [Perforce](https://www.perforce.com/) 是 *目前唯一* 支援版本控制的工具。

請參閱 [版本控制](../../../interface/preferences-window/version-control/version-control.md) 頁面。

**你應該怎麼使用它？**

你應該在 Designer 的專案檔案（\*.sbsprj）中設定所有專案*&#x200B;專屬* 的偏好設定。 這些偏好包括：

* 切線空間插件
* 圖書館
* 別名
* 3D 檢視設定
* 烘焙設定
* [版本控制設定](../../../interface/preferences-window/version-control/version-control.md)

所有路徑相對於&#x200B;*專案檔案（.spsprj）都儲存*。所以你可以在 Perforce 裡和你的專案檔案在同一位置設置 **一個函式庫** 資料夾，並有以下子資料夾樹狀結構：

* 地圖/
* 網格/
* SBS/
* SBSAR/
* 附註說明
* 3Dview/
* ...

在與專案檔案同一層級，你也可以儲存切線空間插件或預設著色器。

設定檔（\*.sbscfg）應該放在 Perforce 工作區裡，與專案檔案並列。

>
> 如需更多關於如何在生產流程&#x200B;**中設置及整合 Substance 3D Designer**&#x200B;的資訊，我們&#x200B;*強烈建議*&#x200B;參考[文件中的管線與專案設定](../../../pipeline-and-project-con/pipeline-and-project-configuration.md)章節。
