# 材料性質

[3D View](../../../interface/3d-view/3d-view.md) 使用稱為&#x200B;*著色器的*&#x200B;程式渲染模型表面。著色器定義材質透過一系列影響模型外觀各方面的屬性來應用於模型。

**3D 視圖的材質**&#x200B;選單可以讓你檢查場景中每個材質使用的著色器。

<a name="openpbr"></a>

## OpenPBR

Designer 預設使用 [OpenPBR](https://academysoftwarefoundation.github.io/OpenPBR/) 材質模型，支援多種複雜效果，如各向異性，傳輸與雜訊。

Designer 內建的預設 [圖形範本](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#graph-templates) 與 [材質樣本](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#material-samples) 皆基於 OpenPBR 模型。

此著色器的屬性遵循 [OpenPBR 參數參考](https://academysoftwarefoundation.github.io/OpenPBR/#parameterreference)，並在光柵化器中共享&#x200B;**，GPU Pathtracer 和 OpenGL [3D 渲染器](../3d-renderers/3d-renderers.md)。

+++ UV

| 參數 | 類型 | 預設 | 說明 |
|---------------------------------|---------|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 鋪磚 | 浮標 | 1.0 | 一個 UV 單元的紋理重複量，值越高<br/>，紋理重複越多。 |
| 從圖中啟用實體大小 | 布林值 | 假 | 自動根據圖表的 [物理尺寸](../../../compositing-graphs/graph-parameters/graph-parameters.md)<br/>調整平鋪，以以適當比例表示材料。 |
| 紫外線尺度 | Float2 | 1.0, 1.0 | 它會分別調整 U 和 V<br/>的平板比例，數值越高，紋理重複次數越多。 |

### 與現有圖的相容性

部分 OpenPBR 材質屬性與 Designer 內建的其他模型有不同的使用識別碼。
Designer 會自動匹配部分識別碼，以確保與 OpenPBR 相容，作為其預設模型。

## Adobe 標準教材

Adobe 標準材質（ASM）模型於 Designer 11.2 中引入，並成為 Designer 的預設著色器最高版本為 15.1。

雖然 Designer 已將 OpenPBR 作為新的預設模型，但 ASM 仍然包含在內，且其屬性也被共享透過光柵化器、GPU Pathtracer 及 OpenGL [3D 渲染器](../3d-renderers/3d-renderers.md)。

此模型在此有文件說明[&#128279;](https://experienceleague.adobe.com/en/docs/substance-3d/general-knowledge/asm/adobe-standard-material)。

<a name="usdpreviewsurface"></a>

## UsdPreviewSurface

UsdPreviewSurface 模型的目的是預覽具備基本功能集的材料，促進相容性透過包含 USD 和/或 Hydra 的渲染器。

在 Designer 中，此材質模型僅由光柵化器與 GPU Pathtracer [3D 渲染器](../3d-renderers/3d-renderers.md)支援。

此模型在此有文件說明[&#128279;](https://openusd.org/dev/spec_usdpreviewsurface.html)。
