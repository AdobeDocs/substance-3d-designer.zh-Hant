# 釘住

釘子是一種輔助工具，讓你能快速跳躍在圖表中的特定位置。

你可以用他們的<b>描述</b> 屬性設定自訂標籤。

## 製作銷釘

釘子可透過以下任一方式製作：

+++節點選單
在圖表檢視中按 <b>空白鍵</b> 開啟 <b>節點選單</b>，並在列表中選擇「釘選」項目。

在搜尋欄輸入「pin」，可以快速顯示該商品並找到。

+++

+++捷徑
如果鍵盤快捷鍵被映射到偏好設定[&#128279;](../../../../interface/preferences-window/preferences-window.md)中的「釘選」項目，當圖表檢視聚焦時按下該快捷鍵。

+++

+++情境選單
在圖表檢視中，在空格按 <b>右鍵</b>並選擇 <b>「新增腳位</b> 」選項。

+++

+++圖工具列
在 Graph View 工具列中，點擊節點調色盤</b>中的<b>「釘選」按鈕。

+++

+++圖書館
在函式庫中，選擇<b>「圖項目</b>」類別，然後拖放「釘選」項目到圖譜檢視中。

+++

>[!TIP]
>
> 當針圖建立時，它的「描述」屬性會自動聚焦，讓你能立即編輯圖釘的文字。

## 跳到瓶子上

在任何圖類型中，按 <b>F2</b> 會依建立順序循環瀏覽該圖中的所有腳位。

針腳會在視窗中以目前的縮放等級框定。
