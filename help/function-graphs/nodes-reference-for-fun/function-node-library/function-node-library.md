# 函式節點函式庫

除了 [原子](../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/atomic-function-nodes.md)節點外，Designer 也提供預先製作的 Substance 函數圖作為實例節點。 他們提供許多工具來加快工作流程，並提供更多向量或顏色處理、重新映射數值、執行更進階代數等功能。

這些工具分為幾類：

<a name="sdf-functions"></a>

## SDF 功能

這些節點讓你可以撰寫 SDF 函數，並用它們專用&#x200B;**的 SDF 函**&#x200B;數參數，在 [Shape splatter v2](../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 和 [3D 檢視器](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/3d-viewer/3d-viewer.md)節點中產生 3D 形狀。

>[!INFO]
> 
> 欲了解更多涉及 SDF 函數的概念與工作流程，請前往專門頁面： [使用 SDF 函數](function-nodes-sdf-functions/working-with-sdf-functions.md)
