# 學習 Designer 中使用的術語與概念。

## #&#x200B;

|  |  |
| --- | --- |
| **3D 場景**{#three-d-scene} | 一組用於表示與動畫化三維空間視覺化的物件與資料：<ul data-preserve-html="true"> <li data-preserve-html="true">[網格](#mesh)</li> <li data-preserve-html="true">[材料](#material)</li> <li data-preserve-html="true">攝影機</li> <li data-preserve-html="true">光源</li> <li data-preserve-html="true">動畫</li> <li data-preserve-html="true">模擬</li> <li data-preserve-html="true">...</li> </ul>[常用的 3D 場景儲存檔案格式](https://www.adobe.com/products/substance3d/discover/3d-files-formats.html) 包括 Pixar [的 USD](#usd) 和 Autodesk 的 FBX。 並非所有檔案格式都支援所有這些元件 |

## A

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **阿爾法通道**{#alpha} | 彩色影像的第四通道，常用於描述不透明度。 |
| **環境遮蔽**{#ambient-occlusion} | 環境光在暴露較少、因此較難觸及的表面上衰減。 |
| **各向異性**{#anisotropy} | 依賴方向的特性。 換句話說，當測量或觀察到不同的座標軸時，結果會有所不同。<br><br>各向異性材料的外觀會因觀察地點而異，且各向異性濾光片並非均勻地應用於所有方向。 |
| **AOV**{#aov} | 任意輸出變數（Arbitrary Output Variable，簡稱AOV）是渲染中[&#128279;](#rendering)用來描述可從渲染輸出的額外資料通道的術語，例如深度、法線或自訂資料。 |
| **API**{#api} | 應用程式介面（API）是一組函式與程序，讓使用者能存取其他程式應用程式的功能與程序。<br><br>API 提供使用者與程式之間受控且安全的層。 它也可能使用其他程式語言，使該程式更易互動並更廣泛地取得。<br><br>Designer 提供 [Python API](../scripting/scripting.md) ，方便存取其多種功能，用於資料操作、建置自訂工具及加速工作流程。 |
| **原子節點**{#atomic-node} | 圖的基本構成要素。 所有 [實例節點](#instance-node) 都可以拆解成原子節點的圖。<br>每種圖類型都有自己的原子節點集合。 |

## B

|                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **烘焙**{#baking} | 從3D模型中計算資訊並儲存成 [貼圖](#texture)的過程。 資料會根據模型的 [UV](#uv) 配置到貼圖中。 |
| **底色**{#base-color} （Albedo） | 利用PBR金屬粗糙[度著色](#shader)模型定義的材料[&#128279;](#material)通道。<br>底色是指表面的顏色，但沒有任何光照資訊。<br><br>它不應與 [擴散（Diffuse](#diffuse)）混淆。 |
| **基準參數**{#base-parameter} | 一個 Substance 圖中所有計算 [位圖](#bitmap)節點共有的參數。<br><br>這些包括點陣圖的核心面向，如解析度（[輸出大小](#output-size)）與 [位元深度](#bit-depth) （[輸出格式](#output-format)），或點陣圖的計算方式，如 [平](#tiling) 鋪模式。<br><br>基礎參數通常[&#128279;](#inheritance)繼承自上游的其他節點或該節點所承載的圖。 |
| **雙線性濾波**{#bilinear-filtering} | 一種用於電腦影像的插值過程，當 [紋理樣本](#texture-sampling) 並非精確位於像素中心時。<br><br>例如，當影像被放大時，這種情況就可能發生。 |
| **位元深度**{#bit-depth} | 用來儲存紋理中像素值的位元數。 較高的位元深度允許編碼更多值，進而產生更平滑的梯度。<br><br>根據值的類型，有不同的位元深度可供選擇：- 整數值可用 8 位元（0 到 255）或 16 位元（0 到 65,535）來編碼。 - 浮點數值可用 16 位元（+32767.9999 至 -32768.0）或 32 位元（-3.4E+38 至 +3.4E+38）<br><br>編碼。低動態範圍影像則使用整數值編碼 0 到 1 的階梯。 高動態範圍影像使用浮點數來編碼原始數值。<br><br>在 Substance 圖中，位元深度由 [輸出格式](#output-format) 參數控制。 |
| **位圖**{#bitmap} | 一張數位影像。 最常見的影像類型有兩種：<ul data-preserve-html="true"> <li data-preserve-html="true">灰階影像只有一個通道：亮度（L）;</li> <li data-preserve-html="true">彩色影像有三個通道：紅、綠、藍（RGB）。 可能還有 [第四個：alpha](#alpha) （A），通常用於不透明度。 Designer 中的彩色影像總是 RGBA。</li> </ul>  點陣圖可被視為數值的網格。 該格子的每個格子都是像素，像素是「圖片元素」的縮寫。 每個像素每個通道儲存一個值。 該值的類型取決於 [位圖的位元深度](#bit-depth) 。 |

## C

|                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **快取**{#cache} （記憶體） | 一組資料——例如： Node 的 [基礎參數](#base-parameter) 與輸出映像——儲存在記憶體中以便重複使用。<br><br>快取大幅加快圖形計算速度，因為它讓 [Substance Engine](#substance-engine) 只重新計算已改變的圖部分。 調整節點連接與參數時，之前所有節點不受這些變更影響，因此不需要 [再次評估](#evaluation) 以更新圖。 取而代之的是他們的快取。<br><br>在處理大型圖形中高解析度與位元深度時，快取可能會佔用顯著的記憶體。 |
| **通道包裝**{#channel-packing} | 一種優化技術，將獨立影像壓縮在單一彩色影像的 RGB（A） 通道中。<br><br>例如，RMA 材質是 [粗糙度](#roughness) 貼圖（R）、金屬度貼圖（M）和 [環境遮蔽](#ambient-occlusion) 貼圖（A）全部壓縮在單一色彩貼圖中。<br><br>另一種常見技術是在法線貼圖[&#128279;](#normal-map)的藍色通道中打包灰階紋理，因為藍色通道——即法向量的「向上」部分——可以在執行時重新計算。<br><br>[RGBA 合併](../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md)節點對於實作此技術非常有用。 |
| **色彩空間**{#color-space} | 定義了一範圍的顏色如何被表示。<br>數位編碼與解碼特定顏色需要這樣的定義，才能理解所使用的數字。<br><br>影像檔案會使用指定的色彩空間來儲存色彩值，這樣這些顏色就能在支援該色彩空間的顯示器上忠實地重現。 顯示器具備特定的色彩重現能力，使其能完全或部分支援特定色彩空間。<br><br>原始資料——例如 [法線映射](#normal-map)——總是在線性色彩空間中編碼與解碼，因為這些顏色並非用於視覺化，且不應對該資料進行任何轉換。<br><br>sRGB 是廣泛支援的色彩空間。其他常見的色彩空間包括 Adobe RGB、Rec。 2100 和 ProPhoto RGB。 |
| **烹飪**{#cooking} （{#compilation}合輯） | 將資料翻譯成另一種語言，以便能快速且有效地執行的過程。<br>計算物質圖的結果需要先將其編譯。 編譯是圖 [評估](#evaluation) 過程的一部分。<br><br>此編譯是在扁平化圖上執行，意即 [所有實例節點](#instance-node) 被其來源圖「替換」，因此只剩下一個較大的圖，該圖即為編譯的圖。<br><br>編譯後的圖無法編輯。 如果參數是 [動態](#dynamic-parameter)的，則會保留公開參數，而 [靜態](#static-parameter) 參數則被鎖定並隱藏。 |
| **淘汰**{#culling} | 一種用於 [渲染](#rendering) [3D 場景](#three-d-scene) 的優化技術，當渲染圖形不可見時，會將其從計算中移除。<br><br>這可能包括相機錐體外的物件或多邊形（*錐體剔除*）、面向相機對面方向的物件（*背面剔除*），或完全被其他不透明物件遮蔽（*遮蔽剔除*）。 |

## D

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **依賴性**{#dependency} | 一個檔案 A 被另一個檔案 B 使用，導致當檔案 A 缺失時，檔案 B 無法如預期運作。<br><br>套件的相依[&#128279;](#package)性可以是另一個套件，因為它參考了其中的圖形、影像檔案、字型等。<br><br>套件儲存其相依路徑，若在該路徑找不到相依，會發出警告。缺少相依關係也 [可能導致圖中出現幽靈節點](#ghost-instance-node) 。 |
| **彌漫**{#diffuse} | 利用 PBR 鏡面光澤[著色](#shader)模型定義的材質[&#128279;](#material)通道。漫射指的是點亮時表面的顏色。<br><br>它不應與 [底色（Albedo）](#base-color)混淆。 |
| **DirectX**{#directx} | 一套用於處理多媒體內容的 API。 其 3D API Direct3D 廣泛應用於電子遊戲開發及其他 3D 產業。<br><br>Direct3D 將紋理的起點（即 （0， 0） 座標）置於&#x200B;*左*&#x200B;上角（Y-down），而 OpenGL[&#128279;](#opengl) API 則將其置於&#x200B;*左*&#x200B;下角（Y-up）。<br><br>這表示 DirectX [法線貼圖](#normal-map)的&#x200B;*通道*&#x200B;相較於 OpenGL 呈現反轉的綠色。事實上，綠色通道承載了法向量的 Y 座標。 |
| **遷移**{#displacement} | 移動3D模型頂點的過程[&#128279;](#vertex)，通常是沿著其[法線](#normal)移動。<br><br>位移常與鑲嵌[&#128279;](#tessellation)和[法線貼圖](#normal-map)結合使用，以在表面上建模更細緻的細節。 |
| **動態參數**{#dynamic-parameter} | 一個參數，該參數的值可能會改變。 換句話說，任何值不常的參數都是動態的。<br><br><br>這包括暴露參數、受暴露參數影響的參數，以及任何受貼圖[&#128279;](#texture-sampling)取樣影響的參數值。<br><br>與 [靜態參數](#static-parameter)不同，動態參數的值可在圖彙編成 [SBSAR 檔案](#sbsar-file)後即時調整。 |

## E

|                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **評價**{#evaluation} | 解析圖中資料與參數傳播的過程。 評估是驗證圖及其連結的有效性，應用 [繼承，](#inheritance)並 [處理](#cooking) 圖。<br><br>在圖視圖中，當連接未被評估時，會以虛線表示。<br>評估將連結轉化為實線。<br><br><br>每當圖中參數被調整時，承載該參數的節點及所有下游節點都會被[&#128279;](#invalidation)取消，必須在渲染[&#128279;](#rendering)前重新評估。 |

## F

|                                                                         |                                                                                                                                  |
|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| **濾波器**{#filter} （節點） | 一個[&#128279;](#node)節點，對影像進行修改（例如變形）或從中提取資訊（例如遮罩）。 |

## G

|                                                                                            |                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **幽靈實例節點**{#ghost-instance-node} | 若參考[的子圖](#subgraph)無法找到——即缺少[依賴——](#dependency)的實例節點[&#128279;](#instance-node)會被載入為幽靈實例節點。<br><br>透過解決缺失的相依性並重新載入 [套件](#package)，幽靈實例節點會被恢復到預期狀態。 |
| **光澤**{#glossiness} | 利用 PBR 鏡面光澤[著色](#shader)模型定義的材質[&#128279;](#material)通道[。光澤性指的是表面的粗糙度——即高度的微觀變化，也稱為 *微多面*。<br><br>高光澤度會帶來平滑的質感，而低光澤則會呈現粗糙且霧面的質感。<br><br>它是粗糙度](#roughness)的反面。 |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **直方圖（圖片）**{#histogram} | 在影像的情境中，直方圖代表給定範圍內的數值族群——通常是 [0， 1]。<br><br>此族群以垂直條線視覺化，影像中出現較多的數值代表該數值的長條較高。<br>條狀圖水平分布，從低值（暗）到高值（亮）。<br><br>彩色影像的直方圖通常與各通道的直方圖重疊，通常是 R、G、B。 |

## I

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **繼承**{#inheritance} | 在 Substance 圖的語境中，繼承描述節點從其上游節點或父圖獲取參數值的特性。<br><br>繼承的參數包括 [解析度](#resolution) （[輸出大小](#output-size)）、 [位元深度](#bit-depth) （[輸出格式](#output-format)）及 [平](#tiling) 鋪模式。<br><br>在此專頁[&#128279;](../compositing-graphs/inheritance-compositing/inheritance-in-substance-compositing-graphs.md)了解更多關於繼承的資訊。 |
| **實例節點**{#instance-node} | 一個實例節點將圖 A 表示到另一個圖 B 中。此時，圖 A 可稱為 [圖 B 的子圖](#subgraph) 。圖 A 的任何變化都會傳播到所有代表該圖的實例節點。<br><br>實例節點會在圖 B 的情境中套用自己的輸入參數集合。從這個角度來看，圖 B 可以承載多個實例節點，這些節點皆參考圖 A，但每個實例會將不同的值或紋理作為輸入傳入圖 A。<br><br>Designer&#39;s Library 中所有非 [原子節點](#atomic-node) 的節點都是實例節點。 |
| **無效化**{#invalidation} | 宣告節點結果已過時的程序。<br><br>當參數被調整時，承載該參數的節點及所有下游節點都會失效，因此需要 [重新評估](#evaluation) 並 [重新渲染](#rendering) 。 |

## M

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **材料**{#material} | 物質在空間中的性質與行為集合，包括表面與體積。<br>一個實體在三維空間中的外觀是由其材質所定義的。<br><br>材料的定義方式多樣，且所有定義都不支持折射、各向異性或光澤等所有性質。 [著色器](#shader)是材質定義的特定實作。<br><br><b>重要提示：「</b>材質」一詞是一個&#x200B;**&#x200B;總稱，用來指稱多種事物，包括：<ul data-preserve-html="true"> <li data-preserve-html="true">[用於計算表面或體積外觀的著色器](#shader);</li> <li data-preserve-html="true">提供給著色器的貼圖[&#128279;](#texture)集合;</li> <li data-preserve-html="true">材質 ID，是 3D 圖元的一個屬性，用來區分使用不同材質的零件。</li> </ul> |
| **網狀**{#mesh} | 一個由 [頂點組成的](#vertex) 三維物件，頂點由邊連接形成多邊形——例如三角形——而這些多邊形再被組合成曲面。 這些表面可以是開放式或封閉式。<br><br>這些表面的外觀由 [分配給它們的材質](#material) 所定義。<br>網格的細節程度也高度依賴於其 [多邊形數量](#polycount)。 |
| **元資料**{#metadata} | 提供關於檔案本身、其環境或與檔案資料相關資訊的資料。<br><br>常見的元資料包括檔案作者、創建與修改日期、版權及封面藝術。<br><br>在 Designer 中，套件[&#128279;](#package)的內容也可以包含元資料。例如，產生織物材料的物質圖可能包含織物物理特性的元資料。 |
| **Mipmap**{#mipmap} | 紋理[&#128279;](#texture)的縮小版本，通常由<br><br>自動計算。紋理可以有自身較小版本的金字塔，這些版本在執行時可互換，以取得最佳品質與效能的最佳大小。<br><br>例如，高頻細節的紋理在較小尺寸下顯示，可能會產生 *莫爾痕* 跡。 此外，較大的紋理通常包含更多的 [紋理樣本](#texture-sampling)。<br><br>「mipmap」一詞源自MIP映射技術，其中MIP代表拉丁文「*multum in parvo*」，意指「小地方裡有許多事物」。 |

## N

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **節點**{#node} | 圖中的物件，執行計算並輸出一個或多個結果。<br><br>結果由輸入參數控制。 這些參數可以在屬性底座中列出為控制項，或作為節點本身的輸入連接器。<br><br>節點主要分為兩大類： [原子節點](#atomic-node) 與 [實例節點](#instance-node)。 |
| **噪音**{#noise} | 一種非具象的圖像，代表形狀與顏色的隨機或偽隨機分布。 噪音常用於為表面或變形增加變化。<br><br>Designer 的節點函式庫包含大量噪音產生器，如 [BnW 斑](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/bnw-spots-2/bnw-spots-2.md)點、[&#128279;](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/perlin-noise/perlin-noise.md)雲[&#128279;](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/clouds-2/clouds-2.md)、Perlin 噪音或 [Voronoi](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/voronoi/voronoi.md)。 |
| **正常**{#normal} | 在三維計算中，曲面的法線是一個 [垂直於該曲面的正規化](#normalization) 向量，從該曲面向外延伸。<br><br>此向量代表 3D 空間中曲面的方向，並用於[根據場景的光源與攝影機視角對該曲面進行](#shader)著色。<br><br>[法線貼](#normal-map)圖貼圖貼圖可用於曲面修改法線並增加細節。 |
| **法線貼圖**{#normal-map} | 貼 [圖](#texture) 貼在表面上以修改其法線。<br><br>它最常用來偽造那些在模型幾何中加入效率不高的細節。 使用此類映射可讓每頂點[&#128279;](#vertex)法線外，還能擁有每[像素](#texel)法線，從而獲得更多曲面資訊，進而提升曲面細節。<br><br>法向量的 X、Y 和 Z 座標分別編碼在地圖的紅、綠、藍通道中。 根據目標圖形 API（[DirectX](#directx) 或 [OpenGL），](#opengl)綠色通道可能會反轉。 |
| **正規化**{#normalization} | 將一組數值重新映射到 [0， 1] 範圍的過程，其中最高的輸入值會被重新映射為 1.0，最低的輸入會被重新映射為 0.0。<br><br>對於向量而言，正規化是將向量的長度（或稱「大小」）調整為 1.0。 |
