# 腳本編寫

可以透過撰寫外掛來控制應用程式。 外掛可用 Python **腳本語言撰寫**，使用版本 **3.9**。應用程式中提供的 Python API 允許直接從腳本存取並使用許多功能。

[Python](https://www.python.org/) 是一種在許多產業中廣泛使用的腳本語言。 它有助於建立自動化、工作流程加速及資產管理工具等多種功能。 API 文件可從主選單 **透過「腳本說明** > **文件...** 動作」存取。
