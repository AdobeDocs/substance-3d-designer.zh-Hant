# MDL 學習資源

本頁提供在 Substance 3D Designer 中使用 [MDL 圖形](../../mdl-graphs/mdl-graphs.md) 的學習資源。

## 參考資料

以下是一份有助於你更深入了解 MDL 材質及其在渲染引擎（例如 NVIDIA 自家 Iray 路徑追蹤器）中的應用的有用文件與參考資料清單。

* [NVIDIA - 材料定義語言](http://www.nvidia.com/object/material-definition-language.html)
* [NVIDIA - MDL 文件](https://raytracing-docs.nvidia.com/mdl/index.html)
* [NVIDIA - MDL 手冊](http://mdlhandbook.com/)
* [NVIDIA - MDL 規範 v1.6](https://developer.download.nvidia.com/designworks/mdl-sdk/secure/MDL_spec_1.6.1_16Dec2019.pdf?__token__=exp=1776166178~hmac=38656bc9d8199764568d1fa0d4d945b90c57638ebd37b100a402bdc983e518ee&t=eyJscyI6ImdzZW8iLCJsc2QiOiJodHRwczovL3d3dy5nb29nbGUuY29tLyJ9)
* [NVIDIA - Iray](https://www.nvidia.com/en-us/design-visualization/iray/)

### 在 Substance 3D Designer 中建立 MDL

[這個系列](https://www.adobe.com/learn/substance-3d-designer/web/creating-an-mdl-in-substance-3d-designer) 是 *了解 MDL 圖形以及在 Designer 中使用 MDL 材質的絕佳起點* 。

本教學中涵蓋的金屬透明塗層材料無法僅透過紋理定義：它有 *兩種不同的高光* ，表現不同：一層較粗糙且帶有斑點的金屬層，另一層非常光滑的透明頂層。

「本課程涵蓋Substance 3D Designer中MDL的基礎。 我們將重現一個物理基礎的金屬/粗糙度著色器作為 MDL，以說明 MDL 節點與圖表的核心概念。 在第二支影片中，我們將探討如何製作一款汽車漆面 MDL。」

[本文](https://www.adobe.com/learn/substance-3d-designer/web/mdl-malachite-material-breakdown) 將帶你了解製作 *更精緻* 材料的方法，這些材料也無法僅靠材質來達成。 在此，利用 MDL 圖與 [Substance 圖](../../compositing-graphs/substance-compositing-graphs.md) 之間的協同效應，高效達成卓越成果。
