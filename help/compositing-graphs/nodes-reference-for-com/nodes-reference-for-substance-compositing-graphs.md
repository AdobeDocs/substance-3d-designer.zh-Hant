# Substance 圖的節點參考

由於 Substance 3D Designer 是一款基於節點的貼圖軟體，你可以使用許多不同的節點。 本節旨在說明不同類型，並記錄軟體所附的所有節點。

我們所稱的 SD 內部的「節點」，可分為兩大主要群組：

* [原子節點](../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md)，任何圖的核心建構單元。
* [圖實例](../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md)、複合節點，節點函式庫中提供 [大量預設內容](../../compositing-graphs/nodes-reference-for-com/node-library/node-library.md)
