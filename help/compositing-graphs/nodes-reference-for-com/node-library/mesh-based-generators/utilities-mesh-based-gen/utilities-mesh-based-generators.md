# 工具（基於網格的產生器）

這些節點是比較抽象的工具，幫助你處理網狀自適應節點。 在某些情況下，它們的功能也與 [材質過濾器](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md) 密切相關。

這個類別只有少數節點，請務必全部查看。
