## 說明

根據烘焙的地圖和使用者設定產生黑白遮罩。 這基本上就是 Painter 的 Mask Builder 設計師版。

這是一個複雜的工具，旨在作為包羅萬象的遮罩建構器，基於烘焙的貼圖、使用者參數以及垃圾搖滾模式與貼圖。 它主要設計為非常先進的全控制節點，用來融合摺痕、髒污和邊緣磨損。 此節點強大到能模擬所有其他面具產生器。

雖然沒有明確的烘焙需求，但你供應越多，這個節點能做的就越多。

## 參數

### 輸入

* **環境遮蔽**： *灰階輸入*
* **曲率**： *灰階輸入*
* **世界空間法線**： *色彩輸入*
* **垃圾搖滾輸入**： *灰階輸入*
* **垃圾搖滾輸入2**： *灰階輸入*
* **散射輸入**： *灰階輸入*\
  自訂散射印章，必須利用散射參數。
* **遮罩（可選）：***灰階輸入*\
  遮罩槽用於遮蔽節點的效果。
* **位置**： *顏色輸入*\
  用於三平面及上下效果。

### 參數

* **等級**： *0.0 - 1.0*\
  設定效果的總強度，逐步揭露。
* **對比**&#x200B;度： *0.0 - 1.0*\
  調整結果的對比度。
* **反轉**： *錯誤/真實*\
  結果會被反轉。 這有助於達成你正在打造的遮罩的相反效果。
* **使用三平面**： *False/True*&#x200B;啟用三平面投影，避免任何帶有髒污地圖的接縫。
* **三平面混合對比**&#x200B;度： *0.0 - 1.0*&#x200B;設定三平面混合的對比度。
* **Grunge**： *0.0 - 1.0*&#x200B;設定全球融合的 Grunge 元素。
* **垃圾搖滾**
  * **尺度**： *0 - 10*&#x200B;設定全球垃圾搖滾的尺度。
  * **使用 Custom Grunge**： *False/True*&#x200B;啟用自訂 Grunge 輸入。
  * **次要自訂垃圾搖滾**： *0.0 - 1.0*&#x200B;啟用第二個自訂垃圾搖滾輸入。
  * **反轉**： *錯誤/真實*\
    顛覆了垃圾搖滾的地圖。
* **AO：***-1.0 - 1.0*&#x200B;設定該效果在被遮蔽的AO區域出現的範圍。可以用以下群組調整。
* **AO**
  * **範圍**： *0.0 - 1.0*&#x200B;設定泥土外觀的閾值或範圍。
  * **對比**&#x200B;度： *0.0 - 1.0*\
    調整 AO 效果的對比度。
  * **噪音：***0.0 - 1.0*&#x200B;設定噪音/垃圾搖滾的程度，讓它們融入 AO 效果。
  * **噪音等級**： *0 - 10*&#x200B;設定 AO 噪音/垃圾搖滾的等級。
  * **噪音類型**： *斑點、雲朵、濕氣、白噪音*&#x200B;在四種不同類型的 AO 噪音間切換。
  * **反轉**： *錯誤/真實*\
    顛覆了 AO 地圖的解讀：噪點會出現在明亮的 AO 區域，而非暗處。
* **曲率**： *0.0 - 1.0*&#x200B;設定曲率邊緣應出現的效果;可為凸與凹。 請和下面的群組一起調整這個設定。
* **曲率**
  * **凸範圍**： *-1.0 - 1.0*&#x200B;設定凸（明亮）曲率邊緣的效果。
  * **凸對比**&#x200B;度： *0.0 - 1.0*&#x200B;設定凸效應的對比度。
  * **凸反轉**： *假/真*&#x200B;將凸邊的詮釋推翻。
  * **凹面範圍**： *-1.0 - 1.0*&#x200B;設定凹面（深色）曲面邊緣的效果。
  * **凹對比**&#x200B;度： *0.0 - 1.0*&#x200B;設定凹面範圍的對比度。
  * **凹反轉**： *假/真*&#x200B;反轉對凹邊的解釋。
  * **平滑度**： *0.0 - 16.0*&#x200B;用於曲面邊緣的模糊與平滑程度。
  * **等級提升**： *0.0 - 1.0*&#x200B;若效果不夠明顯，則需額外加成。
  * **噪音：***0.0 - 1.0*&#x200B;設定噪音/垃圾搖滾對曲率效果的影響。
  * **噪音等級**： *0 - 10*&#x200B;設定噪音的等級。
  * **噪音類型**： *斑點、雲朵、濕氣、白噪音*&#x200B;從四種不同噪音類型中選擇。
* **上下漸層**： *-1.0 - 1.0*&#x200B;根據位置貼圖，從上到下漸層混合或遮罩。 正值會讓東西更明亮，負值則掩蓋現有效果。
* **梯度**
  * **範圍**： *0.0 - 1.0*&#x200B;設定梯度位置。
  * **對比**&#x200B;度： *0.0 - 1.0*\
    調整漸變的對比度。
  * **反轉**： *錯誤/真實*\
    反轉梯度。 實際上是上下互換。
* **世界空間法線**： *0.0 - 1.0*&#x200B;類似於頂/下漸層，但帶有位置圖且有六個方向，類似假光照。 正值變亮，負值變暗。
* **世界太空常態**
  * **最高強度**： *-1.0 - 1.0*
  * **底部強度**： *-1.0 - 1.0*
  * **前葉強度**： *-1.0 - 1.0*
  * **背部強度**： *-1.0 - 1.0*
  * **右心強度**： *-1.0 - 1.0*
  * **左側強度**： *-1.0 - 1.0*
* **刮痕**： *-1.0 - 1.0*&#x200B;將刮痕融合到白色區域。
* **刮痕**
  * **數量**： *0 - 4096*&#x200B;設定總刮痕數量。
  * **比例**： *0.0 - 1.0*&#x200B;設定個別刮痕的比例。
* **散布**： *-1.0 - 1.0*&#x200B;在白色區域內散布自訂印章。
* **散射**
  * **規模**： *0 - 50*&#x200B;效果的總規模。
  * **密度**： *0.0 - 1.0*&#x200B;散射密度控制，應該會出現的數字。
  * **尺寸**： *0.0 - 4.0*&#x200B;散落郵票的尺寸。
  * **尺寸差異**： *0.0 - 1.0*&#x200B;郵票尺寸內的差異。
  * **不透明度變化**： *0.0 - 1.0*&#x200B;印章不透明度內的差異。
