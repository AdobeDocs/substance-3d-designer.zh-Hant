## 說明

根據烘焙的地圖和使用者設定產生黑白遮罩。 這基本上就是 Painter 的 Mask Builder 設計師版。

這是一個複雜的工具，旨在作為包羅萬象的遮罩建構器，基於烘焙的貼圖、使用者參數以及垃圾搖滾模式與貼圖。 它主要設計為非常先進的全控制節點，用來融合摺痕、髒污和邊緣磨損。 此節點強大到能模擬所有其他面具產生器。

雖然沒有明確的烘焙需求，但你供應越多，這個節點能做的就越多。
