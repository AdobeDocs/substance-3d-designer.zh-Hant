## 說明

以指定的指數驅動輸入。 類似調整 [等級](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)中點，但更簡單的方式。 當你想執行精確的數學冪運算時也很有用。

重要提示：請確保使用正確的版本，視你使用的是彩色還是灰階輸入！

## 參數

* **指數**： *0.0 - 10.0*&#x200B;以指數來驅動輸入。
