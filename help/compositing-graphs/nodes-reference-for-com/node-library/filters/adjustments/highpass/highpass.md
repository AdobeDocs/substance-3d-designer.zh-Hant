## 說明

執行高通濾波器，提供彩色及灰階版本。 類似同名的 Photoshop 動作。\
對於消除影像中明顯的亮度差異非常有用，例如在平鋪時清理貼圖時。

重要：務必使用適合你輸入的版本！ 色彩輸入用「Highpass」，灰階輸入用「Highpass Grayscale」。

## 參數

* **半徑**： *0.0 - 64.0*\
  濾波半徑：半徑小則能去除小差異，半徑越大就能去除大面積。
