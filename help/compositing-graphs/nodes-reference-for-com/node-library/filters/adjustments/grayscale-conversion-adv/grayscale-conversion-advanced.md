## 說明

先進且快速的灰階轉換節點，提供幾種預設的轉換模式。

## 參數

* **灰階類型**： *去飽和度、亮度、平均值、最大值、最小*&#x200B;值 去飽和度設定為 0，亮度使用官方亮度權重，平均值與原子節點相同，最大值與最小值分別用於每個通道的最亮值。
