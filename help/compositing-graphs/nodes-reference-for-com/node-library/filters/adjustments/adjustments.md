# 調整

這是主要的濾波器類別之一，節點用來以各種方式調整輸入的值與範圍。 大多數節點是使用 [層級](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) 與 [混合](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blend/blend.md) 節點的進階擴充方式，旨在作為某些操作的更聰明捷徑。

使用<b>左側</b>的導覽列表，在調整選項下瀏覽所有節點。

幾個值得參考的節點：

* [直方圖掃描](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md)
* [倒轉](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/invert/invert.md)
* [自動關卡](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/auto-levels/auto-levels.md)
* [從顏色到遮罩](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/color-to-mask/color-to-mask.md)
