## 說明

除錯工具用來檢查高動態範圍的精確區域。 彩色與灰階兩種版本皆存在。

## 參數

* **範圍最小**： *-2.0 - 0.0*&#x200B;開始高亮的最低範圍。
* **最大**&#x200B;範圍： *1.0 - 3.0*&#x200B;最大高亮範圍。
