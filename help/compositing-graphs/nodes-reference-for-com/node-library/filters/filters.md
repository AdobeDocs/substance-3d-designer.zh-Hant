# 濾鏡

濾波器是處理輸入產生修改過的「濾波」輸出的節點，類似你在其他知名影像應用中習慣的做法。 材質過濾器最大的差別 [在於它們只對](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md) 一個（有時更多）且不代表完整材質的輸入有效。

過濾器是最常見的主要類別之一。 除了 [Atomic 節點類別](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md) 外，沒有其他類別能像從零開始建立貼圖時一樣有用。 花時間了解每個子類別：

* [調整](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/adjustments.md)\
  色彩、色調和明暗的擴展調整。
* [混合](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blending/blending.md)\
  進階與擴展的混合模式。
* [模糊](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blurs.md)\
  先進且高品質的模糊效果。
* [頻道](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/channels.md)\
  擴展通道混音節點。
* [影響](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/effects.md)\
  以貼圖為導向的影像效果，以及「圖層風格」類型的效果。
* [法線貼圖](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-map.md)\
  以法線貼圖為核心的操作。
* [鋪磚](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/tiling.md)\
  節點專注於修復和改善平鋪。
* [轉換](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/transforms.md)\
  進階（數學）二維空間轉換運算。
