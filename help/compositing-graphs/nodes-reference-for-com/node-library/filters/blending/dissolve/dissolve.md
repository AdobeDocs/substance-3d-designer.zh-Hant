## 說明

將兩個輸入混合在一起，並以白噪音作為過渡的遮罩。

## 參數

### 輸入

* **前景**： *色彩輸入*
* **背景**： *色彩輸入*
* **遮罩**： *灰階輸入*\
  遮罩槽用於遮蔽節點的效果。

### 參數

* **不透明度**： *0.0 - 1.0*\
  融合前景與背景的不透明度。
* **Alpha 混合**： *錯誤/真實*\
  切換前景與背景 alpha 通道的混合。 若設為 False，則忽略前景的 alpha 通道。
