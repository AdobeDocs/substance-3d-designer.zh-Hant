## 說明

在輸入時產生旋轉的動態模糊效果。

## 參數

* **取樣**&#x200B;數： *1 - 128*&#x200B;設定模糊效果的品質。
* **角度**： *0.0 - 0.5*&#x200B;設定效果的「旋轉」程度。
* **中心位置**：\
  設定效果的中心點。
