## 參數

|  |  |
|:---|:---|
| <b>取樣</b> <i>1 - 128</i> | 設定模糊效果的品質。 |
| <b>角度</b> <i>0.0 - 0.5</i> | 設定效果的「旋轉」程度。 |
| <b>中心位置</b> | 設定效果的中心點。 |
