# 模糊

模糊類別是標準 [原子盒模糊節點](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md)的擴展。 它包含了更先進、更高品質且多種用途的模糊影像。

請記得每個 Library Blur 節點都有灰階和彩色版本。 盡量使用適合你輸入的版本！

推薦一些不錯的模糊作品：

* [模糊總部](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blur-hq/blur-hq.md)
* [斜坡模糊](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/slope-blur/slope-blur.md)
