## 說明

**3D 貼圖偏移**&#x200B;節點會在連接輸入&#x200B;**的 3D 貼圖***所描述*&#x200B;的物件上，對 X **、** Y **和** Z **軸進行&#x200B;*偏移轉換***。

</td>
</tr>
</table>

## 參數

### 輸入

* **輸入***灰階/彩色*\
  描述 *一個3D物件的3D材質* 。\
  這個物件通常以 *單位立方體*&#x200B;來描述。

### 參數

* **偏移** *Float3*\
  對於連接輸入&#x200B;**的** 3D 貼圖&#x200B;*所描述*&#x200B;的物件所施加的世界空間&#x200B;*偏移*&#x200B;量。
