## 參數

|  |  |
|:---|:---|
| <b>對稱模式</b> <i>鏡子Y、鏡子X、斜向左、斜向右、鏡子X/Y、鏡子X/鏡子Y、斜向左/對角右、對角/對角線左，8</i> | 選擇對稱幾何模式。 |
| <b>傳輸模式</b> <i>0 - 6</i> | 選擇對稱混合模式：複製、加法、減法、乘法、加碼、最大值、最小值。 |
