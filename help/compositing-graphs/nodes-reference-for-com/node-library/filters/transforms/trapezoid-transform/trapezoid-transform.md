## 說明

特殊的變換節點，會以透視/梯形扭曲的方式改變輸入。 可以控制上下兩邊的伸展。 數值可以被推到極限以達到更強的效果。

## 參數

* **頂部拉伸**： *0.0 - 1.0*&#x200B;設定頂部的拉伸或壓扁量。
* **底部伸展**： *0.0 - 1.0*&#x200B;在底部設定拉伸或壓迫的量。
* **背景色**： *（灰階/色彩值）*\
  如果關閉平鋪，請設定為純色背景色。
* **取樣：***雙線性，*&#x200B;最近集取樣品質。
