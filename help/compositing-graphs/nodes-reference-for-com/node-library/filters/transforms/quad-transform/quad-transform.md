## 說明

特殊的轉換節點，允許透過與角點互動來變換四邊形。 允許以非常具體的變身方式進行實務操作。

## 參數

* **p00**：左上角。
* **第1**&#x200B;頁：左下角
* **第10**&#x200B;頁：右上角。
* **第11**&#x200B;頁：右下角。
* **剔除**： *僅前置、僅後、前後、前後*&#x200B;對置 當點交叉時的形狀剔除/隱藏。
* **啟用平鋪**： *錯誤/真實*
* **背景色**：*（灰階值）*如果平鋪不對，則為純色背景色。
* **取樣：***雙線性，*&#x200B;最近集取樣品質。
