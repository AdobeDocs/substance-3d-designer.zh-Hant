## 說明

這會透過將輸入影像以旋轉方向扭曲來轉換。 它還能額外控制旋轉圖案到畫布的各個部分。

## 參數

* **矩陣**\
  允許你手動移動旋轉效果。 也可以透過在 2D 預覽中與 handle 互動來修改。
  * **矩陣**： *（轉換矩陣）*
  * **偏移**&#x200B;量： *0.0 - 1.0*
* **數量**： *-16.0 - 16.0*&#x200B;旋轉效應的強度。
