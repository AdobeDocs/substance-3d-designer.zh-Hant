## 說明

這會透過將輸入影像以旋轉方向扭曲來轉換。 它還能額外控制旋轉圖案到畫布的各個部分。

| <b>矩陣</b> <i>（變換矩陣）</i> |  |
| <b>偏移</b> <i>0.0 - 1.0</i> |  |
