## 說明

計算指定的 SDF 或由函數圖定義的交叉場景的 3D 渲染，並搭配自訂攝影機與環境光源。<br><br>此節點有助於撰寫與視覺化 [Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 節點中使用的 SDF 函式[](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)。<br><br>有輔助工具可用來視覺化空間中形狀的關鍵屬性。<br><br>對於進階使用者，可以自訂函式來設定相機和/或每像素的 3D 渲染。

</tr>
</table>

>[!INFO]
> 
> 欲了解更多涉及 SDF 函數的概念與工作流程，請前往專門頁面： [使用 SDF 函數](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-nodes-sdf-functions/working-with-sdf-functions.md)

<a name="inputs"></a>

## 輸入

|                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>環境</b> *顏色* | 應該投影到無限球體上的影像作為場景的環境，並用於環境光照。<br><br>投影為<i>等矩形</i>，與 Designer 預設環境貼圖相同的方式，該地圖在 3D View > HDRI 環境</b>類別中<b>可用。<br><br>未連接時則使用預設環境。<br><br><i>提示：</i>使用 HDR 影像（32 位元）以獲得精準光照。 |
| <b>輸入 1</b> *顏色* | 當<b>輸出</b>參數設為「自訂」時，可在自訂輸出</b>函數圖中取<b>樣的影像。<br><br>使用[設定為「影像輸入 0」的取樣色彩](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)節點，從此影像取樣。 |
| <b>輸入 2</b> *顏色* | 當<b>輸出參數設為「自訂」時，可取樣<b>於自訂</b>輸出函數圖中的影像。<br><br>使用[設定為「影像輸入 1」的取樣色彩](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)節點從此影像取</b>樣。 |

<a name="outputs"></a>

## 輸出

|               |                                                                                                                                                                                                                                    |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>產出</b> | 渲染後的場景，使用輸出參數中<b></b>選擇的 AOV。<br><br><i>注意：</i>為了在某些 AOV 中準確讀取，請確保 2D 視圖使用線性色彩空間，節點使用 HDR 32 位元輸出格式。 |

<a name="parameters"></a>

## 參數

|                                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:----------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>場景類型</b> *整數* | 用於描述要渲染的表面與形狀的函數類型：<br>- <b>SDF：</b> 使用帶號距離場（SDF）函數，能描述複雜形狀。<br>- <b>交集：</b> 使用交集函數，當只需簡單原始形狀時會更快。 |
| <b>SDF場景</b> *浮標* | 描述場景中表面與形狀的有符號距離場（SDF）函數。<br><br>請使用函式庫中 SDF 函數](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)類別中的[節點來撰寫函式。 |
| <b>交集場景</b> *浮標* | 描述場景中表面與形狀的交集函數。<br><br>簡單原語與運算子的交集函式可在 <b>3d_functions.sbs</b> 函式套件的<b>3d_intersection</b>資料夾中找到。<br><br><i>提示：</i>你可以將函式庫中任一 SDF 節點丟入檔案總管來存取該套件。 |
| <b>產出</b> *整數* | 節點應輸出的 3D 渲染類型，通常稱為 AOV（任意輸出變數）。<br><br>可用的 AOV 有：<br>- <b>美感：</b> 3D 渲染的最終結果，搭配藝術導向的色彩與效果。<br>- <b>法線 WS：</b> 場景中形狀的世界空間法線。<br>- <b>法線 TS：</b> 場景中形狀的切線空間法線。<br>- <b>位置：</b> 場景中形狀表面的世界空間位置。<br>- <b>距離：</b> 從相機到場景<br>中形狀的原始距離- <b>深度：</b> 形狀與相機目標平面有符號的距離，平面始終面向相機。<br>- <b>顏色：</b> 形狀的基底顏色（使用「Set color」節點在場景函式中指派形狀顏色）<br>- <b>材質 ID：</b> 套用到形狀表面的材質 ID（使用「設定材質 ID」節點在場景函式中指派材質 ID）<br>- <b>球體追蹤步驟：</b> 定義形狀表面所需步驟的視覺化。 亮度越高，則需要更多步驟。<br>- 自訂：</b>撰寫自訂函式來計算每像素渲染的顏色。<br><br><i>注意：</i>為了在某些 AOV 中獲得準確讀數，請確保 2D View 使用線性色彩空間，且節點使用 HDR 32 位<b>元輸出格式。 |
| <b>自訂輸出</b> *Float4* | 定義渲染場景每像素 RGBA 顏色的函式圖，作為 Float4 值。<br><br>可用變數：<br>- <code>scene.position</code> （Float3）場景表面的世界空間位置。<br>- <code>場景。法線</code> （Float3）場景表面的世界空間法線。<br>- <code>場景。命中</code> （布林值）當表面被相機射線<br>擊中時，回傳「真」。- <code>檢視。來源</code> （Float3）相機視圖的每像素世界空間位置。<br>- <code>視圖。方向</code> （Float3）根據投影模式，相機視圖的每像素向量。 (E.g. 透視或正字）<br>- <code>材質。顏色</code> （float3）場景表面的底色。<br>- <code>材質。金屬感</code> （漂浮）場景表面的金屬感。<br>- <code>材質。粗糙度</code> （漂浮聲）場景表面的粗糙感。<br>- <code>material.id</code> （整數）場景表面的材質識別。<br><br>節點的影像輸入可透過選擇以下 [取樣](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) 色彩節點槽進行取樣：<br>- <b>影像輸入 0</b> 取樣 輸入 1。<br>- <b>影像輸入 1</b> 取樣 輸入 2。 |
| <b>環境旋轉</b> *浮標* | 環境的旋轉<b></b>，以回合數計算。 |
| <b>背景模式</b> *整數* | 指定場景背景的來源，繪製於無形狀表面的地方。<br><br>- 顏色：</b>平面的「背景色」。<br>- <b>環境：</b>提供給「環境」輸入的影像，使用等矩形投影應用於<b>無限球體。（當輸入未連接時，則使用預設環境。） |
| <b>背景色</b> *Float4* | 場景背景使用的純色。 |
| <b>IBL 範例</b> *整數* | 每個相機取樣所執行的光取樣量。<br><br>較高的數值會帶來更平滑、更精確的照明，但代價是性能下降。 |
| <b>相機取樣</b> *整數* | 每像素所執行的相機取樣量。<br><br>此參數影響抗鋸齒品質及景深效果。<br><br>較高的數值會帶來更清晰、更少雜訊的影像，但代價是效能下降。 |
| <b>雷的行進步伐</b> *整數* | 球體追蹤過程（光線行進技術）中執行的步驟數，用於偵測與繪製形狀表面。<br><br>較高的數值會帶來準確且一致的表面（尤其是複雜形狀），但代價是效能下降。<br><br><i>提示：</i>將輸出</b>參數設<b>為「球體追蹤步驟」AOV，以視覺化需要更多步驟的形狀區域。這些地區將首先受到影響，減少步驟。 |
| <b>次要射線行進步</b> *整數* | 在球體追蹤過程中計算擴散與鏡面遮蔽以繪製投射陰影的步驟數。<br><br>較高的數值會帶來更精確的陰影，但代價是效能下降。 |
| <b>相機模式</b> *整數* | 將場景投影到渲染影像的方法：<br><br>- <b>透視：</b> 此投影傳達深度並啟用鏡頭效果，如景深。<br>- <b>正投影：</b> 此投影將場景平坦化，消除深度。<br>- <b>自訂函式：</b> 撰寫函數圖以設定自訂攝影機。 |
| <b>相機功能</b> *Float3* | 定義相機轉換的功能圖。 這可以用來設定自訂攝影機。<br><br>函式應 <b>設定</b> 以下變數：<br>- <code>view.origin</code> （Float3）相機視圖的每像素世界空間位置。<br>- <code>視圖。方向</code> （Float3）根據投影模式，相機視圖的每像素向量。 (E.g. 透視或正字<br><br>）可 <b>取得</b>以下變數：<br>- <code>camera.origin</code> （Float3）相機的世界空間位置。 （攝影機.方向 * camera_distance + 攝影機.目標）<br>- <code>攝影機.方向</code> （float3）相機的世界空間方向，也就是相機的Y向量。<br>- <code>相機。右</code> （Float3）相機的X向量<br>。- <code>攝影機上</code> （Float3）攝影機的Z-up向量。<br>- <code>攝影機。目標</code> （Float3）相機目標的世界空間位置。 |
| <b>紫外線位置</b> *Float2* | 在二維影像空間中，用來推斷攝影機位置及圍繞 <b>目標位置</b>的方向。<br><br><i>提示：</i> 此參數可透過 <i>選擇節點時 2D 視圖中可用的位置</i> 裝置直覺調整。 |
| <b>視野角</b> *浮標* | 正射相機的視野（FOV），這會影響變焦因子。 |
| <b>焦距</b> *浮標* | 相機的焦距會影響變焦因子和景深效果。 |
| <b>距離目標</b> *浮標* | 相機應該離 <b>目標位置</b>的距離。<br><br>調整此位置後，攝影機會沿著攝影機對目標的方向移動。 |
| <b>目標位置</b> *Float3* | 相機目標的位置，相機始終朝向該目標。 |
| <b>音色映射器</b> *整數* | 應應用於場景渲染的色調映射演算法。<br><br>- <b>無（Raw）<br>- <b>sRGB</b><br>- <b>AgX</b><br>- <b>ACES</b> |
| <b>啟用景深</b> *布林值* | 模擬透視相機的景深鏡頭效果。<br><br>使用 <b>光圈數</b> 和 <b>對焦距離</b> 參數分別調整效果的光圈和焦點。<br><br>結果也會受到焦距</b>的影響<b>。 |
| <b>F 編號</b> *浮標* | 相機的<i>光圈</i>。<br><br>數值越低，景深</i>越短<i>，也就是說，物體銳利的距離範圍變短，且隨著距離增加，模糊效果會更強。 |
| <b>對焦距離</b> *浮標* | 將焦點的距離設定為沿相機前向量的距離。<br><br>在該距離範圍內的表面會顯得銳利，而這個範圍—— <i>景深 </i> ——是由 <b>F數</b>定義的。 |
| <b>曝光（EV）</b> *浮標* | 到達相機感測器的光量，也就是渲染中光線強度。<br><br>值越低，渲染場景就會變暗。<br><br>「曝光值」（EV）特別指相機感光元件暴露<i></i>在多少光線下。 |
| <b>底色</b> *Float3* | 當該顏色未由其 SDF 或交集函數定義時，該表面的預設基底顏色。 |
| <b>粗糙度</b> *浮標* | 對於表面的預設粗糙度值，該值不是由其 SDF 或交集函數定義的。 |
| <b>金屬性</b> *浮標* | 當金屬度值未由其SDF或交函數定義時，該值的表面預設值。 |
| <b>輔助者的不透明度</b> *浮標* | 3D 輔助器的不透明度，值越低，輔助越暗。 |
| <b>包圍框架</b> *布林值* | 一個六邊形籠子的視覺化，界定整個場景的界限。 理想狀況下，應該是最小的尺寸，能完整包含整個場景。<br><br>使用 <b>包圍框架大小</b> 參數來調整籠子的大小。<br><br><b>Colorize out of frame</b> 參數讓你能輕鬆看到籠子外的表面，這會影響在 Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 節點中使用該場景[的結果。（參見「框架大小」工具提示） |
| <b>包圍框架大小</b> *Float3* | 設定包圍框架的 XYZ 大小。<br><br>調整你的場景幀，然後將相同的數值套用到 <b>Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 節點的 [SDF 綁定幀大小</b>參數，確保場景中所有形狀都正確包含並被該節點繪製。 |
| <b>從畫面外上色</b> *布林值* | 將紅色塗裝在包圍框架外的表面上。<br><br>這有助於檢查場景是否完全包含在其包圍框架中。 |
| <b>軸心國</b> *布林值* | 場景中 XYZ 軸的視覺化，以彩色線條從場景原點開始。 |
| <b>格網</b> *布林值* | 一個位於 XY 軸上的格網視覺化，其中 X 與 Y 中一個單元的大小為一個場景單元。 |
| <b>轉換輔助器</b> *布林值* | 這是最後一次應用旋轉的視覺化。<br><br>視覺化包括<br>- <b>一支箭頭</b> 代表旋轉軸方向向量，並依照每個世界空間軸的權重著色。<br>- <b>一條</b> 弧線代表旋轉角度，與箭頭顏色相符的正交方向。 |
| <b>SDF 等值線</b> *布林值* | 有符號距離場（SDF）函數等值線的彩色視覺化。<br><br>等值線是規則重複的線， <i>代表形狀在XY平面上給定高度下的距離場</i> 。<br><br>這些對於檢查 <i>由 SDF 函數定義的空間</i> 的均勻性非常有用。<br><br>利用 <b>SDF 等值線的頻率</b> 與 <b>等值線位置</b> 參數來調整等值線的密度與高度。 |
| <b>SDF 等值線頻率</b> *浮標* | 在一定距離內重複的等值線數量。<br><br>數值越高，線條越密集且越細。 |
| <b>SDF 等值線位置</b> *浮標* | 用來繪製等值線的 XY 平面的世界空間高度。<br><br>利用此方法檢查形狀在不同高度下的距離場。 |
| <b>敏。 命中距離</b> *浮標* | 定義SDF光線行進過程中轉為命中的最小距離。<br><br>數值越低，光線行進步數會增加。 |
