## 說明

從 [洪水填充](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/flood-fill/flood-fill.md) 基底生成灰階地圖，並將數值綁定於每個圖塊的個別大小。

數值是相對於整個畫布大小（全白磁磚會拉伸整個畫布），因此對比度通常較低。
