## 說明

允許你反轉法線貼圖中任何通道，提供快速且簡單的手動操作捷徑。

請記得，幾乎每個使用 Normalmap 作為輸入或輸出的節點，都有反轉 Green 通道的選項，適用於 DirectX 或 OpenGL 風格的法線貼圖。 這表示在這些情況下，你幾乎不需要這個節點。
