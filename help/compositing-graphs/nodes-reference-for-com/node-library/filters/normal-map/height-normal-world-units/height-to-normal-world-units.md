## 說明

一個進階的身高轉普通轉換節點，在轉換過程中會使用真實世界的單位。

當你知道來源高度圖的尺寸，並希望進行最精確的轉換時，例如處理掃描資料時，這很有用。

## 參數

* **表面尺寸（公分）：***0.0 - 1000.0*&#x200B;輸入高度圖的尺寸。
* **高度深度（公分）：***0.0 - 100.0*&#x200B;高度圖細節的最大深度。
* **一般格式**： *OpenGL、DirectX*\
  切換不同的法線貼圖格式（反轉綠色通道）。
* **取樣**： *標準，Sobel*&#x200B;在兩種取樣模式間切換以判定準確度。
