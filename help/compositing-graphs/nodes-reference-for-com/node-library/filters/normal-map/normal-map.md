# 法線貼圖

此類別僅包含用於處理與處理法線貼圖的節點。 當你想讓法線貼圖處理數學上正確，以避免切線空間問題時，這些工具是絕對必須的。

使用 <b>左側</b> 的導覽列表，瀏覽法線貼圖下的所有節點。

此類別中一些非常有用的節點包括：

* [普通聯合測試](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-combine/normal-combine.md)
* [諾曼·索貝爾](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-sobel/normal-sobel.md)
* [正常歸一化](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-normalize/normal-normalize.md)
