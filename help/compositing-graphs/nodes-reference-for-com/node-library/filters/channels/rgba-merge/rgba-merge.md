</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

在四個聲道中分別輸入一個灰階。 不要和 RGB-A 合併搞混，因為這個節點能讓你有更多合併控制！

非常實用的節點，可以把頻道地圖堆疊在一起。 例如，可以用來將 Smoothness、Metallic 和 AO 打包到各自的 R、G 和 B 通道中。
