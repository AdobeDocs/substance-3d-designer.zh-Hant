## 說明

將輸入影像分割成紅、綠、藍和 Alpha 通道。 實際上是「拆解」一張影像。

對於分析和分別使用壓縮頻道很有幫助。 例如，在 Substance Painter 中使用烘焙位置貼圖或烘焙的世界空間法線貼圖來做效果時，可以選擇 X、Y 或 Z 元件。
