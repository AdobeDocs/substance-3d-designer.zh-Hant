## 說明

移除 RGB 在 alpha 混合邊緣上的預先乘法色彩。 這實際上是「逆置」背景色，但過程中會剝離 alpha 通道。

這消除了有時在帶有 alpha 通道的影像邊緣出現的條紋效應。
