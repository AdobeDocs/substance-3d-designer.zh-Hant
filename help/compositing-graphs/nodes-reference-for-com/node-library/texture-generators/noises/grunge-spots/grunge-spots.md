## 參數

|  |  |
|:---|:---|
| <b>平衡</b> <i>浮標</i> | 調整明暗的平衡。 |
| <b>對比</b> <i>浮標</i> | 調整影像的對比度。 |
| <b>倒轉</b> <i>布林值</i> | 透過運算 `1-x` 反轉影像輸出。 |
| <b>非平方展開</b> <i>布林值</i> | 能以非平方比率補償擠壓與拉伸。 |
| <b>進階</b> |  |
| <b>詳情</b> <i>浮標</i> | 調整斑點變 *形* 和分割成細小位置的程度。 |
| <b>覆蓋範圍</b> <i>浮標</i> | 調整影像中斑點的覆蓋範圍。 |
| <b>覆蓋對比</b> <i>浮標</i> | 調整遮罩&#x200B;*的對比*&#x200B;度，用以控制影像中斑點的覆蓋範圍。 |
