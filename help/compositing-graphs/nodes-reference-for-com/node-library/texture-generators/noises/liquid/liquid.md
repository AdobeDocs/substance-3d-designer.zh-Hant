## 參數

|  |  |
|:---|:---|
| <b>規模</b> <i>1 - 128</i> | 設定了效果的全球尺度。 |
| <b>混亂</b> <i>0.0 - 1.0</i> | 相位偏移以引入小幅變化 |
| <b>曲速強度</b> <i>0.0 - 1.0</i> | 設定扭曲效果的強度。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
