## 說明

產生複雜的綜合噪聲圖。 這個節點作為詳細的程序檔非常有用，但要注意這些程序非常耗費效能，因此生成速度較慢。

## 參數

* **平衡**： *0.0 - 1.0*\
  它會像調整亮度一樣，將結果的平衡從黑到白。
* **對比**&#x200B;度： *0.0 - 1.0*\
  調整結果的對比度。
* **反轉**： *錯誤/真實*\
  結果會被反轉。
* **筆刷圖案**： *0.0 - 1.0*&#x200B;在邊緣加裝遮罩，作為筆刷 alpha 使用時使用。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
