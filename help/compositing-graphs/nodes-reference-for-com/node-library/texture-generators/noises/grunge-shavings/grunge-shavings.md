## 說明

## 參數

|  |  |
|:---|:---|
| <b>平衡</b> <i>浮標</i> | 調整明暗的平衡。 |
| <b>對比</b> <i>浮標</i> | 調整影像的對比度。 |
| <b>倒轉</b> <i>布林值</i> | 透過運算 `1-x` 反轉影像輸出。 |
| <b>非平方展開</b> <i>布林值</i> | 能以非平方比率補償擠壓與拉伸。 |
| <b>進階</b> |  |
| <b>刮痕數量</b> <i>浮標</i> | 刮痕的數量與 *覆蓋* 範圍，是用來產生刮屑的效果。 |
| <b>刮痕平鋪</b> <i>整數</i> | 刮痕效果的平鋪量，用來產生刨花。 |
| <b>塵埃強度</b> <i>浮標</i> | 表面覆蓋的灰塵強度。 |
| <b>銳利強度</b> <i>浮標</i> | 全球銳化效應的強度。 |
