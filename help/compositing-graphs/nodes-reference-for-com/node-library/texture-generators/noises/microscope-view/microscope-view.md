## 說明

這會產生一種扭曲的聲音，看起來像是顯微鏡下的細菌或生物。

## 參數

* **比例**： *0 - 10*\
  設定了效果的全球尺度。
* **曲速強度**： *0.0 - 1.0*\
  設定扭曲效果的強度。 記得你也可以選擇負數，雙擊輸入 -1。
* **無障礙**： *0.0 - 1.0*\
  相位偏移以引入小幅變化
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
