## 說明

這個節點會產生類似布料的噪音。 它可以解釋為高度圖

摺痕很適合需要半方向且有大尺度變化的噪音。

<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>規模</b> <i>1 - 8</i> | 設定了效果的全球尺度。 |
| <b>曲速強度</b> <i>0.0 - 128.0</i> | 設定彎曲/扭曲效果的強度。 |
| <b>混亂</b> <i>0.0 - 100.0</i> | 稍微偏移產生噪音的層次，以引入變化。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
