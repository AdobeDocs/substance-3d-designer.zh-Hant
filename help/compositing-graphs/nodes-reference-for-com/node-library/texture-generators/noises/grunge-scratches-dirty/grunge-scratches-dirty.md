## 參數

* **平衡***浮動*&#x200B;調整暗與亮之間的平衡。
* **對比***浮動*&#x200B;調整影像的對比度。
* **反演***布林運算*&#x200B;是透過一個`1-x`運算反轉影像的輸出。
* **非平方展開***布林*&#x200B;以非平方比率補償擠壓與拉伸。
* 進階
  * **基礎 Grunge Intensity** *Float*&#x200B;調整套用在基底表面的 grunge 地圖強度。
  * **刮痕強度***浮點*&#x200B;調整底面刮痕的強度。
