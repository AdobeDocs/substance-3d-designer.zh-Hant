## 說明

這是一個有趣的節點，會產生流動或下降的流體圖案。 它是較為複雜的噪音之一，包含幾個參數。

這種噪音填補了一個特定的領域：它能在重力效應下產生雨水、洩漏或任何類型的流體。

## 參數

|  |  |
|:---|:---|
| <b>規模</b> <i>1 - 8</i> | 設定了效果的全球尺度。 |
| <b>混亂</b> <i>0.0 - 1.0</i> | 透過相位移來引入微小的變化。 |
| <b>曲速強度</b> <i>0.0 - 1.0</i> |  |
| <b>圖案尺寸</b> <i>0.0 - 1.0</i> |  |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
