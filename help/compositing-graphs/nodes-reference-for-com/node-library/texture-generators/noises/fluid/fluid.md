## 說明

這是一個有趣的節點，會產生流動或下降的流體圖案。 它是較為複雜的噪音之一，包含幾個參數。

這種噪音填補了一個特定的領域：它能在重力效應下產生雨水、洩漏或任何類型的流體。

## 參數

* **比例**： *1 - 8*\
  設定了效果的全球尺度。
* **無障礙**： *0.0 - 1.0*\
  透過相位移來引入微小的變化。
* **曲速強度**： *0.0 - 1.0*
* **圖案尺寸**： *0.0 - 1.0*
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
