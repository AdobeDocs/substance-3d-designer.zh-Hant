## 參數

|  |  |
|:---|:---|
| <b>平衡</b> <i>浮標</i> | 調整明暗的平衡。 |
| <b>對比</b> <i>浮標</i> | 調整影像的對比度。 |
| <b>倒轉</b> <i>布林值</i> | 透過運算 `1-x` 反轉影像輸出。 |
| <b>非平方展開</b> <i>布林值</i> | 能以非平方比率補償擠壓與拉伸。 |
| <b>進階</b> |  |
| <b>覆蓋範圍</b> <i>浮標</i> | 調整土壤覆蓋範圍。 |
| <b>規模</b> <i>整數</i> | 調整泥土斑點的比例。 數值越&#x200B;*高，斑*&#x200B;點越細&#x200B;**。 |
