## 說明

這會產生一個複雜的綜合噪聲圖。 它作為詳細程序式非常有用，但要注意這類程序非常耗效能，因此生成速度較慢。

## 參數

|  |  |
|:---|:---|
| <b>平衡</b> <i>0.0 - 1.0</i> |  |
| <b>對比</b> <i>0.0 - 1.0</i> |  |
| <b>倒轉</b> <i>錯誤/真實</i> |  |
| <b>刷子圖案</b> <i>0.0 - 1.0</i> | 在邊緣加裝遮罩，方便用作刷子 alpha 使用。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
