## 說明

這會產生稍微不同的高斯雜訊](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/gaussian-noise/gaussian-noise.md)變體[，帶有較長的暗條作為谷。它也有類似的距離控制來維持平鋪。

## 參數

* **比例**： *1 - 128*\
  設定了效果的全球尺度。
* **無障礙**： *0.0 - 1.0*\
  透過相位移來引入微小的變化。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
