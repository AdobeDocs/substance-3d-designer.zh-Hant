## 說明

簡單的網狀圖案搭配粗塊。 可用來製作高度與細節地圖。

## 參數

* **鋪磚**： *1 - 16*\
  設定結果應該鋪磚的次數。
* **旋轉 45 度**： *假/真*&#x200B;旋轉結果。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
