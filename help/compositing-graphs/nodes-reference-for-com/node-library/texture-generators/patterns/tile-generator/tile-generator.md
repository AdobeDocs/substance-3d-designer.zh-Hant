## 說明

瓦片產生器是函式庫中最先進的節點之一。 如果你學會精通，就能創造任何模式（當然有一定限制）。 從 2017 版本 2.1 開始，有一些重大更新，讓這個節點更符合 [Tile Sampler](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-sampler/tile-sampler.md) 的功能。

這個節點在各種情境下都非常有用，但要注意，單純讀取參數並不能完全教你如何使用它們。 我們建議你也多做實驗！

在99%的情況下，彩色版本根本不需要！

一些一般使用建議：

* 你可以先從基本形狀開始，但如果你有自訂輸入（將 **圖案類型** 設定為 *影像輸入*），請先建立它！ 它決定了整體的外觀。
* 首先要正確設定你的X和Y數量。
* 找到合適的 **尺寸** 模式：相對模式如 **間隙** 模式的行為與 **絕對** 模式有很大不同。
* 接著調整全域 **縮放** 和非均勻 **大小** 。
* 最後，調整任何 **「變化」** 參數直到符合你的需求。 變化的關鍵在於細膩！

## 參數

### 輸入

* **圖案輸入 1-6**： *灰階輸入*\
  自訂圖案影像，當「圖案」參數設為「影像輸入」時使用。
* **背景**：*灰階輸入*&#x200B;背景，用來代替純色。

### 參數

* **X 金額**： *1 - 64*\
  圖案的X字重複次數。
* **Y金額**： *1 - 64*\
  該模式的Y字重複次數。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
* **模式**
  * **圖案**： *影像輸入、方形、圓盤、拋物面、鐘形、高斯分布、荊棘、金字塔、磚塊、漸變、波浪、半鐘形、脊狀鐘、新月形、膠囊、錐形*\
    選擇要使用的圖案形狀。
  * **圖案輸入編號**： *1 - 6*&#x200B;可使用的不同影像輸入數量。 僅在上方選擇影像輸入&#x200B;*時*&#x200B;才可用。
  * **模式輸入分布**： *隨機，依模式編號*&#x200B;若選擇多個影像輸入，如何從不同影像輸入中選擇。
  * **特定**&#x200B;模式： *0.0 - 1.0*\
    讓你可以改變所選圖案的形狀。 效果取決於所選的圖案。
  * **影像輸入過濾（僅限引擎>v4）：***雙線性 + Mipmaps，雙線性，最近*
  * **旋轉**： *0、90、180、270*&#x200B;將所有方塊以固定角度、90度步進進行全球旋轉。
  * **旋轉隨機**： *0.0 - 1.0*&#x200B;隨機旋轉一個格子，旋轉四個90度步數之一。
  * **五點反轉**： *假/真*&#x200B;每隔一格旋轉 90 度。
  * **對稱隨機**： *0.0 - 1.0*&#x200B;透過所選對稱隨機模式隨機鏡像特定圖案。 這個數值越高，鏡像的模式就越多。
  * **對稱隨機模式**： *水平 + 垂直，水平，垂直*&#x200B;當對稱隨機高於0時，決定鏡像行為。
* **規模**
  * ****&#x200B;尺寸模式&#x200B;**:***Normal - 間隙，Normal - 大小，保持比例，絕對，像素*設定圖案大小的一般行為。\
    正常 - 間隙（Interstice）讓你定義圖案元素之間的間隙。 它會受到 X 和 Y 的數量影響。\
    Normal - Size 讓你可以定義圖案元素的大小，不論縫隙大小。 它會受到 X 和 Y 的數量影響。\
    Keep Ratio 允許你設定受 X 和 Y 數量影響的大小，但兩者之間的 X 和 Y 比例保持不變。\
    絕對值讓你設定一個不會受 X 和 Y 影響的絕對大小。\
    像素可以設定絕對像素大小，不受 X 和 Y 數量影響。 改變解析度會影響元素的大小。
  * **中等大小**： *0.0 - 1.0*&#x200B;大小可以交替的欄與列為基礎調整。
  * **間隙 X/Y**： *0.0 - 1.0*&#x200B;僅在一般間隙大小模式下可用。 改變間隙間隙。 影響形狀之間的接縫，允許不像比例&#x200B;**那樣的非均勻控制**。
  * **尺寸（絕對/像素）：***0.0 - 1.0*\
    僅限於普通-間隙尺寸模式之外。 設定的尺寸不均勻，與 **比例**&#x200B;不同。
  * **比例**： *0.0 - 2.0*&#x200B;設定全局比例。
  * **比例隨機**： *0.0 - 1.0*&#x200B;設定每個格塊的全球比例變化。
  * **比例隨機種子**： *0 - 1000*&#x200B;偏移量 比例變化種子。
* **職位**
  * **偏移**&#x200B;量： *0.0 - 1.0*&#x200B;在每連續的列或列上逐步偏移整個圖案（行為取決於垂直偏移參數）。
  * **偏移隨機**： *0.0 - 1.0*&#x200B;隨機化行偏移。
  * **偏移隨機種子**： *0 - 1000*&#x200B;改變隨機偏移效果的相對種子。
  * **垂直偏移***：假/真*&#x200B;集合，無論偏移效果發生在列或直線上;水平或垂直。
  * **位置隨機**： *0.0 - 1.0*&#x200B;以非均勻方式隨機定位，X 與 Y 分別控制。
  * **全域偏移**&#x200B;量： *0.0 - 1.0*&#x200B;將整個結果移至X軸與Y軸。
* **旋轉**
  * **旋轉**： *0.0 - 1.0*&#x200B;對所有圖案方塊進行均勻自由旋轉。
  * **旋轉隨機**： *0.0 - 1.0*&#x200B;隨機化所有地塊的自由旋轉。 這個數值越高，可以旋轉的地塊就越多。
* **顏色**
  * **顏色**：*（灰階值）*設定圖塊純色。
  * **亮度/顏色隨機**： *0.0 - 1.0*&#x200B;引入每格顏色或亮度的變化。
  * **按數字**&#x200B;的亮度： *假/真*&#x200B;會使整個圖案的亮度逐漸淡出。
  * **按比例***的亮度：錯誤/真*&#x200B;表示亮度變化會依地塊比例而異。
  * **棋盤遮罩**： *偽/真*&#x200B;隱藏每隔一格。
  * **水平遮罩**： *假/真*&#x200B;隱藏每隔一欄。
  * **垂直遮罩**： *假/真*&#x200B;每隔一列隱藏一次。
  * **隨機遮罩**： *0.0 - 1.0*&#x200B;隨機隱藏地塊。 這個數值越高，消失的地塊就越多。
  * **反轉遮罩**： *假/真*&#x200B;反轉本區段中任何遮罩效果的結果。
  * **混合模式**： *新增、最大、新增字幕*&#x200B;設定使用哪種混合模式。
  * **背景色**：*（灰階值）*設定為純色背景色。
  * **全域不透明度**： *0.0 - 1.0*&#x200B;設定全域磚塊不透明度。
  * **反向渲染順序**： *False/True*&#x200B;會將圖塊從前到後或反過來渲染。
