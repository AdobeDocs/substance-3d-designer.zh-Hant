## 說明

建立由兩個自訂點以圓形方式定義的灰階漸變。 這個轉換不是從 a 到 b 的，而是圍繞第一點的旋轉，從第二點開始並結束。 請記住，結果永遠不會是磁磚。

</td>
</tr>

<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>第一點</b> | 繞梯度旋轉的第一個點，不一定要居中 |
| <b>第二點</b> | 梯度的第二個起點和終點。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 以非平方比率補償擠壓與拉伸。 |
