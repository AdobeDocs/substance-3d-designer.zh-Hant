## 參數

|  |  |
|:---|:---|
| <b>側線</b> <i>3 - 32</i> | 配菜數量。 |
| <b>規模</b> <i>0.0 - 1.0</i> | 設定全球規模。 |
| <b>旋轉</b> <i>0.0 - 1.0</i> | 旋轉整個形狀。 |
| <b>曲線</b> <i>-1.0 - 1.0</i> | 修改梯度剖面曲線。 |
| <b>梯度</b> <i>0.0 - 1.0</i> | 調整漸變對比度。 |
| <b>反轉梯度</b> <i>錯誤/真實</i> | 反轉梯度方向。 |
| <b>自動秤</b> <i>錯誤/真實</i> | 預設設定時可以縮放到畫布裡。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
