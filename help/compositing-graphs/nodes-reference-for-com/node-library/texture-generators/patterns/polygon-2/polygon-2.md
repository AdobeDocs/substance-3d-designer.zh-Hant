## 說明

產生平滑的漸層多邊形形狀，並可調整選項。 請參見 [Polygon 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md) 以獲得更進階的版本。

## 參數

* **配菜**&#x200B;數量： *3 - 32*&#x200B;配對數量。
* **比例**： *0.0 - 1.0*&#x200B;設定全局比例。
* **旋轉**： *0.0 - 1.0*&#x200B;旋轉整個形狀。
* **曲線**： *-1.0 - 1.0*&#x200B;修改梯度剖面曲線。
* **漸變**： *0.0 - 1.0*&#x200B;調整漸變對比度。
* **反演梯度**： *假/真 反*&#x200B;轉梯度方向。
* **自動縮放**： *預設設定下，假/真*&#x200B;縮放以符合畫布大小。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
