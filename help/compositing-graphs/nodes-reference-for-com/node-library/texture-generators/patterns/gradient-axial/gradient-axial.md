## 說明

在兩個自訂定義點之間建立灰階漸變。 允許在任意角度產生線性漸層，但要注意結果不一定都會平鋪。

## 參數

|  |  |
|:---|:---|
| <b>第一點</b> | 從（黑色）開始的第一個點 |
| <b>第二點</b> | 第二個點結束漸層點（白色） |
| <b>非平方展開</b> <i>錯誤/真實</i> | 以非平方比率補償擠壓與拉伸。 |
