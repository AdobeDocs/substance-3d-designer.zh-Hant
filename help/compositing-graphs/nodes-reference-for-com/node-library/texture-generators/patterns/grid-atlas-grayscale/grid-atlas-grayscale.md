# 格網圖集灰階

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![格狀圖集灰階圖示](grid-atlas-grayscale.resources/grid-atlas-grayscale.png "格網圖格灰階")

<b>收錄於：</b> Generator > Pattern

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

在可調整的 XY 尺寸格子上，最多可打包 16 張灰階影像。<br>輸出的圖集影像可由 [Shape splatter v2](../shape-splatter-v2/shape-splatter-v2.md) 或 [Shape 濺射映射器灰階](../shape-splatter-v2-mapper-grayscale/shape-splatter-v2-mapper-grayscale.md) 節點取樣。

另 [見格點圖集顏色](../grid-atlas-color/grid-atlas-color.md)。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

|                                   |                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>網格大小 X</b> *整數* | X 軸格網大小。<br>也就是說，X 軸上被壓縮的影像數量。 |
| <b>格子大小 Y</b> *整數* | Y 軸格網大小。<br>也就是 Y 軸被壓縮的影像數量。 |
| <b>輸出大小模式</b> *整數* | 根據節點的「輸出大小」基礎參數定義輸出影像大小的方法：<br><br>- 手動：</b>直接使用大小。<br>- <b>自動比率：</b>根據格點大小調整影像比例以最小<b>化影像大小。對於使用三列或三列的非方格網格，例如（3， 2）， （4， 3） |
