## 說明

簡單的纖維狀圖案。 可用於  [Substance 3D Designer](https://www.adobe.com/tw/products/substance3d-designer.html) 中，用於繩索、網格或布料的高度圖與細節。

## 參數

* **鋪磚**： *1 - 16*\
  設定結果應該鋪磚的次數。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
