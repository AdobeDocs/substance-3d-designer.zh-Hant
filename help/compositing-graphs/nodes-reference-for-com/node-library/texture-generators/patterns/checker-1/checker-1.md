## 說明

非常簡單的棋盤格圖案。 磁磚刻意設得很低，讓它看起來盡可能通用。

由於其明顯的對比與平鋪，這種模式對測試案例非常有用。

</td>
</tr>

<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>鋪磚</b> <i>1 - 16</i> | 設定結果應該鋪磚的次數。 |
| <b>旋轉45度</b> <i>錯誤/真實</i> | 整個圖案旋轉45度。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
