<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>鋪磚</b> <i>1 - 16</i> | 設定結果應該鋪磚的次數。 |
| <b>梯度填充單元</b> <i>錯誤/真實</i> | 轉為銳利邊緣，製作銳利的六角形瓷磚。 |
| <b>間隙寬度</b> <i>0.0 - 1.0</i> | 只有當上述選項設為「False」時才有效。 間隙大小改變。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
