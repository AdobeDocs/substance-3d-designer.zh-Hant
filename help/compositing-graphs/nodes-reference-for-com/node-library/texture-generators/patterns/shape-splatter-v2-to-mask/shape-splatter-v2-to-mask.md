# 從 Shape Splatter v2 轉為遮罩

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![形狀濺射 v2 到遮罩圖示](shape-splatter-v2-to-mask.png "從 shape splatter v2 轉為遮罩")

<b>收錄於：</b> Generator > Pattern

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

從 Shape splatter v2 節點產生[的一系列形狀中計算出遮罩。<br><br>可用選項包括隨機選擇，以及依據獨特識別碼和/或材質 ID/圖案 ID* 選擇形狀範圍。<br><br>形狀會由 Shape splatter v2](../shape-splatter-v2/shape-splatter-v2.md) 節點預先遮罩[，根據<i>形狀高度與背景高度的高度混合</i>。](../shape-splatter-v2/shape-splatter-v2.md)<br>背景和未選取的形狀都是純黑色。 （即值為 0）<br><br><b>*：</b> 從 Shape splatter UVW 輸入中取得的其中一個值是材質 ID 或圖案 ID，視 Shape splatter v2 節點中使用的形狀類型</b>而定<b>：<br>- <i>SDF/primitive</i>：材質 ID<br>- <i>圖案輸入/格網圖集：</i>圖案 ID，即列表/圖集中圖案的索引。

</td>
</tr>
</table>

<a name="inputs"></a>

## 輸入

|                             |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>濺射 UVW</b> *顏色* | <b>R</b> - 形狀 UV 的 U 分量。<br><b>G</b> - 圖形 UV 的 V 分量。<br><b>B</b> - 圖形的高度。 （W）<br><b>A</b> - 打包資料：<br>- <i>整數部分：</i> 形狀的唯一識別碼。 （ID）<br>- <i>分數部分：</i>依形狀類型</b>而定<b>：若為SDF/原始材料ID，若為模式輸入/網格圖集則為圖案ID*。<br><br><b>*：</b>模式ID為列表/圖集中中形狀的索引。 |

<a name="outputs"></a>

## 輸出

|               |                                           |
|:--------------|:------------------------------------------|
| <b>產出</b> | 計算出所選形狀的遮罩。 |

<a name="parameters"></a>

## 參數

|                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>產出</b> *整數* | 輸出遮罩中選取的形狀所使用的數值。<br><br>- <b>二元遮罩：</b> 選取的形狀皆使用1的值。<br>- <b>形狀識別碼（整數）：</b> 所選形狀使用其唯一識別碼。 （ID）<br>- <b>材料 ID（整數）：</b> 選取的形狀使用其材質 ID。<br>- <b>形狀 ID（標準化）：</b> 所選形狀使用其唯一識別碼（ID），映射為 [0,1] ，範圍從最低選中 ID 到最高。<br>- <b>材料 ID（正規化）：</b> 選取的形狀使用映射為 [0,1] 的材質 ID，範圍從最低選擇材料 ID 到最高。 |
| <b>形狀識別碼起始範圍</b> *整數* | 作為選取範圍起始的形狀唯一識別碼（ID）。 （包含） |
| <b>形狀識別碼端域</b> *整數* | 作為選取範圍末尾的形狀唯一識別碼（ID）。 （包含） |
| <b>形狀 ID 偏移</b> *整數* | 在選取範圍內，將形狀的唯一識別碼偏移為指定值。<br><br>這讓在不手動調整起始與結束邊界的情況下，就能輕鬆將當前選取偏移至指定值。 |
| <b>材質/圖案識別遮罩組合</b> *整數* | 指定邏輯運算子，將唯一識別碼（ID）選擇與材料 ID/圖案 ID 選擇結合。<br><br>- 無：</b>選擇時完全忽略材料 ID/圖案 ID。<br>- <b>AND：</b>選取的形狀必須同時包含在 ID 與材料 ID/<b>圖案 ID 範圍內。（包含較少形狀）<br>- <b>或：</b> 選取的形狀必須包含在 ID 或材質 ID/圖案 ID 範圍內。 （包含更多形狀） |
| <b>材料/圖案識別碼起始範圍</b> *整數* | 選取範圍的起始是材質 ID 或圖案 ID*。 （包含）<br><br><b>*：</b> 詳情請參見節點描述。 |
| <b>材料/圖案識別碼的終端範圍</b> *整數* | 材料 ID 或圖案 ID* 作為選擇範圍的末端。 （包含）<br><br><b>*：</b> 詳情請參見節點描述。 |
| <b>形狀隨機遮罩</b> *浮標* | 一個形狀隨機遮罩的因子，其中 1 表示所有形狀都被遮罩。 |
