## 說明

以 [Splatter](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter/shape-splatter.md) Data 作為輸入，產生色彩或灰階貼圖。

## 參數

* **背景色**： *色彩輸入*
* **模式1-8**： *色彩輸入*
* **色彩輸入**： *色彩輸入*
* **濺射資料1**： *色彩輸入*
* **濺血資料 2**： *色彩輸入*

### 參數

* **圖案編號**： *1 - 8*
* **隨機圖案分配（僅限顏色）：***0.0 - 1.0*
* **&#x200B; 是法線貼圖 &#x200B;**（僅色彩）**&#x200B;**： *真/假*
* **HSL/亮度調整**： *-1.0 - 1.0*
* **HSL/亮度隨機**： *-1.0 - 1.0*
* **&#x200B;正常角度隨機 &#x200B;**（僅彩色）**&#x200B;**： *0.0 - 1.0*
* **色彩輸入不透明度**： *0.0 - 1.0*
