## 參數

|  |  |
|:---|:---|
| <b>鋪磚</b> <i>1 - 16</i> | 設定結果應該鋪磚的次數。 |
| <b>邊緣光滑度</b> <i>0.0 - 1.0</i> | 在銳利與光滑的邊緣間融合。 |
| <b>間隙寬度</b> <i>0.0 - 1.0</i> | 設定間隙（間隙大小）。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
