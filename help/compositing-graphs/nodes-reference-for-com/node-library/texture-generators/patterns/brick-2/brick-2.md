## 說明

簡單磚塊圖案，請參見 [磚塊生成器](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/brick-generator/brick-generator.md) 或 [磚塊生成器](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md) 以獲得更多選項。

## 參數

* **鋪磚**： *1 - 16*\
  設定結果應該鋪磚的次數。
* **邊緣平滑度**： *0.0 - 1.0*&#x200B;在粗糙與光滑邊緣之間融合。
* **間隙寬度**： *0.0 - 1.0*&#x200B;設定間隙（間隙大小）。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
