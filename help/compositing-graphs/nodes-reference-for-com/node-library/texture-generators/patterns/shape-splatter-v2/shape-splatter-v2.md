## 說明

在背景高度表面上散佈形狀，具備虛擬三維空間</b>中進階散射<b>功能，並具備位置、旋轉、縮放與隨機性的控制。<br><br>該節點提供基本的原始三維形狀，並支援自訂形狀，提供圖案影像、圖集<b></b>或作為有符號距離場（SDF）</b>函數，用於複雜自訂三維形狀。<b></b><b><br><br>有多種 <b>分配形狀</b> 的方法，包括撰寫自訂函數以實現完整控制。<br><br>形狀可利用自訂 <b>密度地圖</b>拉向特定區域。<br><br><i>注意：</i> 此節點不適用於 Substance 引擎的 CPU 版本，例如 SSE2（Windows、Linux）和 NEON（macOS）。

## 輸入

|                                      |                                                                                                                                                                                                                                                                                                                                                                  |
|:-------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>背景高度</b> *灰階* | 形狀散布的基底高度圖。 每個高度會用「最大混合」組合，選較高者。<br><br>背景高度對輸出高度的貢獻由 <b>背景輸入不透明度</b> 參數控制。 |
| <b>密度地圖</b> *灰階* | 這是一張灰階地圖，根據亮度驅動形狀的位移，形狀聚集在其較亮的區域。<br><br>形狀位移的強度由 <b>密度映射乘數</b> 參數控制。 |
| <b>高度偏移圖</b> *灰階* | 一個灰階地圖，根據形狀的樞軸位置均勻地加值。<br><br>地圖的貢獻由 <b>高度偏移地圖乘</b> 數參數控制。 |
| <b>高度比例圖</b> *灰階* | 一個灰階地圖，其數值作為形狀高度的因子。<br><br>地圖的貢獻由 <b>高度尺度地圖乘</b> 數參數控制。 |
| <b>形狀尺度圖</b> *灰階* | 一個灰階地圖，其數值用來決定形狀的縮放。<br><br>地圖的貢獻由 <b>比例地圖乘</b> 數參數控制。 |
| <b>形狀旋轉</b> *灰階* | 一個灰階地圖，其數值會加到形狀的三維旋轉中，並由三維旋轉地圖乘數</b>參數提供的<b>每軸因子調整。 |
| <b>向量映射</b> *顏色* | 一個描述方向向量的地圖，可用來驅動形狀的旋轉和/或位置，並使用以下參數：<br><br>- <b>向量地圖位移</b> 調整圖形移動時的效果。<br>- <b>斜率旋轉輸入</b> 可設定為「向量地圖」，利用此地圖利用相關參數旋轉形狀。 |
| <b>遮罩映射</b> *灰階* | 用於遮罩 <b>形狀的影像依照遮罩映射閾值</b>。<br><br>也就是說，位於亮度低於該閾值的區域的形狀會被遮罩。 |
| <b>模式輸入 1</b> *灰階* | 當 <b>圖案類型</b> 設為「圖案輸入」時，#1 圖案被散射的高度圖。<br><br><i>提示：</i> 使用接近圖案在散射時可能擁有的最大大小的解析度。 |
| <b>模式輸入 2</b> *灰階* | 當 <b>圖案類型</b> 設為「圖案輸入」時，散布的 #2 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案可能最大大小的解析度。 |
| <b>模式輸入 3</b> *灰階* | 當 <b>圖案類型</b> 設為「圖案輸入」時，散布的 #3 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案最大大小的解析度。 |
| <b>模式輸入 4</b> *灰階* | 當 <b>Pattern 類型</b> 設為「Pattern input」時，散布的 #4 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案最大大小的解析度。 |
| <b>模式輸入 5</b> *灰階* | 當 <b>圖案類型</b> 設為「圖案輸入」時，散射的 #5 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案最大大小的解析度。 |
| <b>模式輸入 6</b> *灰階* | 當 <b>Pattern 類型設為「Pattern input</b> 」時，散射的 #6 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案最大大小的解析度。 |
| <b>模式輸入 7</b> *灰階* | 當 <b>Pattern 類型</b> 設為「Pattern input」時，散射的 #7 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案最大大小的解析度。 |
| <b>模式輸入 8</b> *灰階* | 當 <b>圖案類型</b> 設為「圖案輸入」時，散布的 #8 圖案的高度圖。<br><br><i>提示：</i> 使用接近散射圖案可能最大尺寸的解析度。 |
| <b>格網圖集高度</b> *灰階* | 描述圖譜中圖案高度的圖片。<br><br>使用 <b>格網圖集大小</b> 參數來指定圖集的網格大小。 |
| <b>格點圖譜法線</b> *顏色* | 這張圖片描述了裝在圖冊中圖案的法線。<br><br>使用 <b>格網圖集大小</b> 參數來指定圖集的網格大小。 |

## 參數

|                                                   |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:--------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>位置分配模式</b> *整數* | 空間中形狀分布的方法：<br><br>- <b>二維格網：</b> 一種簡單的均勻格網。<br>- <b>泊松圓盤：</b> 一種模擬，旨在隨機偏移格子，以防止重疊，同時利用可用空間。<br>- <b>均勻分布：</b> 均勻分布指定數量的形狀。 需要更密集的計算。<br>- <b>自訂函數：</b> 撰寫函數圖以定義形狀分布。 可用變數列於節點描述中。 |
| <b>位置函數</b> *Float2* | 函數圖用於定義形狀分布。<br><br>該圖會輸出影像中形狀的 XY 正規化位置的 Float2 值。<br><br>可用變數：<br>- <code>shape.id</code> （漂浮）這個形狀的唯一識別碼。<br>- <code>形狀。數量</code> （浮點）由 <b>數量</b> 參數指定的形狀數量。 |
| <b>X 金額</b> *整數* | 分配網格中的欄位數量。<br><br>也就是在 X 軸上產生的形狀數量。 |
| <b>Y金額</b> *整數* | 分配網格中的列數。<br><br>也就是在 Y 軸上產生的形狀數量。 |
| <b>金額</b> *整數* | 產生的形狀數量。 |
| <b>輸出標準格式</b> *整數* | 輸出法線貼圖的格式。<br><br>實際上是反轉綠色通道。<br><br>- <b>DirectX：</b> Y軸指向上方。<br>- <b>OpenGL：</b> Y軸指向下方。 |
| <b>非平方展開</b> *布林值* | 在非正方形影像中，會保留形狀的比例，並將它們的生成擴展到影像的邊界。 |
| <b>形狀類型</b> *整數* | 有多種形狀可供散布，每種形狀都有其特定特徵。<br><br><b>SDF 函數</b>是一個函數圖，用來產生一個描述三維形狀表面的帶號距離場（SDF）。這使得複雜程序形狀能動態變化的三維散射成為可能。<br><br><b>使用簡單光線/曲面交集函數計算的基本形狀</b>已準備好使用：立方體、球體、圓柱體、平面、圓盤<br><br><b>。輸入圖案</b> 由圖形提供影像。 這些圖案被映射到平面，並可 <i>擠</i> 出成三維形狀：<br>- 影像輸入：連接於 <b>圖案輸入 #</b> 輸入腳位的圖案。<br>- 格狀圖集：將圖案打包到與 <b>格網圖集</b> 輸入連接的圖譜影像中。 |
| <b>網格圖集大小</b> *整數2* | 圖集中提供給 <b>格網圖集</b> 影像輸入的行數和列數。<br><br><i>注意：</i> 圖集中空格會導致形狀分布出現空隙。 |
| <b>重新計算格點圖集法線</b> *布林值* | 當為真時<i>，提供給<b>格網圖集法線</b>影像輸入的法線貼圖會被忽略，並提供給<b>格網圖集高度</b>的圖案法線圖則從零</i>計算。<br><br>若為 <i>False</i>，則直接使用提供給 <b>Grid Atlas 法線</b> 的法線貼圖。<br><br><i>注意：</i> 法線強度會根據 <b>Shape 擠出高度</b>調整。 |
| <b>格網圖集正規格式</b> *整數* | 提供給 <b>格網圖集法線</b> 影像輸入的法線貼圖格式。<br><br>實際上是反轉綠色通道。<br><br>- <b>DirectX：</b> Y軸指向上方。<br>- <b>OpenGL：</b> Y軸指向下方。 |
| <b>模式輸入號碼</b> *整數* | 輸入影像提供的圖案數量。<br><br>在節點上增加盡可能多 <b>的 Pattern 輸入 #</b> 輸入腳位。 |
| <b>啟用形狀擠出</b> *布林值* | 透過將輸入圖案解讀為高度圖來切換擠出，從而產生複雜的程序化 3D 形狀。 |
| <b>形狀擠出對稱性</b> *布林值* | 使輸入圖案能前後對稱擠出。<br><br>對稱軸是擠出 <i>的中點</i>，意即其位置可能隨形狀的樞軸位置而改變。 |
| <b>形狀擠出高度</b> *浮標* | 影像空間中擠出的最大距離，其中 1 是影像的最長邊。<br><br>這個距離是根據 <b>Shape 的縮放</b> 值來縮放的。 |
| <b>形狀擠出樣品</b> *整數* | 為繪製輸入圖案的擠出而進行的樣本數量。<br><br>越多的樣本越多，擠出越平滑、更明確，但會犧牲部分效能。 |
| <b>模式函數</b> *浮標* | 作者所繪的 Substance 函數圖用於計算映射到 3D 平面 SDF 的圖案。<br><br>這些圖案也可透過使用 <b>Enable shape extrude</b> 來擠出。 |
| <b>模式 SDF 功能</b> *浮標* | Substance 函數圖，負責描述空間中三維物體表面的有符號距離場（SDF）。<br><br>瀏覽函式庫中內建的 [SDF 函](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions) 式集合，透過結合多個 SDF <i>原語</i> ，利用可用的 <i>運算子</i> 與 <i>轉換</i>來撰寫複雜物件。<br><br>SDF 形狀完全是程序化的，且可動態調整，使每個散布形狀皆具 <i>獨特</i>性。<br><br>使用 [3D 檢視](../../../filters/effects/3d-viewer/3d-viewer.md) 節點來視覺化 SDF 函數的結果。<br><br><i>注意：</i> 若要在 SDF 函式中應用隨機性，請使用 [Hash](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#random) 節點而非「隨機」。 |
| <b>SDF 邊界框架大小</b> *Float3* | 定義 SDF 形狀的最大包圍框（Bbox）大小，進而用以計算其 2D Bbox。<br><br>圖形僅在其 2D Bbox 範圍內繪製，其餘部分會被裁剪。 |
| <b>啟用切斷</b> *布林值* | 切換裁剪圖案，忽略所有低於 <b>Cutout 閾</b>值的數值。 這樣可以確保只使用所需的圖案輪廓。 |
| <b>切斷閾值</b> *浮標* | 灰階值下方會裁掉圖案中的數值。 也就是說，作為圖案輪廓邊框的數值。 |
| <b>標準化工作流程</b> *布林值* | 開啟時，能自動調整形狀高度，使其 <i>在放大或縮小時保持原始比例</i> 。<br><br>關閉時，形狀的高度會以影像的完整高度範圍表示，無論其原始比例如何。<br><br>形狀高度仍可透過高度 <b>比例</b> 參數手動調整。 |
| <b>形狀比例會影響身高比例</b> *布林值* | 當 <i>為真</i>時，形狀的高度比例會隨著比例變化而調整，以維持其比例。<br><br>當為假</i>時<i>，高度尺度與形狀尺度無關，導致變形。 |
| <b>身高比例</b> *浮標* | 形狀高度的乘數，其中 1 是形狀的全高度，表示為形狀正規化高度範圍的全高度範圍。 （參見 <b>正規化工作流程</b>） |
| <b>身高隨機</b> *浮標* | 隨機將每個形狀的高度縮放到指定的比例，其中 1 代表可以完全縮放到 0。 |
| <b>高度尺度地圖乘數</b> *浮標* | 所提供的 <b>高度比例地圖</b>強度，1 表示完整地圖值與形狀高度相乘。 |
| <b>背景輸入不透明度</b> *浮標* | 最終高度圖中提供的 <b>背景高度</b> 輸入的強度。<br><br>形狀與背景的高度會使用「最大混合」組合，使用較高的那個。 |
| <b>高度與背景的偏移</b> *浮標* | 應該加的背景高度與形狀高度的比例，1 表示會加上整個背景高度。<br><br>這可以用來讓形狀「停靠」在背景高度上。 |
| <b>符合背景</b> *浮標* | 變形強度對形狀高度施加，以匹配每像素背景高度，其中 1 表示完全匹配。<br><br><i>注意：</i> 當 <b>高度偏移與背景</b> = 0 時，此參數不影響。 |
| <b>平滑的背景斜率</b> *浮標* | 平滑強度應用於背景高度，用於 <b>背景高度偏移</b> 與 <b>從背景</b> 調整。<br><br>這會軟化變形頻率和高度偏移，這可能比預期更嚴重。 |
| <b>高度偏移</b> *浮標* | 一個加在形狀高度上的值，導致直線偏移。<br><br>該數值以影像的全高度範圍表示。 |
| <b>高度偏移隨機</b> *浮標* | 對形狀高度施加隨機偏移，直到指定值為止。<br><br>該數值以影像的全高度範圍表示。 |
| <b>身高與內標的偏移</b> *浮標* | 偏移量依分布中形狀的指數對其高度施加，偏移量從一個形狀線性增加到下一個形狀，直到指定值。<br><br>數值可以手動設定超過 <code>[0、1]</code> 範圍。 |
| <b>高度偏移地圖乘數</b> *浮標* | 利用指定因子調整高度偏移映射</b>所施加<b>的偏移強度，其中 1 表示映射上的強度值是直接套用的。<br><br>整個形狀的高度會透過在偏移映射中 XY 樞軸位置加值來偏移。<br><br>乘數值可以手動設定超過 <code>[0、1]</code> 範圍。 |
| <b>尺寸模式</b> *整數* | 定義散佈形狀大小的方法：<br><br>- 自動：</b>大小以形狀單元大小的因子表示。<br>- <b>絕對（紋理空間）：</b>大小以影像最長邊<b>的因子表示。 |
| <b>保持體型比例</b> *布林值* | 調整形狀大小，以保留非方格格線與影像尺寸的原始比例。 |
| <b>形狀尺度</b> *浮標* | 形狀的大小由尺寸模式</b><br><br><i>定義<b>。注意：</i>使用<b>泊松圓盤</b>分布時，調整形狀大小會使形狀移動以利用可用空間。使用 <b>Shape scale post Poisson</b> 參數來調整形狀。 |
| <b>形狀尺度隨機</b> *浮標* | 將形狀隨機縮放至指定值，1 可能使某些形狀縮放到零。 |
| <b>比例地圖乘數</b> *浮標* | 形狀縮尺中數值 <b>相乘的強度會與形狀大小相映</b> 成趣。 |
| <b>泊松之後的形狀尺度</b> *浮標* | 泊松圓盤模擬後，會應用一個比例因子。 |
| <b>形狀大小</b> *Float3* | 每個軸線分別設定比例因子，用來調整形狀大小。 |
| <b>形狀大小隨機</b> *Float3* | 將形狀以隨機</i>因子<i>縮放到指定值，1 可能導致部分形狀縮放至零。 |
| <b>汽缸半徑</b> *浮標* | 散射圓柱體SDF的半徑。 半徑以尺寸模</b>定義<b>的因子表示。 |
| <b>形狀大小</b> *Float2* | 每個軸線分別設定比例因子，用來調整形狀大小。 |
| <b>形狀大小隨機</b> *Float2* | 將形狀以隨機</i>因子<i>縮放到指定值，1 可能導致部分形狀縮放至零。 |
| <b>位置隨機</b> *浮標* | 在XY軸上施加隨機偏移，直到指定值為1，其中1是影像最長邊的長度。 |
| <b>位置隨機乘數</b> *Float2* | 每個軸上對 XY 軸形狀施加隨機偏移的因數。 |
| <b>位置分布序列</b> *整數* | 用於均勻分布形狀於空間中的演算法。 <br><br>- <b>R2</b>：基於黃金比例。 它速度快，無論形狀數量多少，都能提供更均勻且看似隨機的分布。<br>- <b>哈頓</b>：基於質數。 它對稀疏分布效果很好，但隨著形狀數量增加，速度會變慢，且可能出現可見線條。<br><br>這些演算法被稱為 <i>準隨機</i> 與 <i>低差異</i>，因為它們遵循確定性序列（準隨機），旨在均勻覆蓋空間（低差異）。 |
| <b>密度映射乘數</b> *浮標* | 一個偏移因子，讓形狀聚集在密度貼圖</b>中<b>最亮的區域。 |
| <b>法線偏移</b> *浮標* | 這些形狀沿著其法線——即局部 Z 軸——位移。 |
| <b>偏移量沿正常隨機</b> *浮標* | 會隨機地在形狀的法線上增加一定數量的位移。<br><br>隨機金額可以是正數或負數，直到指定值，也可以是負數。 |
| <b>向量地圖位移</b> *浮標* | 這是透過將向量映射</b>中的 <b>RGB 值分別加到形狀的 XYZ 座標，來施加位移的因子。<br><br>位移以影像最長邊的因子表示。<br>例如： RGB 值為 （0.5， 0.5， 0） 則會將形狀沿 X 軸和 Y 軸的大小減半。<br><br>參數值為 1.0 則表示加總值。 |
| <b>向量位移乘數</b> *Float3* | 在每個軸上調整 <b>向量貼圖位移</b> 的因子，0.0 表示該軸不施加位移。 |
| <b>全域偏移</b> *Float2* | 在任意</i>高度偏移、隨機偏移及其他位移後，會對每個形狀<i>的位置施加偏移。<br><br>這表示使用此參數移動形狀不會改變其位置、方向與縮放。 |
| <b>線位偏移</b> *浮標* | 依照線位偏移模式，套用在格子 <b>上的形狀線條上。</b> |
| <b>線位偏移模式</b> *整數* | 將線位偏移</b>應用<b>於形狀的方法。<br><br><b>All</b> 方法將偏移量以影像最長邊的因子（即貼圖空間中）為單位。<br>- <b>All - 水平：</b>逐步以列索引的因子水平相加。<br>- <b>All - 垂直：</b>逐欄垂直遞增偏移值，以欄索引的因子為單位。<br><br><b>Quincunx</b> 方法將偏移量作為形狀單元大小的因子。<br>- <b>Quincunx - 水平：</b>每隔一列均勻加總偏移值。<br>- <b>Quincunx - 垂直</b>：每隔一列均勻加總偏移值。 |
| <b>樞軸位置（地方）</b> *Float3* | 調整樞軸在圖形局部空間中的位置，影響變換的原點。 （例如位置偏移、旋轉與縮放）<br><br>例如，調整 Z 軸樞軸位置，使形狀繞其底面旋轉。 |
| <b>三維旋轉</b> *Float3* | 對所有形狀均勻地套用每軸旋轉，且以轉數計算。 |
| <b>三維旋轉隨機</b> *浮標* | 一個因子，表示在指定數值內，順時針或逆時針旋轉的隨機旋轉量。 |
| <b>三維旋轉隨機乘法</b> *Float3* | 調整 3D 旋轉</b>所施加<b>的隨機旋轉量，隨機旋轉是每個軸的獨立因子。 |
| <b>3D 旋轉映射乘法</b> *Float3* | Shape 旋轉</b>映射中<b>數值與每個形狀的每軸旋轉相加的強度，其中 1 表示加總旋轉量。 |
| <b>繞著正常軌道旋轉</b> *浮標* | 旋轉量均勻地施加在所有形狀周圍的法線（即當地 Z 軸）上，以轉圈數計算。 |
| <b>繞著正常隨機旋轉</b> *浮標* | 對每個形狀繞其法線（即當地 Z 軸）隨機旋轉，順時針或逆時針，最多可旋轉一圈。 |
| <b>斜坡旋轉</b> *浮標* | 旋轉形狀使其與背景在位置的斜率相匹配。<br>也就是說，對背景高度的法線施加等於全域 Z 上向量旋轉的旋轉。<br><br>此參數為該旋轉的因數，1 表示施加完整旋轉。<br><br>此旋轉會被加到其他可套用於形狀的旋轉中。 |
| <b>斜坡旋轉輸入</b> *整數* | 驅動斜率旋轉</b>的來源<b>。<br><br>- <b>背景：</b>使用背景高度貼圖，從該高度貼圖計算出的法線是旋轉的目標方向。<br>- <b>向量貼圖：</b>向量貼圖貼圖指定的向量與旋轉的目標方向相同使用。</b> |
| <b>向量映射乘法</b> *浮標* | 將形狀繞<b>向量映射旋轉軸</b>的軸旋轉，以匹配向量貼</b>圖紋理所描述<b>的向量方向。<br>也就是說，對貼圖中的向量施加等於全域 X 向右向量的旋轉。<br><br>此參數為該旋轉的因數，1 表示施加完整旋轉。<br><br>此旋轉會被加到其他可套用於形狀的旋轉中。 |
| <b>向量映射旋轉軸</b> *整數* | 旋轉應繞向量映射<br><br></b>指定的<b>軸。- <b>法線：</b>將形狀繞其法線旋轉，類似使用「繞法線旋轉」參數。<br>- <b>Z 軸：</b>圍繞全域 Z 軸旋轉形狀，類似於使用「3D 旋轉」參數的 Z 分量。 |
| <b>遮罩隨機</b> *浮標* | 隱藏形狀總數的比例，隨機順序，1 表示所有形狀都被隱藏。<br><br>此參數與遮罩映射結合。 （若使用） |
| <b>遮罩映射閾值</b> *浮標* | 遮罩地圖</b>中的<b>灰階值，形狀會隱藏在下面。<br><br>該映射與遮罩隨機</b>參數結合<b>。 |
| <b>紫外線尺度</b> *Float2* | 每個軸的 UV 乘法器，隨著數值增加，平鋪效果也會增加。 |
| <b>帽UV尺度</b> *Float2* | 一個每軸乘數，用於圓柱體電容的紫外線，且平鋪隨值增加而增加。 |
| <b>Cap UV 模式</b> *整數* | 計算圓柱體大容量UV的方法。<br><br>- <b>極座標：</b>  使用極座標，U在圓柱Z軸上增加，V隨距離越遠而增加。<br>- <b>平面投影：</b> 使用平面投影，UV透過頂部的邊界框（即調整為大小的矩形）映射。 |
| <b>顯示形狀 2D Bbox</b> *布林值* | 疊加圖形在影像中包圍矩形的視覺化。 這是繪製形狀的區域。 |
| <b>顯示形狀 3D Bbox</b> *布林值* | 在 3D 空間中疊加圖形包圍體積的視覺化。 這是繪製SDF形狀和擠出平面的區域。<br><br>對於 SDF 形狀，這個區域與 SDF 邊界框架大小</b>相符<b>。<br><br>這種視覺化有助於評估形狀的跨度與方向。 |
| <b>顯示形狀樞軸</b> *布林值* | 疊加了樞軸形狀的視覺化，作為其局部 XYZ 軸向量的組合。<br><br>此視覺化有助於評估形狀的方向及其變換的起點。 （例如偏移、旋轉、縮放） |
