## 參數

|  |  |
|:---|:---|
| <b>鋪磚</b> <i>1 - 16</i> | 設定結果應該鋪磚的次數。 |
| <b>職位</b> <i>0.0 - 1.0</i> | 設定梯度的中點或頂點。 |
| <b>旋轉</b> <i>0, 90°</i> | 將方向從左-右轉為上-下，或反之。 |
