## 參數

|  |  |
|:---|:---|
| <b>條紋</b> <i>1 - 100</i> | 設定條紋數量。 自動調整結果以確保鋪磚。 |
| <b>寬度</b> <i>0.0 - 1.0</i> | 條紋寬度。 |
| <b>柔和度</b> <i>0.0 - 1.0</i> | 設定條紋邊緣的過渡。 |
| <b>轉移</b> <i>0 - 20</i> | 條紋會傾斜。 自動增加更多條紋以確保鋪磚。 |
| <b>對齊</b> <i>邊緣，中心</i> | 設定 Pivot 用於 Shifting。 |
| <b>過濾</b> <i>錯誤/真實</i> | 啟用過濾功能。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
