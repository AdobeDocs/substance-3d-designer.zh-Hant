## 說明

會產生平鋪、斜角條紋圖案。 圖案會自動調整，以確保連續性。

## 參數

* **條紋**： *1 - 100*&#x200B;條紋數量。 自動調整結果以確保鋪磚。
* **寬度**： *0.0 - 1.0*&#x200B;條紋寬度。
* **柔和度**： *0.0 - 1.0*&#x200B;設定條紋邊緣的過渡。
* **Shift**： *0 - 20*&#x200B;傾斜條紋。 自動增加更多條紋以確保鋪磚。
* **對齊**： *邊緣，中心*&#x200B;設置樞軸以便移動。
* **過濾**： *False/True*&#x200B;啟用過濾功能。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
