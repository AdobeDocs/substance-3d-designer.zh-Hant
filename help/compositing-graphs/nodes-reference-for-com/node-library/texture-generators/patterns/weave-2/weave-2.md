## 說明

產生簡單的織紋圖案。 有隨機化的對照。 在最大混亂狀態下，這甚至可以當作噪音使用。

## 參數

|  |  |
|:---|:---|
| <b>鋪磚</b> <i>1 - 16</i> | 設定結果應該鋪磚的次數。 |
| <b>混亂</b> <i>0.0 - 100.0</i> | 在織法的針目間亂擺，增加變化。 |
| <b>旋轉45度</b> <i>錯誤/真實</i> | 旋轉到預設角度。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
