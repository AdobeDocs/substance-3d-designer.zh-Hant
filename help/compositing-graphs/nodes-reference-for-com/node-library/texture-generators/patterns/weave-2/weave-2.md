## 說明

產生簡單的織紋圖案。 有隨機化的對照。 在最大混亂狀態下，這甚至可以當作噪音使用。

## 參數

* **鋪磚**： *1 - 16*\
  設定結果應該鋪磚的次數。
* **無障礙**： *0.0 - 100.0*\
  在織法的針目間亂擺，增加變化。
* **旋轉45度**： *假/真*&#x200B;旋轉至預設角度。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
