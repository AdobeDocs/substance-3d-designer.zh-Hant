## 說明

**Tile Random 2** 節點會產生相鄰的圖塊，尺寸和高寬比都隨機。

網格可以透過隨機 *傾斜* 形狀的側邊來打散角度來調整。

形狀可透過縮放、斜角&#x200B;**、圓角&#x200B;*及*&#x200B;分列旋轉&#x200B;*等選項*&#x200B;進行調整。 &#x200B;**

這些調整可由 *輸入映射*&#x200B;控制。

專用輸出可以讓你將形狀的 **UV** 輸入到 **Flood Fill（...）** 節點用於施加額外變化。

## 參數

### 輸入

* **隨機大小地圖***灰階*\
  灰階輸入影像控制形狀的隨機比例。\
  其影響由 **隨機大小輸入映射乘** 數參數控制。
* **隨機斜面圖***灰階 灰階*&#x200B;輸入影像控制形狀的隨機傾斜。\
  其影響由 **隨機斜入映射乘** 數參數控制。
* **圓角半徑地圖***灰階*\
  灰階輸入影像，控制形狀圓角的半徑。\
  其撞擊由圓角半徑輸入地圖多數控制 **。** 參數。
* **斜角距離圖***灰階*\
  灰階輸入影像控制形狀的斜角。\
  其撞擊由斜面距離輸入映射多重控制 **。** 參數。
* **遮罩貼圖***灰階*\
  灰階輸入影像，控制形狀的遮罩。\
  其影響由遮罩映射輸入開始與&#x200B;**遮罩映射輸入結束**&#x200B;參數控制&#x200B;**。**

### 參數

* **X***整數*\
  X 軸上的&#x200B;**&#x200B;**&#x200B;格子數量。
* **Y** *整數*\
  Y軸上的&#x200B;**&#x200B;**&#x200B;格子數量。
* 大小
  * **隨機大小乘***數浮點*\
    對隨機縮放強度進行 *全域* 調整。
  * **隨機大小輸入映射乘數***浮點*\
    利用從隨機尺寸映射&#x200B;**輸入中取***樣的值*&#x200B;調整隨機縮放強度。
  * **隨機大小 X** *浮點*\
    僅&#x200B;*調整 X **軸*隨機縮放**&#x200B;的強度。
  * **隨機大小 Y** *浮點*\
    只能&#x200B;*調整 Y **軸*隨機縮放**&#x200B;的強度。
  * **隨機大小分布整***數*\
    控制分配隨機縮放值的方法：
    * *均勻*：隨機刻度對所有格子以相同方式&#x200B;*應用*
    * *藍噪聲*：隨機音階是 *用藍噪聲模式調整* 的
* 形狀面向 - 變形
  * **間隙厚度***浮球*&#x200B;調整形狀間隙的厚度。它對所有&#x200B;*形狀都是*&#x200B;平等的。
  * **隨機位置乘數***浮點*\
    對形狀施加一個隨機位置偏移，直到 *它與格子的邊界*&#x200B;相接。
  * **圓角半徑***浮動*&#x200B;調整&#x200B;*形狀圓角的半徑*。值為 **0** 表示不應用四捨五入。\
    *注意*：當 **「每軸斜角啟用** 」參數設 *為 True*，此效果無法套用。
  * **圓角 半徑輸入 地圖 多。** *浮動*&#x200B;調整 **圓角半徑地圖** 輸入映射對圓角半徑的影響強度。\
    該映射作為&#x200B;*圓角半徑&#x200B;**參數的每像素*乘**&#x200B;數。\
    *注意*：當 **「每軸斜角啟用** 」參數設 *為 True*，此效果無法套用。
  * **比例乘法***浮點*\
    調整每個形狀的大小，依其單元&#x200B;*面積的比例*&#x200B;調整。
  * **縮放***隨機浮動*&#x200B;調整隨機刻度施加於&#x200B;*每個*&#x200B;形狀的強度。
  * **旋轉***浮點*&#x200B;透過將每個&#x200B;*角落*&#x200B;移動到&#x200B;*格子邊界上的相鄰*&#x200B;角來旋轉形狀。\
    此方法會在旋轉時對形狀施加一定程度 *的變形* 與 *縮放* 。
  * **旋轉隨機***浮點*&#x200B;調整每個形狀所施加隨機旋轉強度的隨機量。\
    旋轉方法描述於 **旋轉** 參數中。
  * **角落位置 隨機***浮點*&#x200B;透過對每個角落&#x200B;*在格子邊界施加隨機偏*&#x200B;移&#x200B;**&#x200B;來扭曲形狀。
* 斜坡
  * **隨機斜率乘***數浮點*\
    對隨機傾斜強度進行 *全域* 調整。
  * **隨機斜輸入映射乘***法浮點*\
    利用從隨機斜面圖&#x200B;**輸入取***樣的數值*&#x200B;調整隨機傾斜強度。
  * **隨機斜面 X** *浮球*\
    調整隨機傾斜的強度\
    僅在&#x200B;*X **軸*上**。
  * **隨機斜向 Y** *浮球*\
    調整隨機傾斜的強度\
    **僅限&#x200B;*於Y**&#x200B;軸*。
  * **隨機斜率分布整***數*\
    控制分配隨機斜向值的方法：
    * *均勻*：隨機斜率以相同方式&#x200B;*套用*&#x200B;於所有儲存格
    * *藍噪：*&#x200B;隨機斜斜度透過 *藍噪點模式進行* 調整
* 斜面
  * **斜角距離模式***整數*\
    設定 *了獲得形狀斜角距離* 的方法：
    * *相對於格線大小*：形狀依其格子尺寸&#x200B;**&#x200B;的指定&#x200B;*比例斜角——相對於形狀大小*：形狀依其尺寸的指定&#x200B;*比例斜角*
    * *相對於影像大小*：形狀會依照影像的指定 *比例斜角*
  * **斜面距離乘***數浮點*\
    對斜角的距離進行 *全域* 調整。
  * **斜角距離輸入映射 多重** *浮標*\
    利用 **斜面距離圖** 輸入映射作為 *每像素* 乘數來調整斜角距離。
  * **斜角圓弧浮***球*\
    調整斜角所施加的圓角強度，使其更具 *凸性*。
  * **啟用每軸斜角控制***布林值*\
    當&#x200B;*為真*&#x200B;時，斜角可分別&#x200B;***在 X**&#x200B;軸和&#x200B;**Y**&#x200B;軸上施加與調整*。\
    *注意*：此動作&#x200B;*會抵&#x200B;***消圓角**&#x200B;效應。
  * **斜角距離 x** *浮子*\
    只能&#x200B;*調整 X **軸*斜面**&#x200B;的距離。此距離取決於斜面距離模式&#x200B;**參數的**&#x200B;值。\
    *注意*：此參數僅在「 **每軸斜角啟用** 」參數設 *為 True* 時可用。
  * **斜角距離 Y** *浮點*\
    僅&#x200B;*調整 Y **軸*斜角**&#x200B;的距離。此距離取決於斜面距離模式&#x200B;**參數的**&#x200B;值。\
    *注意*：此參數僅在「 **每軸斜角啟用** 」參數設 *為 True* 時可用。
* 遮色片
  * **遮罩隨機反轉***布林值*\
    顛倒形狀的隨機遮罩。
  * **遮罩隨機起始***浮點*\
    對於給定 **的隨機種子**，偽隨機遮罩會依 *照從起始形狀到終點形狀的特定順序* 進行。 這個參數可以讓你&#x200B;*偏移起始*&#x200B;形狀的&#x200B;*索引*。\
    *注意*：這決定了遮蔽值範圍&#x200B;*的*&#x200B;一個極限。因此 *，該值可能大* 於 **遮罩隨機端** 值。
  * **遮罩隨機端***點浮點*&#x200B;對於給定&#x200B;**的隨機種子**，會依&#x200B;*照從起始形狀到終點形狀的特定順序*&#x200B;進行偽隨機遮罩。這個參數可以讓你&#x200B;*偏移終端*&#x200B;形狀的&#x200B;*索引*。\
    *注意*：這決定了遮蔽值範圍&#x200B;*的*&#x200B;一個極限。因此 *，該值可能大* 於 **遮罩隨機起始** 值。
  * **以格子面積遮罩 反元***布林*\
    將形狀的遮蔽被其細胞面積反轉。
  * **依單元區域遮罩 起始***浮點*\
    調整 *遮罩形狀的最小* 單元面積閾值。\
    *注意*：這決定了遮蔽值範圍&#x200B;*的*&#x200B;一個極限。因此 *，該值可能大* 於 **遮罩單元面積的終點** 值。
  * **依格面積遮罩 結束***浮點*&#x200B;調整&#x200B;**&#x200B;遮罩形狀的最大格子面積閾值。\
    *注意*：這決定了遮蔽值範圍&#x200B;*的*&#x200B;一個極限。因此 *，該值可能低於* **Mask by Cell Area 起始** 值。
  * **遮罩映射輸入反演***布林值*\
    透過遮罩貼圖&#x200B;**輸入映射反轉形狀**&#x200B;的遮罩。
  * **遮罩映射輸入 開始***浮點*\
    調整&#x200B;*遮罩圖&#x200B;**輸入映射中**&#x200B;遮罩形狀的最小灰階值*&#x200B;閾值。\
    *注意*：這決定了遮蔽值範圍&#x200B;*的*&#x200B;一個極限。因此 *，該值可能大* 於 **遮罩映射輸入端** 值。
  * **遮罩貼圖輸入***結束浮點*&#x200B;調整&#x200B;*遮罩貼圖&#x200B;**輸入貼圖中遮罩形狀的最大灰階值*閾**&#x200B;值。\
    *注意*：這決定了遮蔽值範圍&#x200B;*的*&#x200B;一個極限。因此&#x200B;*，該值可能低於&#x200B;***遮罩映射輸入起始**&#x200B;值。
