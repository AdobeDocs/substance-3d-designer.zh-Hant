## 說明

渲染一個帶有陰影的灰階 3D 立方體，同時也作為螢幕深度。 當搭配高精度位深時，所產生的立方體邊緣極為銳利且清晰。 非常有趣且實用！

## 參數

|  |  |
|:---|:---|
| <b>方向偏移</b> | 允許立方體進行類似 3D 的 X 和 Y 旋轉。 也可以透過操作 2D 預覽中的小點來完成（如下範例所示） |
| <b>規模</b> <i>0.0 - 1.0</i> | 允許對立方體進行非均勻的縮放。 |
| <b>規模</b> <i>0.0 - 1.0</i> | 整個立方體都能均勻縮放。 |
| <b>非平方展開</b> <i>錯誤/真實</i> | 能以非平方比率補償擠壓與拉伸。 |
