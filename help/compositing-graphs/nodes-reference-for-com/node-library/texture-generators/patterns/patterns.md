# 模式

圖案是看起來像人造的人工圖形。 它們大多遵循規則來放置，但大多數時候可以引入隨機變化。

當你想要規則圖案作為底座時，它們很有用，例如磚塊、瓷磚、編織圖案等。

幾乎所有圖案都能完美拼貼，且不受解析度影響，這表示你可以重新縮放它們而不損失畫質。

使用 <b>左側</b> 的導覽列表，瀏覽所有模式下的節點。
