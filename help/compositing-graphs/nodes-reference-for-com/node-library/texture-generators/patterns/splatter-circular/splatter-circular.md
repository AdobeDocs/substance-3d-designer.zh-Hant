## 說明

Splatter Circular 產生基於環狀的圖案，並具備多種控制。 它可以使用預先定義的形狀或自訂輸入。 它類似[於方塊產生器](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)，但是圓形擺放而非格子。

這對於想要以各種隨機化選項將形狀呈圓形排列時非常有用。

## 參數

### 輸入

兩種輸入都是可選的。

* **圖案影像輸入 1-6**： *灰階輸入（彩色輸入）*\
  僅 Splatter Circular ：自訂圖案影像，當「Pattern」參數設為「影像輸入」時使用。
* **背景**： *灰階輸入（彩色輸入）*

### 參數

* **圖案數量**： *1 - 64*\
  要在戒指上放置的圖案方塊數量。
* **隨機模式數量**： *0.0 - 1.0*\
  隨機化放置圖案數量。 最好搭配戒指數量超過1。
* **隨機模式數量 最小**&#x200B;值： *1 - 10*&#x200B;設定隨機化的最低模式數量。
* **戒指金額**： *1 - 10*\
  設定要填滿的環數。 這些環總是放在外層的環內，且空間均勻。
* **非平方展開**： *假/真*\
  能以非平方比率補償擠壓與拉伸。
* **模式**
  * **圖案**： *影像輸入、方形、圓盤、拋物面、鐘形、高斯分布、荊棘、金字塔、磚塊、漸變、波浪、半鐘形、脊狀鐘、新月形、膠囊、錐形*\
    選擇要使用的圖案形狀。
  * **模式輸入編號**： *1 - 6*&#x200B;設定可使用的不同影像輸入數量。 僅在上方選擇影像輸入&#x200B;*時*&#x200B;才可用。
  * **模式輸入分布**： *隨機、依模式編號、環編號*&#x200B;設定多個模式輸入的選擇方式。 隨機指隨機選出一個，圖案編號指它們只是放在一個循環序列中，而環號則是每個環都有不同的環。
  * **影像輸入濾波**： *雙線性 + Mipmaps，雙線性，最近*
  * **特定**&#x200B;模式： *0.0 - 1.0*\
    讓你可以改變所選圖案的形狀。 效果取決於所選的模式。
  * **對稱隨機**： *0.0 - 1.0*\
    根據以下行為，設定應該隨機翻轉/鏡像的方塊數量。
  * **對稱隨機模式**： *水平 + 垂直，水平，*&#x200B;垂直 決定對稱鏡像行為。
* **職位**
  * **半徑**： *0.0 - 1.0*\
    設定圖案放置中心的半徑。
  * **隨機半徑**： *0.0 - 1.0*&#x200B;隨機化每個圖案方塊的半徑。
  * **環形半徑倍數**： *0.0 - 1.0*\
    影響多環間距。
  * **角度隨機**： *0.0 - 1.0*&#x200B;隨機化每個圖案的角度。 越多的旋轉量越大。
  * **螺旋因子**： *0.0 - 1.0*\
    將環形區域變成螺旋形，每塊方塊的半徑都會稍微增加。
  * **散布**： *0.0 - 2.0*&#x200B;設定每枚戒指的回合數。 這個數字可以被提升到極限之外。
  * **方向**&#x200B;偏移： *0.0 - 1.0*\
    將每個圖案從中心沿角度移動。 這個效果很大程度上取決於角度隨機，或者看起來就像是半徑的倍數。
  * **全球偏移**： *0.0 - 1.0*\
    能翻譯整個形狀。
* **規模**
  * **連結圖案**： *假/真*&#x200B;讓圖案方塊的長度取決於半徑，也就是說每個形狀應該會接觸到前一個和下一個形狀。
  * **大小（連接）：***0.0 - 1.0*\
    會在全球範圍內改變每個圖案的大小。 連接時，它是相對於總半徑的。
  * **隨機**&#x200B;大小： *0.0 - 1.0*\
    會隨機化每個圖案的大小。
  * **等級**： *0.0 - 2.0*\
    均勻地縮放每個圖案。
  * **隨機**&#x200B;分數： *0.0 - 1.0*\
    隨機化均勻的縮放。
  * **依圖案編號**&#x200B;縮放： *0.0 - 1.0*&#x200B;使圖案縮放依環狀結構位置而異。
  * **反轉模式編號**： *錯誤/真實*\
    若與前述選項結合，則可將縮放從小變大，反之亦然。
  * **依戒指號碼**&#x200B;比例： *0.0 - 1.0*&#x200B;使比例依賴戒指號碼。
  * **反演環位號**： *偽/真*&#x200B;與前述選項搭配使用，可反轉縮放範圍從小到大，反之亦然。
* **旋轉**
  * **圖案旋轉**： *0.0 - 1.0*&#x200B;均勻旋轉所有圖案。
  * **圖案旋轉**&#x200B;隨機： *0.0 - 1.0*\
    隨機化圖案輪換。
  * **模式旋轉樞軸**： *中心、最小 X、最大 X、最小 Y、最大 Y*\
    設定每個圖案可單獨旋轉的樞軸點位置。
  * **中心方向**： *錯誤/真*\
    會把每個圖案旋轉，使其朝向環的中心。 關閉它會讓它們的方向相同——這可能會產生偏移方向的不良效果。
  * **環狀旋轉**： *0.0 - 1.0*&#x200B;將整個環繞中心旋轉。
  * **環狀旋轉隨機**： *0.0 - 1.0*&#x200B;隨機化每個環的旋轉。
  * **環狀旋轉偏移**： *0.0 - 1.0*\
    偏移每個環的旋轉。
* **顏色**
  * **顏色**：*（灰階值）*顏色，與選取的圖案相乘。
  * **亮度隨機**： *0.0 - 1.0*&#x200B;隨機化顏色或亮度，對每個圖案方塊。
  * **按比例**&#x200B;尺的亮度： *0.0 - 1.0*&#x200B;使亮度依照個別圖案尺度而定。
  * **依圖案編號**&#x200B;的亮度： *0.0 - 1.0*&#x200B;使亮度依賴於圖案序列。 例如可以搭配螺旋圖案使用。
  * **反轉模式號碼**： *假/真*&#x200B;反轉前一個選項。
  * **依環號**&#x200B;的亮度： *0.0 - 1.0*&#x200B;使亮度依賴於環狀序列。
  * **反轉環號**： *假/真 反*&#x200B;轉前一個選項。
  * **隨機面具**： *0.0 - 1.0*&#x200B;隨機隱藏圖案。
  * **背景色**：*（灰階值）*會改變純色背景色。
  * **混合模式**： *加、最大、新增子組*&#x200B;如何混合重疊的圖案。
  * **全域不透明度**： *0.0 - 1.0*&#x200B;設定整個結果的全域不透明度。
