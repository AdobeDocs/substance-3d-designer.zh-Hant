# 材質產生器

材質產生器是不需要任何輸入的節點：它們完全從零產生影像。 你可以把「材質產生器」想成「程序化」的另一種說法。

它們分為兩大類：

* [聲音](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  噪音才是真正的程序化圖形，隨機形狀和像素，就像眾所周知的 Perlin 和 Clouds 聲音一樣。
* [模式](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  圖案大多是看起來像人造的形狀，並有許多額外的控制來隨機化它們。
