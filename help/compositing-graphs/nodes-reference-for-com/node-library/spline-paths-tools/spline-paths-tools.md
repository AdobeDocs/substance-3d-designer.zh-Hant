# 樣條與路徑工具

樣條與路徑工具是一組用於在 Substance 圖中處理路徑與樣條的節點：

<b>路徑是一連串點連接</b> 成直線。

<b>樣條</b> 曲線是由控制點及其切線所塑造的平滑曲線。 每個點也控制樣條的高度與厚度屬性，這些屬性用於驅動影像的映射、變形與散射。

此範疇包含以下子範疇：

* [花鍵工具](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-tools.md)\
  節點用於產生與調整樣條曲線，並用於映射、散射或扭曲影像。
* [路徑工具](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-tools.md)節點，用於產生與調整路徑，並將路徑轉換為樣條，用於複雜的影像散射或扭曲。
