## 說明

在輸入父樣條上放置樣條曲線。

節點提供深度自訂選項，控制樣條線的散佈方式，讓你可以散布簡單的直線樣條，或是你自己的自訂樣條。

這個節點讓你可以用樣條曲線映射[&#128279;](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-mapper-grayscale/spline-mapper-grayscale.md)器節點來建立複雜的結構來映射顏色和影像，或作為骨[架用散佈在樣條](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-spline-grayscale/scatter-on-spline-grayscale.md)鍵上放置形狀。

## 輸入

|  |  |
|:---|:---|
| <b>預覽</b> *灰階* | 輸入樣條線預覽為灰階影像。 |

| <b>樣條資料</b> *顏色* | 編碼在彩色影像 RGBA 通道中的父樣條的額外資料：  <b>R</b> - 切線 X  <b>G</b> - 切線 Y  <b>B</b> - 切線 Z  <b>A</b> - 未使用 |
| <b>樣條量</b> *整數* | 父樣條的數量。 |
| <b>自訂樣條座標</b> *顏色* | 彩色影像 RGBA 通道中編碼的自訂樣條點座標：  <b>R</b> - X 位置  <b>G</b> - Y 位置  <b>B</b> - 高度  <b>A</b> - 打包資料：- 符號：樣條線為閉合（負）或開（正） - 絕對值：厚度 + 1 |

<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>側邊</b> *整數* | 控制：樣條曲線應該分散在父樣條的哪一側，因為「前」是父&#x200B;*樣條曲線的*&#x200B;方向：<br><br>- <b>左</b> 將樣條線放在左側。<br>- <b>右</b> 將樣條曲線放在右側。<br>- <b>左 + 右</b> 樣條曲線放在兩側。<br>- <b>左 / 右 - 交替</b>放置樣條線 交替擺放左邊或右邊（例如每隔一邊）。<br>- <b>左 / 右 - 隨機</b> 隨機選擇每個樣條線的邊。 |
| <b>數量模式</b> *整數* | 沿著母樣條線散布樣條的方法，會影響每個父樣條上的散布樣條數量：<br><br>- <b>每個樣條</b> 鍵數量固定 分配均勻間隔的樣條量。<br>- <b>間距</b> 樣條數會自動調整以符合指定的均勻間距。<br><br>在這兩種情況下，第一和最後一個散布樣條分別恰好落在每個父樣條的起點和結尾。 |
| <b>花鍵數量</b> *整數* | 每個父樣條均勻分布的樣條數量。 |
| <b>花鍵間距</b> *浮標* | 在父樣條線上應該間隔的最小距離，同時使第一個和最後一個樣條線分別落在每個父樣條的起點和結束點。 |
| <b>花鍵類型</b> *整數* | 選擇在父樣條線上散布的樣條類型：<br><br>- 直線</b> 一種簡單直線樣條<br>。- <b>自訂樣條鍵</b> 提供給<b>自訂樣條</b>輸入的<b>樣條鍵。多重樣條在附加於列表時會被支援。 |
| <b>自訂樣條鍵選擇</b> *整數* | 當多個自訂樣條線附加於列表中時，此參數允許你選擇這些樣條線在散佈中的分布方式。<br><br>- 整個清單</b> 所有樣條線作為一組散布在一起。<br>- <b>順序式</b> 每個樣條線依序散布，繞行列表。<br>- <b>隨機</b> 每個散布樣條線從列表中隨機抽取一個<b>樣條線。 |
| <b>開始</b> *浮標* | 偏移母樣條起點的散射起點。 該值為每個父樣條線的正規化長度。 |
| <b>結束</b> *浮標* | 偏移母樣條起點，該點是散射結束。 該值為每個父樣條線的正規化長度。 |
| <b>翻轉方向</b> *布林值* | 將散布樣條的方向反轉。 |
| <b>左右對稱模式</b> *整數* | 對母樣條線兩側散布的樣條鍵的對稱性方法。- 禁用 不套用對稱性，樣條線透過簡單旋轉放置在兩側。<br>- <b>左對稱</b> 左邊的樣條相對於母樣條與右邊的樣條對稱。<br>- <b>右對稱</b> 右邊的樣條相對母樣條與左邊的樣條對稱。</b> <b><br><br> |
| <b>左/右隨機連結</b> *布林值* | 控制父樣條曲線兩側的樣條曲線在使用隨機旋轉、隨機縮放等時是否應該使用相同的數值。換句話說：<br><br>- 假：</i>每個樣條線使用不同的隨機值<br>- <i>真：</i>兩個樣條線<i>共享相同的隨機值 |
| <b>花鍵樞軸模式</b> *整數* | 設定了放置散佈樣條軸點的方法，影響旋轉與縮放。<br>請注意，樞軸 *總是放在父樣條上* ，其控制項會影響散射樣條。 換句話說：樞軸不會移動，而是散布樣條移動並相對地與之縮放。<br><br>- <b>沿樣條</b> 曲線位置 沿著散布樣條移動樞軸。<br>- <b>絕對位置</b> 為樞軸設定任意位置。 |
| <b>沿樣條鍵的樞軸位置</b> *浮標* | 樞軸在散布樣條上的正規化位置，0為起點，1為終點。<br>請注意，樞軸會跟隨 *散射樣條的方向* ，且樣條的方向可能會改變，以保持樞軸的位置和相對母樣條的位置與旋轉。 |
| <b>樞軸絕對位置</b> *Float2* | 樞軸在紫外空間中的位置。 |
| <b>非平方修正</b> *布林值* | 調整樣條曲線的位置與厚度，以保持非正方形解析度下的形狀。注意：使用自訂樣條時，自訂樣條曲線應使用&#x200B;*與散</b>射樣條節點上的散佈樣條相同的影像比例*<b>。</i><br><i> |
| <b>規模</b> |  |
| <b>樣條尺度</b> *浮標* | 一個全域控制，涵蓋所有樣條曲線的大小，其中 1 是它們的原始大小。<br>縮放是相對於樣鍵的樞軸進行。 樞軸位置可利用 <b>樣條樞軸</b> 參數進行偏移。 |
| <b>樣條尺度隨機</b> *浮標* | 對樣條大小施加隨機乘數，最高可達指定值。 |
| <b>比例圖輸入倍增器</b> *浮標* | 控制比例貼圖</b>輸入的<b>強度。此映射作為當前圖案大小的乘數。<br>此映射的效果與尺寸</b>組中<b>其他參數結合。 |
