## 說明

在輸入父樣條上放置樣條曲線。

節點提供深度自訂選項，控制樣條線的散佈方式，讓你可以散布簡單的直線樣條，或是你自己的自訂樣條。

這個節點讓你可以用樣條曲線映射[&#128279;](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-mapper-grayscale/spline-mapper-grayscale.md)器節點來建立複雜的結構來映射顏色和影像，或作為骨[架用散佈在樣條](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-spline-grayscale/scatter-on-spline-grayscale.md)鍵上放置形狀。

## 參數

|  |  |
| --- | --- |
| <b>側邊</b> *整數* | 控制：樣條曲線應該分散在父樣條的哪一側，因為「前」是父&#x200B;*樣條曲線的*&#x200B;方向：左邊 將樣條線放在左側。右 將花鍵放在右側。   左 + 右 將樣條線放在兩側。   左/右 - 交替放置左邊或右邊的樣條曲線（例如每隔一側）。   左/右 - 隨機 隨機選擇每個花條的邊。 |
| <b>數量模式</b> *整數* | 將樣條沿著母樣條線散佈的方法，會影響每個母樣條線上散布的樣條數量：每個樣條鍵數量固定 分配均勻間隔的樣條量。   間距 花鍵數量會自動調整以符合指定的均勻間距。   在這兩種情況下，第一和最後一個散布樣條分別恰好落在每個父樣條的起點和結尾。 |
| <b>花鍵數量</b> *整數* | 每個父樣條均勻分布的樣條數量。 |
| <b>花鍵間距</b> *浮標* | 在父樣條線上應該間隔的最小距離，同時使第一個和最後一個樣條線分別落在每個父樣條的起點和結束點。 |
| <b>花鍵類型</b> *整數* | 選擇應該散佈在父樣條上的哪種樣條線：直線 一種簡單的直線樣條。   自訂樣條鍵 提供給自訂樣條</b>鍵輸入的<b>花條。多重樣條在附加於列表時會被支援。 |
| <b>自訂樣條鍵選擇</b> *整數* | 當將多個自訂樣條線附加成一個清單時，這個參數讓你可以選擇這些樣條線在散射中應該如何分布。   完整列表所有樣條線會分散在一起。   順序式 每個樣條線依序散布，繞行整個清單。   隨機：每個散布的樣條線會從列表中隨機抽取一個樣條。 |
| <b>開始</b> *浮標* | 偏移母樣條起點的散射起點。  該值為每個父樣條線的正規化長度。 |
| <b>結束</b> *浮標* | 偏移母樣條起點，該點是散射結束。  該值為每個父樣條線的正規化長度。 |
| <b>翻轉方向</b> *布林值* | 將散布樣條的方向反轉。 |
| <b>左右對稱模式</b> *整數* | 對稱性方法應用於母樣條兩側散布的樣條。   停用 不套用對稱性，樣條透過簡單旋轉放置在兩側。   左對稱性左邊的樣條相對於母樣條，與右邊的樣條相對對稱。   右對稱 右邊的樣條相對於母樣條，與左邊的樣條對稱。 |
| <b>左/右隨機連結</b> *布林值* | 控制父樣條曲線兩側的樣條曲線在使用隨機旋轉、隨機縮放等時是否應該使用相同值。換句話說：   *- 假：* 每個樣條線使用不同的隨機值  *- 真：* 兩個樣條線共享相同的隨機值 |
| <b>花鍵樞軸模式</b> *整數* | 設定了放置散佈樣條軸點的方法，影響旋轉與縮放。   請注意，樞軸 *總是放在父樣條上* ，其控制項會影響散射樣條。 換句話說：樞軸本身不會移動，而是散布樣條移動並相對地與它縮放。   沿著樣條線定位 沿著散射樣條移動樞軸。   絕對位置 為樞軸設定任意位置。 |
| <b>沿樣條鍵的樞軸位置</b> *浮標* | 樞軸在散布樣條上的正規化位置，0為起點，1為終點。   請注意，樞軸會跟隨 *散射樣條的方向* ，且樣條的方向可能會改變，以保持樞軸的位置和相對母樣條的位置與旋轉。 |
| <b>樞軸絕對位置</b> *Float2* | 樞軸在紫外空間中的位置。 |
| <b>非平方修正</b> *布林值* | 調整樣條的位置與厚度，以保持非正方形解析度下的形狀。   *注意：*&#x200B;使用自訂樣條線時，自訂樣條曲線應使用&#x200B;*與散</b>佈樣條節點上的散佈樣條曲線相同的影像比例*<b>。 |

+++高度

|  |  |

| <b>起始高度模式</b> *整數* | 計算散布樣條起始高度的方法。   手動設定所有散布樣條的絕對值相同。   從父樣條線（+ 自訂樣條線）使用父樣條的高度，然後用 <b>自訂樣條開始高度多重設定加入自訂樣條線的高度。</b> 參數。   從自訂樣條線中，使用自訂樣條線的高度即可。   *注意：*&#x200B;將樣條類型</b>設<b>為「自訂樣條」，並連接<b>自訂樣條</b>鍵輸入以使用自訂樣條的高度。 |

| <b>起始高度偏移</b> *浮標* | 對散射樣條的起始高度施加絕對偏移。 |
| <b>起始高度</b> *浮標* | 設定散布樣條起始高度的絕對值。 |
| <b>終端高度模式</b> *整數* | 計算散佈樣條線末高的方法。   手動設定所有散布樣條的絕對值相同。   從父樣條線（+ 自訂樣條線）使用父樣條線的高度，然後用 <b>自訂樣條線結束高度模組加入自訂樣條線的高度。</b> 參數。   從自訂樣條線中，使用自訂樣條線的高度即可。     *注意：*&#x200B;將樣條類型</b>設<b>為自訂樣條，並連接<b>自訂樣條</b>輸入以使用自訂樣條的高度。 |
| <b>客製化花鍵端高度多大。</b> *浮標* | 控制自訂樣條線自身結束高度對散落樣條曲線終點高度的貢獻，其中 1 表示使用自訂樣條的全部高度。   自訂樣條曲線的高度會根據所選 <b>的結束高度模式</b>不同使用：  *- 從父樣條曲線（+ 自訂樣條* ）：高度會加到父樣條曲線上  *- 自訂樣條* 曲線：高度直接使用 |
| <b>端高度偏移</b> *浮標* | 對散射樣條的終點高度施加絕對偏移。 |
| <b>端高度</b> *浮標* | 設定散布樣條線末端高度的絕對值。 |
