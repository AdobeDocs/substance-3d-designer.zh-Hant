# 花鍵橋（2個花鍵）

<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>收錄於：</b> 樣條與路徑工具 > 樣條鍵工具

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

從樣條曲線 #1</b> 到 <b>樣條曲線 #2</b> 生成樣條<b>曲線。產生的樣條可以是線性（直線）或三次貝茲曲線（曲面）。

</td>
</tr>
</table>

>[!IMPORTANT]
>
> 若提供給 <b>樣條線 #1</b> 與 <b>樣條線 #2</b> 輸入的資料包含多個樣條線，則僅使用每個清單中最後一個樣條線。

## 輸入連接器

<b>預告 #1</b> *灰階*&#x200B;輸入樣條 #1 的預覽，作為灰階影像。

<b>樣條座標 #1</b> *色彩*&#x200B;指編碼在彩色影像RGBA通道中的輸入樣條點#1的座標。\
    <b>R</b> - X 位置\
    <b>G</b> - Y 位置\
    <b>B</b> - 身高\
    <b>A</b> - 打包資料：\
* 符號：樣條鍵為閉（負）或開（正）;\
* 絕對值：厚度 + 1。

<b>樣條資料 #1</b> *顏色*&#x200B;輸入樣條線 #1 的額外資料，編碼在彩色影像的 RGBA 通道中。\
    <b>R</b> - 切線 X\
    <b>G</b> - 切線 Y\
    <b>B</b> - 未上場\
    <b>A</b> - 未上場

<b>花鍵量 #1</b> *整數*&#x200B;輸入樣條的數量 #1。

<b>預告 #2</b> *灰階*&#x200B;輸入樣條 #2 的預覽，作為灰階影像。

<b>樣條座標 #2</b> *顏色*&#x200B;指輸入樣條的 #2 點座標編碼在彩色影像的 RGBA 通道中。\
    <b>R</b> - X 位置\
    <b>G</b> - Y 位置\
    <b>B</b> - 身高\
    <b>A</b> - 打包資料：\
* 符號：樣條鍵為閉（負）或開（正）;\
* 絕對值：厚度 + 1。

<b>樣條資料 #2</b> *色彩*&#x200B;輸入樣條 #2 的額外資料編碼在彩色影像的 RGBA 通道中。\
    <b>R</b> - 切線 X\
    <b>G</b> - 切線 Y\
    <b>B</b> - 未上場\
    <b>A</b> - 未上場

<b>花鍵量 #2</b> *整數*&#x200B;輸入樣條的數量 #2。

<b>起始切線長度曲線</b> *灰階* （當「橋樑樣條類型」設為「立方貝茲」時可用）描述曲線的影像，使用其第一排像素的值。\
此輸入用來控制每個生成樣條線 #1 起點的「出線」切線長度。\
你可以用 Curve 節點來撰寫曲線。

<b>開始切線旋轉曲線</b> *灰階* （當「橋樑樣條類型」設為「立方貝茲」時可用）描述曲線的影像，使用其第一排像素的值。\
此輸入用來控制每個產生樣條曲線 #1 起點的「出」切線旋轉。\
影像的灰階值代表若干匝。\
你可以用 Curve 節點來撰寫曲線。

<b>端切長度曲線</b> *灰階* （當「橋樑樣條類型」設為「立方貝茲」時可用）描述曲線的影像，使用其第一排像素的值。\
此輸入用來控制每個樣條線 #2 上產生的樣條線末點的「內線」切線長度。\
你可以用 Curve 節點來撰寫曲線。

<b>端切旋轉曲線</b> *灰階* （當「橋樑樣條類型」設為「立方貝茲」時可用）描述曲線的影像，使用其第一排像素的值。\
此輸入用於控制每個產生樣條線末點的「內」切線旋轉，該點位於樣條線 #2 上。\
影像的灰階值代表若干匝。\
你可以用 Curve 節點來撰寫曲線。

## 輸出連接器

<b>預覽</b> *灰階*&#x200B;輸出樣條的預覽作為灰階影像。

<b>樣條座標</b> *顏色*&#x200B;指編碼在彩色影像RGBA通道中的輸出樣條點座標。\
    <b>R</b> - X 位置\
    <b>G</b> - Y 位置\
    <b>B</b> - 身高\
    <b>A</b> - 打包資料：\
* 符號：樣條鍵為閉（負）或開（正）;\
* 絕對值：厚度 + 1。

<b>樣條資料</b> *色彩*&#x200B;輸出樣條的額外資料編碼於彩色影像的RGBA通道中。\
    <b>R</b> - 切線 X\
    <b>G</b> - 切線 Y\
    <b>B</b> - 未上場\
    <b>A</b> - 未上場

<b>樣條量</b> *整數*：輸出樣條的數量。

## 參數

<b>橋式樣條量</b> *整數*：沿著樣條線 #1 到 樣條線 #2 產生的樣條數。

<b>橋式樣鍵類型</b> *整數*&#x200B;產生的樣條類型：
* 線性：從開始到結束的直線樣條;
* 三次貝塞爾：從起點到終點的曲線樣條，曲線由起點與終點的長度與角度控制。

<b>起始樣條 #1</b> *浮點*&#x200B;偏移從樣條曲線 #1 生成樣條的位置。 該值為樣條線 #1 的正規化長度。\
值越高，樣條數量相同，就堆疊得更緊密。

<b>起始樣條 #2</b> *浮點*&#x200B;偏移從樣條曲線 #2 上產生樣條曲線的位置。 該值為樣條線 #2 的正規化長度。\
值越高，樣條數量相同，就堆疊得更緊密。

<b>端點樣條 #1</b> *浮點*&#x200B;偏移是從樣條曲線 #1 上的位置移到樣條曲線產生的位置。 該值為樣條線 #1 的正規化長度。\
值越低，樣條數量相同，排列得更緊密。

<b>端點樣條 #1</b> *浮點*&#x200B;偏移是從樣條曲線 #2 到樣條曲線產生的位置。 該值為樣條線 #2 的正規化長度。\
值越低，樣條數量相同，排列得更緊密。

<b>偏移樣條 #1</b> *浮點*&#x200B;對 樣條線 #1 上所有樣條線的起點施加偏移量。 該值為樣條線 #1 的正規化長度。\
與樣條起點或終點相接的樣條會留在那裡。

<b>偏移樣條 #2</b> *浮點*&#x200B;對 Spline #2 上所有樣條線的起點施加偏移。 該值為樣條線 #2 的正規化長度。\
與樣條起點或終點相接的樣條會留在那裡。

<b>偏移隨機起始</b> *浮動*&#x200B;對樣條曲線 #1 上每個樣條線的起點施加隨機偏移。 該值為樣條線 #1 上樣條線間的正規化距離。\
當保持為 0 時，樣條曲線均勻分布於起始樣條線 #1 點與終點樣條線 #1 點之間。

<b>偏移隨機終點</b> *浮點*&#x200B;對樣條線 #2 上的每個樣條線的終點施加隨機偏移。 該值為樣條 #2 上樣條線間的正規化距離。\
當保持為 0 時，樣條曲線均勻分布於起始樣條曲線 #2 點與終點樣條曲線 #2 點之間。

<b>切線長度起始</b> *浮點* （當「橋接樣條類型」設為「立方貝茲」時可用）：指所有產生樣條線中，樣條線 #1 起點的「出」切線長度。

<b>切線長度端</b> *浮點* （當「橋接樣條類型」設為「立方貝茲」時可用）指所有產生樣條線 #2 端點的「內」切線長度。

<b>切線旋轉起始</b> *浮動* （當「橋接樣條類型」設為「立方貝茲」時可用）是所有產生樣條曲線中，樣條曲線 #1 起點的「出」切線旋轉。\
其數值為回合數。

<b>切線旋轉端</b> *浮動* （當「橋樑樣條類型」設為「立方貝茲」時可用）：所有產生樣條曲線中，樣條曲線 #2 端點的「內」切線旋轉。\
其數值為回合數。

+++預覽
<b>分段數量</b> *整數*&#x200B;調整預覽輸出中繪製樣條曲線視覺化所使用的段數。\
數值越高，線條越平滑。

<b>節目指導助理</b> *布林值*&#x200B;在預覽輸出中會在樣條曲線的起始處顯示一個點，在末端顯示一個箭頭。

<b>顯示厚度包絡</b> *布林值*\
在樣鍵厚度邊緣顯示額外線條。

<b>厚度（px）</b> *浮點*&#x200B;調整預覽輸出中樣條曲線的厚度（像素數）。
