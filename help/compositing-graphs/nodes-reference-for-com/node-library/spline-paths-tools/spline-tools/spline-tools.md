# 花鍵工具

樣條鍵工具是一組用於產生和調整樣條曲線的節點，也用於映射、散射或扭曲影像。

樣條曲線是由控制點及其切線所塑造的平滑曲線。 每個點也控制樣條的高度與厚度屬性，這些屬性用於驅動影像的映射、變形與散射。

>
