# 樣條灰階上的散射

<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

## 說明

沿著輸入樣條線在輸入背景上繪製指定的圖案。

</td>
</tr>
</table>

節點提供深度自訂選項，以控制圖案的散布方式。

散射的某些面向可透過圖中其他節點的影像來控制，以進一步強化結果的動態特性。

>[!NOTE]
>
> 另 [見樣條色](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-on-spline-color/scatter-on-spline-color.md)上的散射。

<a name="inputs"></a>

## 輸入

|  |  |
|:---|:---|
| <b>背景</b> <i>灰階</i> （原色） | 灰階影像，應該繪製在上面的樣條曲線。 |
| <b>樣條座標</b> <i>顏色</i> | 彩色影像RGBA通道中編碼的輸入樣條點座標：<br><b>R</b> - X 位置<br><b>G</b> - Y 位置<br><b>B</b> - 高度<br><b>A</b> - 填充資料：<br>符號：樣條線為閉合（負）或開（正）;<br>- 絕對值：厚度 + 1。 |
| <b>樣條資料</b> <i>顏色</i> | 彩色影像的 RGBA 通道中編碼的輸入樣條線額外資料。<br><b>R</b> - 切線 x<br><b>G</b> - 切線 y<br><b>B</b> - 未使用<br><b>A</b> - 未使用 |
| <b>樣條量</b> <i>整數</i> | 輸入樣條的數量。 |
| <b>圖案輸入#</b> <i>灰階</i> | 應該散佈在樣條上的圖案。 |
| <b>比例尺地圖</b> <i>灰階</i> | 地圖控制著散落圖案的比例尺。 此地圖的效果由「比例圖輸入乘數」參數控制，並與「尺寸」組中其他參數結合使用。 |
| <b>高度圖</b> <i>灰階</i> | 地圖控制散布圖案的高度。 此映射的效果由「高度輸入乘數」參數控制，並與「色彩」組中其他「色彩」參數結合。 |
| <b>面具地圖</b> <i>灰階</i> | 地圖控制著散落圖案的遮罩。 此映射的效果由「遮罩映射閾值」參數控制，並與其他「遮罩」參數合併於「顏色」群組中。 |

<a name="outputs"></a>

## 輸出

|  |  |
|:---|:---|
| <b>產出</b> <i>灰階</i> | 代表圖案的圖案，分布在輸入背景上的輸入樣條線上。 |

<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>花鍵輸入</b> <i>整數</i> | 選擇散射圖案應使用哪些樣條鍵的方法：<br><br>- <i>所有樣條</i>：使用輸入列表中的所有樣條線;<br>- <i>單一樣條線</i>：僅使用輸入列表中指定的樣條線;<br>- <i>樣條範圍</i>：僅使用輸入列表中指定範圍內的樣條線。 |
| <b>樣條指數</b> <i>整數</i> （當「樣條輸入」設為「單樣條鍵」時可用） | 樣條線的列表索引，應該用於散射圖案。 |

| <b>形狀量</b> <i>整數</i> （當「散佈模式」設定為「形狀量」時可用） | 每條樣條線上均勻分布的圖案數量。 |
| <b>形狀分布沿樣條曲線</b> <i>整數</i> （當「散佈模式」設定為「形狀量」時可用） | 沿樣條線分布圖案的方法：<br><br>- <i>來源</i>：圖案間距受樣條點切線影響，形狀在長切線點附近距離較遠;<br>- <i>均勻</i>：圖案沿樣條線均勻分布，無論切線與軌跡如何。 |
| <b>形狀間距</b> <i>浮動</i> （當「散佈模式」設定為「形狀間距」時可用） | 在樣條線上，圖案間距的最小距離，同時仍能讓每個樣條的起點和終點分別落在第一個和最後一個點。 |
| <b>開始</b> <i>浮標</i> | <span id="_Hlk135680521"></span>將散射起點從樣條曲線起點的點來偏移。 該值為每個樣條的正規化長度。 |
| <b>結束</b> <i>浮標</i> | 偏移點從樣條線起點到散射結束處。 該值為每個樣條的正規化長度。 |
| <b>形狀樞軸</b> <i>Float2</i> | 在樣條切空間中偏移模式 X 與 Y 的樞軸。<br>考慮到樞軸是放置在樣條鍵上的，這實際上使圖案沿著或垂直於樣條線偏移。<br>注意：樞軸的位置會影響「縮放」與「旋轉（樞軸）」參數的影響。 |
| <b>模式</b> |  |
| <b>模式</b> <i>整數</i> | 應散布於樣條線上的圖案：<br><br>- 圖案輸入</i>：使用提供給「圖案輸入#」輸入的圖案;<br>- 方形;<br>- 圓盤;<br>- 拋物面;<br>- 鐘形;<br>- 高斯分布;<br>- 棘紋;<br>- 金字塔;<br>- 磚塊;<br>- 漸變;<br>- 波浪;<br>- 半鐘形;<br>- 脊狀鐘形;<br>- 新月形;<br>- 膠囊;<br>- 錐形;<br> <i>- 漸變 w。偏移;<br>- 半球。 |
| <b>模式輸入編號</b> <i>整數</i> （當「Pattern」設定為「Pattern Input」時可用） | 選擇輸入模式的索引，該索引應被散射。 |
| <b>模式輸入分布</b> <i>整數</i> （當「Pattern」設定為「Pattern Input」時可用） | 選擇在給定樣條線上散布哪些輸入圖案的方法：- 隨機：隨機選擇圖案;<br>- <i>沿樣條曲線</i>：圖案指數沿樣條線逐漸增加;<br>- <i>圖案索引</i>：在每個樣條線上的輸入圖案索引上進行迴圈;<br>- <i>樣條索引</i>：在輸入樣條線列表中，從一個樣條線到下一個樣條線的輸入圖案索引進行迴圈。</i><i><br><br> |
| <b>分布抖動</b> <i>浮點</i> （當「模式輸入分布」設定為「沿樣條」時可用） | 隨機增加或減少樣條上所選圖案的索引。 |
| <b>覆寫第一模式</b> <i>布林值</i> | 手動選擇應該放置在每個樣條線起點的圖樣索引。 |
| <b>第一模式輸入索引</b> <i>整數</i> （當「覆蓋第一模式」設定為「真」時可用） | 每個樣條曲線起始處應放置的圖案索引。 |
| <b>覆寫最後模式</b> <i>布林值</i> | 手動選擇應該放在每個樣條線末端的圖樣索引。 |
| <b>最後模式輸入索引</b> <i>整數</i> （當「覆寫最後模式」設定為「真」時可用） | 應該放在每個樣條線末端的圖案索引。 |
| <b>重複作品</b> |  |
| <b>分配模式</b> <i>整數</i> | 放置重複圖案的方法：<br><br>- 線性</i>：重複圖案沿著樣條曲線的法線均勻分布;<br>- <i>圓形</i>：重複圖案沿著樣條曲線中心的虛擬圓排列，位於圖案<i>的原始位置。 |
| <b>重複數量</b> <i>整數</i> | 重複圖案的數量。 |
| <b>偏移</b> <i>Float2</i> （當「分發模式」設為「線性」時可用） | 對樣條線切線（平行）與法線（垂直）上重複件的位置施加偏移。<br>樣條曲線兩側的重複件則朝相反方向移動。 |
| <b>偏移中心</b> <i>Float2</i> （當「分發模式」設為「線性」時可用） | 對樣條線上 X （平行）和 Y（垂直）上的重複點施加偏移量。 |
| <b>擴散角</b> <i>浮動</i> （當「分配模式」設為「循環」時可用） | 虛擬圓的弧線，沿著重複物分布，即該弧的角度，其中1為完整圓。 |
| <b>偏移距離</b> <i>浮動</i> （當「分配模式」設為「循環」時可用） | 虛擬圓的半徑，重複物分布於此範圍內。 |
| <b>旋轉</b> <i>浮標</i> | 旋轉虛擬圓圈，重複的圓圈分布在該圓圈上。 |
| <b>偏移開始/結束衰減</b> <i>Float2</i> | 在對重複件套用偏移時，會考慮從樣條線中點到起點與結束點的距離。<br>這表示靠近樣條線端點的重複件會減少偏移量。 |
| <b>厚度偏移衰減</b> <i>浮標</i> | 在對重複件套用偏移量時，會考慮樣條的厚度。<br>這表示在樣條中厚度較小的部分重複的偏移量會減少。 |
| <b>規模</b> |  |
| <b>尺寸模式</b> <i>整數</i> | 設定散佈圖案大小的方法：<br><br>- 法線</i>：大小透過全域「縮放」參數均勻控制;<br>- <i>從樣條</i>鍵中使用厚度：大小由樣條<i>的厚度驅動。 |
| <b>厚度影響</b> <i>整數</i> （當「尺寸模式」設定為「從樣條中取厚度」時可用） | 指定圖案刻度軸的哪一軸應由樣條的厚度驅動：<br><br>- X 與 Y：厚度與 X 軸與 Y 軸的尺寸相乘;<br>- <span id="_Hlk135741125"></span>X：厚度僅乘以 X 軸的尺寸;<br>- Y：厚度僅與 Y 軸的尺寸相乘。<br><br>當未乘以時，圖案的原始比例就是影像的整個範圍。<br>這表示在「X」模式下，Y軸的大小是影像的整個範圍，需要透過尺寸參數來調整。 使用 &#39;Y&#39; 模式時，X 軸的尺寸也同樣適用。 |
| <b>規模</b> <i>Float2</i> | 在其他參數之前，X 和 Y 模式的原始大小是由其他參數完成的。 |
| <b>隨機大小</b> <i>Float2</i> | 在X和Y中減少圖案大小時，會施加隨機乘數，最高可達指定值。 |
| <b>厚度尺度</b> <i>浮動</i> （當「尺寸模式」設定為「從樣鍵中取厚度」時可用） | 當花鍵厚度驅動圖案比例時，還會增加額外的倍數。 |
| <b>規模</b> <i>浮點</i> （當「尺寸模式」設為「正常」時可用） | 一個全域控制，適用於所有圖案的大小，其中 1 是影像的整個跨度。<br>縮放是相對於圖案的樞軸來調整。 樞軸位置可以透過「形狀樞軸」參數來偏移。 |
| <b>量表隨機</b> <i>浮標</i> | 對圖案大小施加隨機乘數，最高可達指定值。 |
| <b>比例圖輸入倍增器</b> <i>浮標</i> | 控制比例貼圖輸入的強度。 此映射作為當前圖案大小的乘數。<br>此地圖的效果與「大小」組中的其他參數結合。 |
| <b>比例輸入取樣模式</b> <i>貼圖空間</i> | 將縮放貼圖中的值映射到樣條曲線的方法：<br><br>- <i>貼圖空間</i>：這些值會套用到樣條曲線上，如果使用貼圖的 UV 座標放置在貼圖中，該位置會被套用。 這實際上將值套用到「原位」的樣條曲線上;<br>- <i>沿樣條</i>線水平：這些值直接套用到編碼的樣條的座標（參見樣條座標輸入），每列從上到下分別套用到不同的樣條曲線;<br>- <i>Hor. 沿樣條曲線（蘭德。 偏移量 X）：</i>這些值直接套用到編碼後樣條的座標上（參見樣條座標輸入），每個樣條曲線（即樣條座標的每一列）在縮放映射中隨機進行水平偏移;<br>- <i>Hor。 沿樣條曲線（蘭德。 偏移 Y）：</i>這些值直接套用到編碼後樣條的座標（參見樣條座標輸入），每個樣條曲線（即樣條座標中的每一列）在縮放映射中隨機垂直偏移。 |
| <b>開始/結束衰減</b> <i>Float2</i> | 在縮放圖案時，會考慮從樣條曲線中點到起點與終點的距離。<br>這表示靠近樣條端的圖案尺寸會被縮小。 |

| <b>旋轉（樞軸）</b> <i>浮標</i> | 會圍繞他們的樞軸旋轉圖案。<br>樞軸位置可以透過「形狀樞軸」參數來偏移。 |
| <b>旋轉隨機（樞軸）</b> <i>浮標</i> | 對其樞軸周圍的圖案施加額外的隨機旋轉。<br>樞軸位置可以透過「形狀樞軸」參數來偏移。 |
| <b>旋轉隨機中心（樞軸）</b> <i>浮標</i> | 繞著圖案的樞軸旋轉，旋轉中心是隨機旋轉參數所施加的。 |
| <b>輪轉（中鋒）</b> <i>浮標</i> | 會讓圖案繞著中心旋轉。 |

| <b>旋轉隨機中心（中心）</b> <i>浮標</i> | 繞著圖案中心旋轉，也就是隨機旋轉參數所施加的旋轉中心。 |
| <b>顏色</b> |  |

| <b>樣條厚度倍增器</b> <i>浮標</i> | 每個圖案顏色相乘於樣條厚度的強度。<br>注意：輸出顏色是所有顏色乘數的加權結果。 |
| <b>形狀指數乘數</b> <i>浮標</i> | 每個圖案顏色相乘於其正規化指數的強度。<br>注意：輸出顏色是所有顏色倍數的加權結果。 |
| <b>半球高度模式</b> <i>整數</i> （當「模式」設為「半球」時可用） | 樣條高度對散布在半球圖案上的效果：<br><br>- 偏移</i>：樣條高度加到半球高度上;<br>- <i>縮放</i>：樣條高度與半球<i>高度相乘。 |
| <b>花鍵高度倍數</b> <i>浮標</i> | 每個圖案顏色與樣條線高度相乘的強度。<br>注意：輸出顏色是所有顏色乘數加權結果。 |
| <b>形狀尺度倍增器</b> <i>浮標</i> | 每個圖案顏色相乘於其比例尺的強度。<br>注意：輸出顏色是所有顏色倍數的加權結果。 |
| <b>隨機亮度</b> <i>浮標</i> | 施加隨機乘法器，最高可降低圖案亮度。<br>注意：輸出顏色為所有色彩乘數的加權結果。 |
| <b>高度輸入倍數</b> <i>浮標</i> | 控制高度圖輸入的強度。 此映射作為圖案當前亮度的乘數。<br>此映射的效果會與「色彩」組中的其他參數結合使用。<br>注意：輸出顏色是所有色彩乘數的加權結果。 |
| <b>高度圖輸入取樣模式</b> <i>整數</i> | 將高度貼圖中的值映射到樣條曲線的方法：<br><br>- <i>紋理空間</i>：這些值會套用到樣條曲線上，如果使用貼圖的 UV 座標放置，則會在紋理中放置的位置。 這實際上將值套用到「原位」的樣條曲線上;<br>- <i>沿樣條</i>線水平：這些值直接套用到編碼的樣條的座標（參見樣條座標輸入），每列從上到下分別套用到不同的樣條曲線;<br>- <i>Hor. 沿樣條曲線（蘭德。 偏移量 X）：</i>這些值直接套用到編碼後樣條的座標上（參見樣條座標輸入），每個樣條曲線（即樣條座標的每一列）在縮放映射中隨機進行水平偏移;<br>- <i>Hor。 沿樣條曲線（蘭德。 偏移 Y）：</i>這些值直接套用到編碼後樣條的座標（參見樣條座標輸入），每個樣條曲線（即樣條座標中的每一列）在縮放映射中隨機垂直偏移。 |
| <b>面具隨機</b> <i>浮標</i> | 調整隨機遮罩圖案的範圍，0表示沒有圖案被遮罩，1表示所有圖案都遮蔽。 |
| <b>遮罩貼圖閾值</b> <i>浮標</i> | 遮罩貼圖中低於此閾值的值會被處理為黑色，而高於閾值的則會被處理為白色。<br>這表示遮罩貼圖中低於此值的所有區域圖案都會被遮罩。 |
| <b>遮罩圖譜輸入取樣模式</b> <i>整數</i> | 將遮罩貼圖中的值映射到樣條曲線的方法：<br><br>- <i>紋理空間</i>：這些值會套用到樣條曲線上，若使用貼圖的 UV 座標放置，則會在貼圖中放置的位置。 這實際上將值套用到「原位」的樣條曲線上;<br>- <i>沿樣條</i>線水平：這些值直接套用到編碼的樣條的座標（參見樣條座標輸入），每列從上到下分別套用到不同的樣條曲線;<br>- <i>Hor. 沿樣條曲線（蘭德。 偏移量 X）：</i>這些值直接套用到編碼後樣條的座標上（參見樣條座標輸入），每個樣條曲線（即樣條座標的每一列）在縮放映射中隨機進行水平偏移;<br>- <i>Hor。 沿樣條曲線（蘭德。 偏移 Y）：</i>這些值直接套用到編碼後樣條的座標（參見樣條座標輸入），每個樣條曲線（即樣條座標中的每一列）在縮放映射中隨機垂直偏移。 |
| <b>反轉遮罩地圖</b> <i>布林值</i> | 使用 &#39;1 減 1 - x&#39; 運算反轉遮罩映射的值。 |
| <b>面具反轉</b> <i>布林值</i> | 反轉圖案的遮蔽。 |
| <b>非平方修正</b> <i>布林值</i> | 調整點的位置，以在非正方形解析度下保留樣條曲線形狀。 |
