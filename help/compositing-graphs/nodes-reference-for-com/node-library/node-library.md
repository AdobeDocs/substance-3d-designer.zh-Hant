# 節點函式庫

除了 [原子節點](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md)外，Designer 還附帶一個預先製作 [的圖形實例](../../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md)函式庫，分為多個類別。 有超過 200 種不同的設計，有些非常常用，有些則是針對非常特定情境設計的。這個文件區域會詳細說明所有圖書館節點，並提供哪些節點適合入門的指引與技巧。

Designer 的函式庫面板顯示的類別比我們目前所記錄的還多，最明顯的是缺少 MDL 節點，這些未來可能會被新增。
