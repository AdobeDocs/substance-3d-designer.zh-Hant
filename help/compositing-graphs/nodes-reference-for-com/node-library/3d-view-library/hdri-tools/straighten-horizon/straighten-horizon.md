## 說明

對於地平線不直的HDRI，這個節點提供了一個簡單且使用者友善的校正方法。

## 參數

* **啟用地平線修正**： *錯誤/正確*\
  啟用與停用效果。 允許切換前後比較並找出正確的點。
* **地平線點#1位置**：\
  第一點，有 2D View 的把手。
* **地平線點#2位置**：\
  第二點，有 2D View 的把手。
* **水平旋轉**： *0.0 - 1.0\
  繞中央軸線額外旋轉。*
