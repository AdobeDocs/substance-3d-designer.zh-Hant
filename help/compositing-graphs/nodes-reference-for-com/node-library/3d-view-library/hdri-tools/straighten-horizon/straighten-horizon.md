## 參數

|  |  |
|:---|:---|
| <b>啟用地平線校正</b> <i>錯誤/真實</i> | 啟用與停用效果。 允許切換前後比較並找出正確的點。 |
| <b>地平線點#1位置</b> | 第一點，有 2D View 的把手。 |
| <b>地平線點#2位置</b> | 第二點，有 2D View 的把手。 |
| <b>水平旋轉</b> <i>0.0 - 1.0</i> | 繞中央軸線額外旋轉。 |
