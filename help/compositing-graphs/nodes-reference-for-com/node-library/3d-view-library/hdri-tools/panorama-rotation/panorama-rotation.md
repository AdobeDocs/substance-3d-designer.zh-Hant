## 說明

將輸入的球面映射全景影像繞其中心點旋轉，保持投影/映射正確。 對傾斜或調整 HDRI 影像很有用。

## 參數

* **旋轉**： *0.0 - 1.0*
* **方向角**： *0.0 - 1.0*
* **繞極**&#x200B;點旋轉前： *-1.0 - 1.0*
* **繞極**&#x200B;點旋轉後： *0.0 - 1.0*
