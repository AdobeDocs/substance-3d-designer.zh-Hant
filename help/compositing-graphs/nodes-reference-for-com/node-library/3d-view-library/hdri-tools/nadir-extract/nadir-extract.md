## 說明

擷取球面映射輸入影像的中心基點（天底）。 可用來將一張影像的天底轉印到另一張，遮蔽相機或三腳架。

## 參數

* **等級**： *0.0 - 10.0*\
  將地面點設定為「縮放水平」
* **旋轉**： *0.0 - 1.0*\
  繞中心軸旋轉。
* **輸出伽瑪**： *sRGB，線性*&#x200B;輸出伽瑪。
