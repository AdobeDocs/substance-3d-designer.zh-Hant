## 說明

調整輸入影像的色彩平衡。 類似於攝影中的白平衡調整。 可以用來調整 HDR 影像中走調的暖色或冷色。

## 參數

* **溫度**： *-1.0 - 1.0*\
  在暖色和冷色間切換。
* **洋紅色**： *-1.0 - 1.0*\
  調性在洋紅色和綠色之間切換。
* **色彩空間**：*HDR（線性）、LDR（sRGB）*決定輸入影像色彩空間的解讀方式。
