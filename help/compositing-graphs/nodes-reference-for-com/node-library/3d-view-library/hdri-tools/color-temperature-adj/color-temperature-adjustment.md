## 說明

調整輸入影像的色彩平衡。 類似於攝影中的白平衡調整。 可以用來調整 HDR 影像中走調的暖色或冷色。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

|  |  |
|:---|:---|
| <b>溫度</b> <i>-1.0 - 1.0</i> | 在暖色和冷色間切換。 |
| <b>洋紅色</b> <i>-1.0 - 1.0</i> | 調性在洋紅色和綠色之間切換。 |
| <b>色彩空間</b> <i>HDR（線性）、LDR（sRGB）</i> | 判斷輸入影像的色彩空間如何被解讀。 |
