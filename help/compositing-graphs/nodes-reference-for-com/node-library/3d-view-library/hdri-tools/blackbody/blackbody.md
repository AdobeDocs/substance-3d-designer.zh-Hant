## 說明

將開爾文色溫轉換成RGB。 開爾文值越低代表顏色越暖，開爾文值越高代表顏色越冷。

## 參數

* **溫度**： *1000.0 - 27000.0*&#x200B;以開爾文計，決定顏色。
