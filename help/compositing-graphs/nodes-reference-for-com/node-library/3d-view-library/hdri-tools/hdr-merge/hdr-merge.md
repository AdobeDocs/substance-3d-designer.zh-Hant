<td style="border: 0;" valign="top">

## 說明

將多張照片曝光合併，創造高動態範圍影像。 第一個輸入是曝光最不足的影像。

## 輸入

* **輸入1-**&#x200B;**&#x200B; 16**： *彩色輸入*輸入影像。 可用數量取決於參數。

## 參數

* **輸入**： *2 - 16*\
  設定可用輸入的數量。
* **暴露 Delta（*EV）：**&#x200B;0.0 - 4.0*\
  設定曝光差異以解讀不同影像。
* **白點**： *0.0 - 13.0*&#x200B;設定白點以調整最終結果。
