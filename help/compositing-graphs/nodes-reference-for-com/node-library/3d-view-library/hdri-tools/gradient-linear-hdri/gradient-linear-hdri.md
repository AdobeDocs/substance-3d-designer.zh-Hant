## 說明

在中心和使用者放置的點上創造線性漸層。 最終結果會調整為球面投影，與一般 [的漸變線性 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/gradient-linear-1/gradient-linear-1.md) 不同。

## 參數

* **積分位置**：\
  用來判定梯度方向的油膏位置。
* **最高顏色**： *（顏色數值）*\
  漸層頂部的顏色（點位）
* **底部顏色**： *（顏色值）*\
  漸層底部（遠離點）的顏色。
* **對比**&#x200B;度： *0.0 - 1.0*\
  調整結果的對比度。
