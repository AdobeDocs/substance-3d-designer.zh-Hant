# 3D 視圖（圖書館）

3D View 類別僅包含與球形投影 HDRI 相關的節點，無論是用於 Substance 3D Designer 的 3D View 的 HDRI，或是匯出至其他應用程式如 Substance 3D Painter 的節點。

有兩個子類別：

* **HDRI 環境**：目前沒有文件，因為這些純粹是用於 3D View 顯示的影像，沒有額外參數。
* **HDRI 工具**：用於建立與編輯球形 HDRI 影像的工具節點。 於 SD 2019.2 推出。
