# 材質過濾器

材質過濾器是與完整素材輸入（Full Material input）合作的節點：多通道的組合，最佳使用方式為 [連結建立模式](../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)。 當你使用完整的 PBR 材質，而不只是單一通道（如 Basecolor 或 Normal），或是簡單的黑白遮罩時，你都會想使用 Material Filters 類別。

此類別包含多個子類別：

* [1-Click](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/1-click/1-click.md)\
  僅包含 Bitmap2Material。
* [影響](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/effects-material.md)\
  花俏的全方位材質特效。
* [轉換](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/transforms-material/transforms-material.md)\
  多管道轉型助手。
* [混合](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/blending-material.md)\
  多聲道混合節點。
* [PBR 公用事業](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-utilities.md)\
  PBR 輔助節點與工具。
* [掃描處理](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md)\
  專門為 Photoscaned 材質設計的工具。
