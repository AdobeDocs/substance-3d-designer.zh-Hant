# 效果（材料）

此類別包含產生完整材質效果的節點，類似 [風化](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/weathering/weathering.md) 節點的運作方式，但主要差異在於這些效果節點可以接收任何材質作為輸入。 它們也需要一個烘焙好的地圖作為輸入，主要是高度圖。

兩個很好的例子是 [Water Level](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/water-level/water-level.md) 和 [Snow Cover](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/snow-cover/snow-cover.md)。
