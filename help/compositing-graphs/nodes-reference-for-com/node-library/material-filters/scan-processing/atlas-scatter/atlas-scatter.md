## 說明

從地圖集中提取元素，散布在背景上。 Atlas 輸入是完整的材質，由各個元素排列並包裝在單一材質圖表上組成。 這個節點會利用內部 [的 Atlas Splitter](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/atlas-splitter/atlas-splitter.md) 流程將它們分割並散布，類似 [Shape Splatter](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter/shape-splatter.md)。 Atlas Scatter 至少需要輸入不透明度地圖，以及 Atlas 的高度地圖輸入，才能運作。

>[!NOTE]
>
> 數百個 [圖集](https://source.substance3d.com/allassets?assetType=substanceAtlas)已準備好用於阿特拉斯散佈節點，現已在 [Substance Source](https://source.substance3d.com/)上取得。

## 輸入與參數

### 參數

* **Atlas 輸入解析度**： *解析度，1 到 12*\
  手動設定完整輸入圖集的解析度，以確保良好的效能與品質比。
* **X 金額**： *1 - 64*\
  該模式重複次數為數。
* **Y金額**： *1 - 64*\
  該模式的Y字重複次數。
* **模式**
  * **圖案範圍**： *0 - 10*\
    定義了要散佈的圖案範圍。 若設為 0，則所有模式都會被使用。
  * **圖案分布模式**： *隨機、模式索引、線索引、欄索引*&#x200B;定義圖譜元素的使用順序。
  * **模式分布地圖乘數**： *0.0 - 1.0*\
    根據輸入影像的灰階值選擇形狀圖案。
  * **旋轉**&#x200B;模式： *0、90、180、270*\
    對每個圖譜元素施加固定旋轉，依選定度數調整。
  * **圖案旋轉**&#x200B;隨機： *0.0 - 1.0*\
    對設定的圖集元素部分施加隨機旋轉。
  * **Atlas 形狀偵測精度**： *簡單或小型形狀、複雜或大型形狀，無故障模式*\
    設定形狀偵測的精確度。 準確度越高，對效能的影響就越大。
  * **降階 Atlas 不透明度（更快偵測）：***-4 - 0*\
    讓你可以控制輸入圖集不透明度貼圖的下縮比例，這張圖用於形狀偵測。 較低的解析度會提升效能，但犧牲準確度。
  * **忽略形狀 小於***：0.0 - 1.0*&#x200B;設定形狀必須最小大小才能被偵測，表示為整體影像的比值
* **規模**
  * **評分：***0.0 - 5.0*\
    設定散佈形狀的相對比例。
  * **隨機**&#x200B;分數： *0.0 - 1.0*\
    定義了對每個散落形狀施加隨機縮放的乘數。
  * **無重疊**&#x200B;量表： *0.0 - 1.0*\
    縮小形狀比例，避免重疊。
  * **比例地圖乘數**： *0.0 - 1.0*\
    將形狀縮放乘以輸入影像灰階值。
  * **尺寸**： *0.0 - 1.0*\
    以長度（X）和寬度（Y）來設定散落形狀的相對比例尺。
  * **從Bg坡**&#x200B;度計算的尺寸比： *0.0 - 1.0*\
    根據背景高度斜率調整形狀大小比。
  * **保持長寬比**： *0.0 - 1.0*\
    決定應保留散落形狀原始比例的多少，而非使用其網格單元比例，即 X Amount 與 Y M 值的比例。
* **職位**
  * **位置隨機**： *0.0 - 2.0*\
    一個乘數，用於將每個形狀從網格起點隨機方向移動。
  * **隨機分布**： *高斯分布、均勻分布*\
    隨機位置從高斯分布切換為均勻分布。 高斯分布會產生比均勻分布更有機的結果。
  * **向量地圖乘數**： *0.0 - 1.0*\
    控制向量地圖輸入的影響，使形狀朝地圖紅色（X）和綠色（Y）通道指定的向量方向移動。
  * **水平**&#x200B;偏移： *-2.0 - 2.0*\
    X 軸位置偏移的乘數。
  * **垂直偏移**： *-2.0 - 2.0*\
    一個位置偏移的乘數，沿著Y軸。
  * **界外選項**： *比例形狀，限制位置*\
    由於濺射的技術特性，形狀只能畫出比原本位置超過2格大小的距離。 如果形狀變得太大或移動太遠，你有兩個選擇：- 縮放形狀會在遇到界限時縮小形狀大小 - 限制位置會將形狀移回原本位置
* **旋轉**
  * **旋轉**： *0.0 - 1.0*\
    讓你可以控制所有形狀的局部旋轉。
  * **旋轉隨機**： *0.0 - 1.0*\
    每個形狀隨機施加旋轉量的乘數。
  * **從Bg斜**&#x200B;坡轉動： *0.0 - 1.0*\
    根據背景高度斜率的函數修改形狀旋轉。 通常與「來自Bg斜率的尺寸比」參數結合使用。
  * **旋轉地圖乘數**： *0.0 - 1.0*\
    將形狀旋轉與輸入影像灰階值相乘。
  * **向量地圖乘數**： *0.0 - 1.0*\
    根據向量影像輸入設定形狀旋轉。
* **高度**
  * **身高刻度自動調整**： *錯誤/真實*\
    根據圖案比例自動調整高度，使形狀高度與背景高度成比例。
  * **混合模式**： *高度混合、Alpha 測試*\
    設定了重疊形狀的求解方法。
  * **身高偏移**： *-1.0 - 1.0*\
    對形狀高度套用全域偏移
  * **身高偏移隨機**： *0.0 - 1.0*\
    每個形狀隨機施加高度偏移的乘數
  * **高度偏移地圖多重增壓**&#x200B;器： *0.0 - 1.0*\
    將形狀高度偏移乘以輸入影像灰階值。
  * **身高評分**： *0.0 - 1.0*\
    讓你能控制散落形狀的全局高度比例
  * **身高隨機**： *0.0 - 1.0*\
    每個形狀隨機施加高度刻度的乘數
  * **高度比例地圖乘數**： *0.0 - 1.0*\
    以輸入影像灰階值乘以形狀高度尺度。
  * **符合背景**： *0.0 - 1.0*\
    在 0 時，形狀高度保持不變;在 1 時，形狀高度會被底層高度背景所改變。
  * **平滑成型背景**： *0.0 - 2.0*\
    讓你可以控制形狀在與背景形成對其高度變形時施加的平滑量。
  * **從Bg斜**&#x200B;率偏斜： *0.0 - 1.0*\
    根據局部背景高度斜率變形形狀高度：在形狀高度上加入對應背景斜率的線性梯度。
  * **背景斜率平滑度**： *0.0 - 2.0*\
    控制當形狀因斜率而傾斜時，對背景斜率施加的平滑量。
  * **剪裁黑像素**： *錯誤/真實*\
    忽略圖案輸入的黑色值。
  * **平坦模式基底**： *錯誤/真實*\
    讓你能將背景高度壓平，使其起始高度與形狀相符。
* **遮蔽**
  * **遮罩隨機**&#x200B;值： *0.0 - 1.0*\
    遮罩隨機數量的形狀，表示為總數的比值。
  * **遮罩隨機地圖乘數**： *0.0 - 1.0*\
    將隨機形狀遮罩設定為灰階影像輸入的函數。
  * **Bg Slope** 的面罩： *-1.0 - 1.0*\
    根據背景斜率控制形狀的遮罩。
* **顏色**
  * **色彩調整**： *-1.0 - 1.0*\
    讓你可以全局調整散布元素的顏色。
  * **顏色隨機**： *0.0 - 1.0*\
    一個乘數，用來隨機偏移每個形狀的顏色值。
  * **背景**&#x200B;色彩： *0.0 - 1.0*\
    將形狀顏色轉換成其位置背景的顏色。
* **正常**
  * **從Bg斜**&#x200B;率偏斜： *0.0 - 1.0*\
    根據背景法線調整形狀的法線。
  * **普通隨機**： *0.0 - 1.0*\
    一個乘數，將形狀的法線偏斜，隨機偏向每個形狀。
  * **一般格式**： *DirectX、OpenGL*\
    切換不同的法線貼圖格式（反轉綠色通道）
* **粗糙度**
  * **粗糙度調整**： *-1.0 - 1.0*\
    這樣可以讓你偏移全域形狀的粗糙度。
  * **背景**&#x200B;粗糙度： *0.0 - 1.0*\
    將形狀的粗糙度轉換到它們所在位置的背景粗糙度。
  * **粗糙度隨機**&#x200B;值： *0.0 - 1.0*&#x200B;一個乘數，用於將粗糙度以隨機數量抵消每個形狀。
