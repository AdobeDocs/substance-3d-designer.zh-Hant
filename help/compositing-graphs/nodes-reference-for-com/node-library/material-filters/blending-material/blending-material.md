# 混合（材料）

混合類別是最重要的多通道素材類別之一。 它包含用於組合、切換及混合多個同時輸出材料的節點。

這些節點能節省大量工作，但務必充分了解 [連結創建模式](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) ，才能正確使用它們。

以下幾個節點是不錯的起點：

* [多材料混合](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/multi-material-blend/multi-material-blend.md)
* [材料調整混合](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-adjustment-blend/material-adjustment-blend.md)
