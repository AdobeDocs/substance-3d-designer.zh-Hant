# 缺少 Substance 模型圖功能

## 晚年

Substance 模型圖是我們首次嘗試參數化建模，後來<b>在 Substance 3D Designer 13.0.0</b> 版本<b>中被淘汰</b>。

12.4.1</b> 版本<b>是 *Designer 最後一個*&#x200B;支援 Substance 模型圖的版本。因此，使用此功能的使用者不應升級至更高版本。
