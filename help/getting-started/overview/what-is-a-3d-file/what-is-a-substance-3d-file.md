# 什麼是 Substance 3D 檔案？

![參數磚牆材料](what-is-a-substance-3d-file.resources/MaterialsOverview.gif "參數磚牆材料")

*由Käy Vriend製作的磚牆材料範例。\
參數可調整以動態控制材質外觀。*

Substance 3D 檔案是一種動態貼圖產生器，可直接用於多種應用。

它是動態的，因為與傳統點陣圖檔案不同，Substance 3D 檔案的創建者可以選擇<b>暴露參數</b>，以控制<b></b>最終產生的結果。

例如，可以改變物體上的灰塵量，或足球隊球衣的顏色。 你的天賦和想像力是你能做到的全部限制。

Substance 材質可以發佈，然後用於<b>整合 <b>Substance 3D 引擎</b>的外部應用程式</b>（例如 *Unity* 或 *Unreal Engine*）。

Substance 3D 材料可以是 *100% 程序化*&#x200B;的，因此其輸出尺寸會非常輕。
