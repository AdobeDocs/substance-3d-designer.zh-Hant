# 所有變動

## 版本 16

### 16.0.4

*（2026年7月2日發布）*

**補充：**

* [3D 視角]將渲染解析度在 X 和 Y 鍵中固定為 4096
* [烘焙師]將 bake-sdk 更新至 3.22.3
* [引擎]更新物質引擎至v9.4.4
* [OpenGL][OpenPBR]降低鏡面瓣的雜訊，以達到高粗糙度+各向異性
* [場景]保留UV primvar插值模式

**修正：**

* [3D 視圖]美元匯出：資源路徑以絕對路徑儲存
* [烘焙者]高多邊形網格載入取消時烘焙失敗（Windows）
* [Bakers]高多邊形 3D 場景列表不包含與低多邊形相同識別碼的資源
* [Bakers]正常世界空間：當有輸入正常時，總會回傳 WS normal
* [內容]在 Shape Splatter V2 中，當圖案不均勻地縮放時，正常範圍不正確
* [內容]形狀濺射 V2：黑色法線用於「平面」與「圓盤」形狀
* [內容]形狀濺射 v2：第一個形狀未正確與背景融合
* [崩潰聲]隨機崩潰可能與影片有關（豐富的提示）
* [圖]貼上從新圖複製且識別碼為空白的節點時會當機
* [PSD]PSD 檔案載入次數過多

**修正：**

* [當機]修正 v16.0.2 中引入的回歸問題，導致部分使用者在啟動時當機
