# 版本 2020.1 （10.1）

**Substance Designer 2020.1** 包含新的捷徑編輯器、MaterialX 外掛，以及使用 Adobe Color Engine 和新增烘焙功能在色彩管理方面的多項新改進。

發行日期： *2020年4月10日*

>[!NOTE]
>
> 從本版本開始，應用程式版本號將改變格式。 原本應該是 **2020.1** 版本的版本現在變成 **了 10.1.0**。

## 主要特色

### 節點建立新捷徑編輯器

![](version-2020-1-10-1.resources/banner-shortcuts.png)

在這個版本中，我們引入了一個新的捷記編輯器，允許定義鍵盤捷徑，以加快不同圖模式中節點的建立。

新的捷徑編輯器可透過主偏好設定 **>編輯偏好設定>捷徑**&#x200B;存取。 預設情況下，所有捷徑欄位都是空的。

* **每種圖類型的捷徑**\
  Substance Designer 可為每種圖類型定義捷徑，從一般合成圖到進階如函數與 MDL。

  ![](version-2020-1-10-1.resources/shortcuts-graph-type.png)
* **同時為原子節點和自訂過濾器指派捷徑**\
  預設情況下，介面會顯示每種圖類型的原子節點。 使用搜尋欄位不僅能精細清單，也能讓自訂函式庫的篩選器和節點變得可存取：

  ![](version-2020-1-10-1.resources/shortcut-node-search.gif)
* **建立新的捷徑**\
  要為特定節點建立新的捷徑，只需點擊該節點名稱旁的文字欄位，並在鍵盤上輸入所需鍵。 要清除捷徑，請使用十字鍵。

  ![](version-2020-1-10-1.resources/shortcut-edition.gif)
* **管理捷徑衝突**\
  請使用警告圖示上的提示，了解更多衝突資訊。 它會說明某個金鑰是否與現有金鑰衝突，或該應用程式已用於其他用途。

  ![](version-2020-1-10-1.resources/shortcut-conflict-duplicate.png)

  ![](version-2020-1-10-1.resources/shortcut-conflict-app.png)
* **搜尋捷徑**\
  如果有太多捷徑需要追蹤，或某節點預設不見，請使用搜尋系統將它們隔離出來：

  ![](version-2020-1-10-1.resources/shortcut-search.gif)

### 全新 MaterialX 外掛（測試版）

![](version-2020-1-10-1.resources/banner-materialx.png)

在 2019 年 SIGGRAPH 期間，我們展示了一款 Substance Designer 的 MaterialX 外掛。 [MaterialX](http://www.materialx.org/) 是由工業光魔（ILM）開發 [的一種格式，](https://www.ilm.com/) 允許藝術家創作素材，並能在多種平台及多種用途中使用（如電影、電視節目、遊戲、VR 體驗及製造）。 這個新外掛現已提供測試版，允許製作可用於其他相容 DCC 應用程式的 MaterialX 材質。 請參考我們近期 [關於 MaterialX](https://magazine.substance3d.com/research-a-portable-shader-graph/) 的文章，了解這個新外掛背後的流程與目標。

這個新外掛可：

* 同時開發程序式著色器和貼圖。
* 為 Substance Painter 建立進階著色器，具備細節貼圖與程序遮罩等功能，並可於執行時調整。
* 在 Substance Designer 和 Substance Painter 視圖中，從遊戲引擎或 VFX 管線中匹配著色器功能。

要取得外掛，只要到 [Substance Share](https://share.substance3d.com/libraries/6111) 下載即可。

![](version-2020-1-10-1.resources/banner-ace-1.jpg)

除了 OpenColorIO 外，現在還可以使用 Adobe Color Engine（ACE）來支援 ICC 設定檔以進行色彩管理。 這表示你現在可以匯入和匯出校正過的圖片，以匹配其他軟體，如 Photoshop 和 Illustrator。

* **啟用 Adobe Color Engine**\
  使用專案設定來定義要使用哪種色彩管理系統：

  ![](version-2020-1-10-1.resources/color-ace-setting.png)
* **更改螢幕設定檔**\
  在透過 2D 或 3D 視圖預覽影像時，請使用下拉選單指定要使用的設定檔：

  ![](version-2020-1-10-1.resources/color-ace-profile.png)
* **ACES 傳統色彩管理**\
  ACES 的色調映射輸出轉換現已透過 Legacy 色彩管理模式提供。

### 改良烘焙師

![](version-2020-1-10-1.resources/banner-baking-2.jpg)

我們透過兩項主要調整來精煉部分烘焙師：

* **改良取樣**\
  環境遮蔽、厚度與曲率烘焙器現在採用了一種全新的取樣方法，大幅提升了烘焙結果的品質。 這樣能產生更悅耳的噪音和更穩定的結果，且不需要增加取樣數。 下圖顯示的是上方的取樣方法，下方則是新方法，從左到右分別是 4、8 和 16 個取樣（所有渲染皆以抗鋸齒為 4x4 子取樣完成）。

  ![](version-2020-1-10-1.resources/bakers-sampling-comparison.jpg){width="600px"}
* **新的正規化設定**\
  厚度和高度圖烘焙器新增了一個正規化參數，讓你能將原始值烘焙到貼圖上，而不是被固定在 0-1 範圍內的值。 這對於高度圖非常有用，可以知道低多邊形與高多邊形網格之間的原始距離。 除數值會精確對應到低多邊形網格的位移強度，以匹配高多邊形網格的輪廓。 為了正確解讀高度圖，我們也暴露了一個新的「純量零值」參數，用以定義對應於 0 的像素值。 此外，手動因子還能修正因每個 UV-Tile 正規化而導致 UDIM 網格接縫問題。

  ![](version-2020-1-10-1.resources/baker-none-normalization.png)

### 改良版 3D 視角

![](version-2020-1-10-1.resources/banner-3dview.jpg)

3D 視圖獲得多項生活品質提升，應該能讓日常工作更愉快：

* **渲染器間的參數同步**\
  現在 OpenGl 和 Iray 之間的著色器參數會同步，讓兩者之間切換變得容易許多。
* **顯示材質輸入預覽並新增禁用參數**\
  著色器輸入參數現在會顯示其輸入的預覽：可以是統一的顏色參數、圖形節點或位圖。 也可以取消勾選參數，暫時停用該參數。

  ![](version-2020-1-10-1.resources/3dview-map-preview.png)

  ![](version-2020-1-10-1.resources/3dview-enable-setting.gif)
* **設定中的環境地圖預覽**\
  當進入 **3D 檢視>環境>編輯** 時，現在會預覽用來照明場景的環境貼圖。

  ![](version-2020-1-10-1.resources/3dview-env-settings.jpg)
* **全新 Unlit 著色器**\
  預設包含了一個名為「unlit」的新著色器。 它不會對任何光照做出反應，而是可以用來在視口中顯示一個貼圖，覆蓋在一個網格上。 這對於觀察烘焙材質很有幫助。

  ![](version-2020-1-10-1.resources/3dview-unlit-shader.jpg){width="500px"}
* **在高 DPI 螢幕上使用視窗降細的效能提升**\
  與 Substance Painter 類似，主偏好設定新增了一個名為 **Viewport 縮放** 的新參數，能偵測螢幕是否使用 HDPI 縮放（例如 MacOS的 Retina 螢幕），並自動將視窗解析度除以 2。 此行為避免以過高解析度繪製視窗，並提升整體效能。\
  目前設定值為：

  * **沒有**：沒有視窗縮放。
  * **自動** （預設）：如果應用程式在 HDPI 螢幕上，視窗解析度會被除以二。

  ![](version-2020-1-10-1.resources/3dview-hdpi-scaling.png)

### 新內容

![](version-2020-1-10-1.resources/banner-content-7.jpg)

此版本亦包含一些新增或改良的節點：

* **改良版 PBR 渲染節點**\
  這個節點在先前版本中已引入，且已大幅改進。 它現在提供攝影機控制、新形狀（如平面和圓柱體）、後期效果（景深、光暈/眩光、暗影等）以及新的材質類型（如透明塗層和各向異性），同時也支援不透明材質。\
  欲了解更多資訊，請參閱專門的文件 [頁面](../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-render/pbr-render.md)。

  ![](version-2020-1-10-1.resources/sphere-forest-gravel.jpg){width="250px"}

  ![](version-2020-1-10-1.resources/sphere-chesterfield.jpg){width="250px"}

  ![](version-2020-1-10-1.resources/sherif.jpg){width="250px"}
* **新的 PBR 渲染映射節點**\
  作為 PBR Render 的擴充，你可以用這個新節點來建立複合地圖通道預覽。\
  欲了解更多資訊，請參閱專門的文件 [頁面](../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-render-mapping/pbr-render-mapping.md)。

  ![](version-2020-1-10-1.resources/pbr-render-mapping-ex-2.png){width="250px"}

  ![](version-2020-1-10-1.resources/pbr-render-mapping-ex.png){width="250px"}
* **全新 FXAA 濾波器**\
  新濾波器實作了快速近似抗鋸齒（FXAA）演算法，這是一種抗鋸齒方法。 它可用於一般紋理，以平滑鋸齒狀的線條或邊緣。\
  欲了解更多資訊，請參閱專門的文件 [頁面](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/fxaa/fxaa.md)。

  ![](version-2020-1-10-1.resources/content-fxaa.png){width="600px"}
* **新 Hald CLUT 濾波器**\
  此濾鏡允許透過輸入查找表（LUT）調整影像的色調與顏色。 它使用 Hald CLUT 格式，可以從這裡[&#128279;](http://www.quelsolaar.com/technology/clut.html)提供的身份 LUT 直接開始建立一個 CLUT。\
  欲了解更多資訊，請參閱專門的文件 [頁面](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/hald-clut/hald-clut.md)。

  ![](version-2020-1-10-1.resources/content-hald-clut.jpg){width="600px"}
